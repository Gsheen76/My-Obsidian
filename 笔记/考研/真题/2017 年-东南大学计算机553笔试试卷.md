#### 1. 什么是“else 摇摆问题”？举例说明。（10 分） 
```text
“else 摇摆问题”是指在嵌套的 if 语句中，由于没有使用花括号明确语句块范围，导致 else 无法直观判断应与哪一个 if 匹配的问题。按照语言规则，else 总是与最近的、尚未匹配的 if 配对，但这种规则容易引起歧义，影响代码可读性，甚至导致逻辑错误。例如：if(a>0) if(b>0) printf("x"); else printf("y"); 这里的 else 实际上与第二个 if(b>0) 匹配，而不是第一个 if(a>0)。如果程序员误以为 else 对应第一个 if，就会产生错误理解。为避免该问题，应使用花括号明确结构，使逻辑关系清晰。
```

#### 2. 函数模板和函数重载的区别与联系。（10 分） 
```text
函数重载是指在同一作用域内定义多个同名函数，通过参数类型、个数或顺序的不同来区分调用，编译器在编译阶段根据实参类型选择最合适的函数实现。
函数模板是一种泛型机制，用一个通用的函数描述适用于多种数据类型的操作，编译器在使用时根据传入类型自动实例化具体函数。

二者的联系在于都实现了多态性，提升代码复用性与灵活性。区别在于，函数重载需要为每种类型分别编写函数，而函数模板只需编写一次即可适用于多种类型；同时在匹配规则上，当模板与普通函数重载同时存在时，编译器通常优先选择最匹配的普通函数，其次才考虑模板实例。
```

#### 3. 怎样区分虚函数和纯虚函数？它们各有什么作用？（20 分）
```text
虚函数是指在基类中使用 virtual 关键字声明的成员函数，它可以在派生类中被重写，通过基类指针或引用调用时，会根据对象的实际类型动态绑定到对应的函数实现。其作用是实现接口的可扩展性和灵活的多态调用。

纯虚函数是在虚函数基础上进一步抽象，在声明时赋值为0（如 virtual void f()=0;），表示该函数在基类中没有具体实现，必须由派生类重写。含有纯虚函数的类称为抽象类，不能直接实例化。纯虚函数的作用是定义统一接口，强制派生类实现特定功能，从而规范类的设计结构。
```

#### 4. 面向对象程序中，“接口”与“实现方法”分离有什么优点？（10 分） 
```text
在 面向对象编程 中，将“接口”与“实现方法”分离具有多方面优点。首先，有助于提高程序的可维护性，当实现细节发生变化时，只要接口保持不变，使用该接口的代码无需修改。其次，可以增强代码的可扩展性，不同的实现可以在不影响调用者的情况下进行替换或扩展。再次，这种分离有利于降低模块之间的耦合，使系统结构更加清晰，便于团队协作开发。此外，它还支持多态机制，使同一接口可以对应多种实现，提高代码复用性和灵活性，从而提升整体软件设计质量。
```

# 三、 编程题

读取日期 07/21/2016，转换为以下格式 July 21, 2016 并输出到屏幕。要求：从标准
输入获取形如 “月/日/年” 的字符串；解析并转成英文月份（如 07 => July，08 => 
August 等），拼装成 “July 21, 2016” 格式；输出到屏幕。
```c++
#include<iostream>
#include<string>
using namespace std;

int main(){
    string Month[12]={"Jan","Feb","Mar","Apr","May","Jun","Jul","Aug","Sep","Oct","Nov","Dec"};
    int monthNum;
    string date;
    cout << "Enter a date (mm/dd/yyyy): ";
    cin >> date;
    string month = date.substr(0, date.find("/"));
    date.erase(0, date.find("/") + 1);
    string day = date.substr(0, date.find("/"));
    date.erase(0, date.find("/") + 1);
    string year = date.substr(0);
    monthNum = stoi(month);
    cout<< Month[monthNum-1] << " " << day << ", " << year << endl;
}
```
