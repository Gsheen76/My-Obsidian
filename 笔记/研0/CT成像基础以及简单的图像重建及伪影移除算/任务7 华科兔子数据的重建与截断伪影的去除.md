# Step1 postlog
  
从之前的学习中我们知道，重建是将线积分得到的正弦图通过滤波反投影方法回抹，试图”消去“线积分运算，得到原始物体信息的过程。
真实数据的投影拍摄过程遵循 Beer-Lambert Law
$$N = N_0 \exp\left(-\int_L \mu(l)\,dl\right)$$
即出射光子数与入射光子数满足指数衰减。因此，在进行滤波反投影前需要先拆出线积分项，即
$$\int_L \mu(l)\,dl = -\ln\frac{N}{N_0}$$
我们将这张图称为 postlog，CT 重建实际上是对 postlog 图做重建，重建结果消去线积分，得到 μ 值组成的图像。你也可以将 μ 值转换成 HU 值
$$HU = \frac{\mu - \mu_{water}}{\mu_{water}} \times 1000$$
使用如下参数可以打开投影图 `0.raw` 及文件夹下所有投影共 400 张：
CBCT（锥束 CT）使用平板探测器，这意味着拍出来的投影就好像一般的 X 光片一样，是人读得懂的样子（红框）；多排 CT 的投影则在竖方向短得多（黄框）；线阵探测器的 CT 的投影在一个 view 则只有一行，通过堆叠不同 view 的投影即得到正弦图。

# Step 2 重建

我们将使用 mgfbp 工具进行锥束 CT 重建。给出系统的几何参数和扫描协议如下：

|参数|数值|说明|
|---|---|---|
|Source-Isocenter-Distance|311.14 mm|射线源到旋转中心距离|
|Source-Detector-Distance|435.94 mm|射线源到探测器距离|
|OffsetU|0.14 mm|沿投影横方向的偏移|
|OffsetV|1.03 mm|沿投影竖方向的偏移|
|TotalAngle|360|总角度数|
|TotalViews|400|意味着每个 view 旋转 360/400 度|
|DetectorWidth|3072|像素|
|DetectorHeight|1944|像素|
|DetectorElementSize|0.0748 mm|探测器每个像元的物理尺寸|
我们希望将其重建为切片为 **512×512** 像素的，切片数为 **256** 的 Volume。VoxelSize（体素大小）为正方形，**0.3125 mm**。你可以依据上述信息编写 mgfbp 的配置文件，也可以使用 crip 库调用已经添加到 PATH 环境变量的 mgfbp 程序进行重建，具体可参考末尾的代码。

由于原始投影非常大（4G+），处理代价很高，且目前的 mgfbp 对此类超大投影不能正确重建（这一点吴锬等同学进行了修复，后续会更新），因此我们会使用一种叫做 **binning** 的技术来缩小投影大小，即多像素合一。`crip.preprocess.binning` 函数提供了一种最简单的处理方式，即横纵方向每间隔 `binRate` 像素取一次值。

# Step 3 截断伪影校正

使用上述参数重建时，你会发现当兔子超出了重建图的 FOV 时，边缘部分发亮，这被称为**截断伪影**。其产生原因是在某些投影下兔子超出了投影图的边界，表现在正弦图上就是正弦超出了横方向的边界。（如红色箭头所示，兔子超出了边界）这导致进行滤波时 Ramp 核在边界位置出现异常，最终使得重建图像在 FOV 边缘发亮。

为了校正这个问题，我们可以将正弦图左右分别补出一部分，使得 Ramp 滤波可以正常进行。如下图所示，黄线右侧为镜面对称的补出结果，并增加了余弦衰减，单侧补出宽度为原始正弦图的 10%。当然，补充的部分毕竟是原始不存在的部分，因此只能大致改善 FOV 边缘的视觉效果，但不能保证重建数值的正确性。

# 参考程序

> 说明：`crip` 可使用 `pip install crip==1.6.3` 安装，注意该库还处于频繁迭代阶段，其中的 API 会经常变动，且需要批判地看待库的正确性。
```python
projs = []
for file in tqdm(listDirectory(ProjDir, style='fullpath'), ncols=80):
    proj = imreadRaw(file, H, W, dtype=np.int16)
    proj = flatDarkFieldCorrection(proj, Flat)  # 求 postlog
    binningProj = binning(proj, (BinRate, BinRate)).copy()  # 在高宽方向均 bin
    del proj
    projs.append(binningProj)
imwriteTiff(projs, 'BinningPostlogs.tif')
sinos = projectionsToSinograms(projs)  # 投影转为正弦图
del projs
imwriteTiff(sinos, 'Sinos.tif')

# 建立 mgfbp 运行需要的文件夹
os.makedirs('./sgm', exist_ok=1)
os.makedirs('./rec', exist_ok=1)
os.makedirs('./tmp', exist_ok=1)
  
# 系统参数
SID = 311.14
SDD = 435.94
OffsetU = 0.14
OffsetV = 1.03
TotalAngle = 360  # or -360
TotalViews = 400
DetectorElementSize = 0.0748 * BinRate
VolHW, VolSlice = 512, 256
VoxelSize = 0.3125

# 滤波反投影过程使用的滤波核
Filter = 'GaussianApodizedRamp'
FilterParam = 1

# 重建
imwriteRaw(sinos, './sgm/sgm_rabbit.raw', dtype=np.float32)

# mgfbp 需要使用正弦图重建，数据类型为 float32
cfg = MgfbpConfig()
cfg.setGeometry(SID, SDD, TotalAngle, OffsetU)
cfg.setIO(abspath('./sgm'), abspath('./rec'), '.*rabbit.*',
          OutputFileReplace=['sgm', 'rec'])
cfg.setSgmConeBeam(w, TotalViews, TotalViews, DetectorElementSize,
                   h, DetectorElementSize, OffsetV)
cfg.setRecConeBeam(VolHW, VoxelSize, VolSlice, VoxelSize,
                   Filter, FilterParam, ImageRotation=90)
Mgfbp(tempDir='./tmp').exec(cfg)

# 截断伪影校正
pad = int(sinos.shape[0] * 0.1)  # 向左右各拓 10%
paddedSinos = padSinogram(sinos, (pad, pad))
imwriteRaw(paddedSinos, './sgm/sgm_pad.raw', dtype=np.float32)
cfg = MgfbpConfig()  # 建议不要复用前面的 cfg 进一步 set
cfg.setGeometry(SID, SDD, TotalAngle, OffsetU)
cfg.setIO(abspath('./sgm'), abspath('./rec'), '.*pad.*',
          OutputFileReplace=['sgm', 'rec'])
cfg.setSgmConeBeam(w + 2 * pad, TotalViews, TotalViews,
                   DetectorElementSize, h, DetectorElementSize, OffsetV)
cfg.setRecConeBeam(VolHW, VoxelSize, VolSlice, VoxelSize,
                   Filter, FilterParam, ImageRotation=90)
Mgfbp(tempDir='./tmp').exec(cfg)
recPad = imreadRaw('./rec/rec_pad.raw', VolHW, VolHW,
                   dtype=np.float32, nSlice=VolSlice)
imwriteTiff(fovCrop(recPad, 256, 0), './rec/red_pad.tif')
```
