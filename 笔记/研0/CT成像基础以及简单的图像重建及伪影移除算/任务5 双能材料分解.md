# step1

阅读《双能材料分解》的第一节，理解为什么诊断能量范围内不同材料的线性衰减系数可通过另两种材料的线性衰减系数通过线性组合获得（在没有kedge的情况下）和材料基的概念。

# step2

尝试将 水 和 骨头（Bone Cortical） 的线性衰减系数以PMMA和铝的线性衰减系数为基做分解，以验证《双能材料分解》的第一节内容的正确性，具体如下：
进入 https://physics.nist.gov/PhysRefData/XrayMassCoef/tab4.html  获取有机玻璃（Polymethyl Methacrylate；PMMA）、水 和 骨头（Bone Cortical） 在20、30、40、50、60、80、100 keV的线性衰减系数；
进入 https://physics.nist.gov/PhysRefData/XrayMassCoef/tab3.html 页面获取铝在20、30、40、50、60、80、100 keV的线性衰减系数；将线性衰减系数看作向量：μ ⃗=(μ(20 keV),μ(30 keV),…,μ(100 keV))
求解如下最小二乘问题：
(α_1,α_2 )=  arg⁡min┬(α_1,α_2 )⁡〖|├ μ ⃗-α_1 μ ⃗_PMMA-α_2 μ ⃗_Al ┤|^2 〗 
其中μ ⃗是水或者骨头（Bone Cortical）的线性衰减系数。对于每种材料，将原始的线性衰减系数随能量变化和线性组合获得的线性衰减系数画在一张图上，y轴建议为log坐标。例如将水的μ(E)曲线和水分解对应的α_1 μ_PMMA (E)+α_2 μ_Al (E)画在一张图上。
提示：网站直接获取的数据是质量衰减系数μ/ρ, 相应乘以物质对应密度才是线性衰减系数μ. 物质密度可在
https://physics.nist.gov/PhysRefData/XrayMassCoef/tab1.html
https://physics.nist.gov/PhysRefData/XrayMassCoef/tab2.html
页面获得。

# step3

阅读《双能材料分解》的第二节，理解双能材料分解。

# step4

重建sgm/sgm_80.raw和sgm/sgm_140.raw文件，这是一个脑部CT在80 kVp和140 kVp两个光谱下正投影的模拟，生成该数据的正投影参数如下：

```json
/*********************************************************
  * geometry and detector parameters
  *********************************************************/
  // source to isocenter distance [mm]
  "SourceIsocenterDistance": 500,
  // source to detector distance [mm]
  "SourceDetectorDistance": 1000,
  // number of detector elements
  "DetectorElementCount": 1000,
  // number of views for reconstruction
  "Views": 1000,
  // the physical size of detector element size [mm]
  "DetectorElementSize": 0.4,
```
具体的光谱信息在spec文件夹内。要求重建图为512*512，像素大小为0.4 mm，滤波核为“GaussianApodizedRamp“：2。根据以上参数和要求，自行更改config_mgfbp.jsonc配置文件，进行重建（不要求把图像转化为HU值）。用合适的窗位窗宽显示图像，观察图像中的硬化伪影。

# step5

多能谱下材料分解系数的获取。从spec文件夹的spec_80.txt 和spec_140.txt文件中获取光谱（文件第一列为能量（单位：keV），第二列为权重）。利用下述多能谱下的postlog衰减公式获取不同厚度PMMA和铝的衰减：
A_i (L_PMMA,L_Al )= -ln⁡〖(∫dE Ω_i (E) e^(-μ_PMMA (E) L_PMMA-μ_al (E)L_Al ))/(∫dE Ω_i (E) )〗
其中L_PMMA,L_Al为PMMA和铝的长（厚）度，i=1或2，分别代表80 kVp或140 kVp的光谱, A_i即为两个光谱下的postlog投影数据（正弦图上的数据）。具体模拟细节为：PMMA的长度取0,2,4,…,20厘米，铝的长度取0,1,2,3,4,5厘米。将PMMA的长度和铝的长度组合，一共有11x6=66种组合，因此对于一个光谱产生66个数据点，两个光谱共计66*2=132个数据点。
提示：注意L_PMMA,L_Al得单位需和μ_PMMA 〖,μ〗_al单位匹配。

# step6

利用产生的数据反解出L_PMMA,L_Al与A_1,A_2的函数关系，使用多元多项式拟合。利用你产生的132个A_i (L_PMMA,L_Al )数据点，尝试拟合如下关系：
L_PMMA=β_1,0 A_1+β_0,1 A_2+β_2,0 A_1^2+β_1,1 A_1 A_2+β_2,0 A_2^2
L_Al=γ_1,0 A_1+γ_0,1 A_2+γ_2,0 A_1^2+γ_1,1 A_1 A_2+γ_2,0 A_2^2
求解系数β,γ. 
![](assets/任务5%20双能材料分解/file-20260518201229587.png)

# step7

将你求得的系数用在原始投影数据sgm/sgm_80.raw和sgm/sgm_140.raw上，以点对点的方式进行材料分解。例如将sgm_80的第一行第一列的像素值作为A_1，sgm_140的第一行第一列的像素值作为A_2，求出第一行第一列的像素对应的L_PMMA和L_Al；将sgm_80的第一行第二列的像素值作为A_1，sgm_140的第一行第二列的像素值作为A_2，求出第一行第二列的像素对应的L_PMMA和L_Al……。最终求得L_PMMA和L_Al构成的正弦图。
![](assets/任务5%20双能材料分解/file-20260518201217867.png)

# step8

利用第4问中的重建参数重建L_PMMA和L_Al构成的正弦图。重建所得图像即为各位置材料关于PMMA和铝的分解系数α_1 (r ⃗),α_2 (r ⃗)。
![](assets/任务5%20双能材料分解/file-20260518201206163.png)

# step9

通过重建所得的材料基图像获得CT图像（模拟单能图像）。选取某一能量，此处选择80 keV，找出PMMA和铝在80 keV下的衰减系数，获得衰减系数的图像：
μ(r ⃗ )=α_1 (r ⃗ ) μ_pmma (80 keV)+ α_2 (r ⃗ ) μ_al (80 keV)
再将μ(r ⃗ )转化为HU值
HU(r ⃗ )=μ(r ⃗ )/(μ_water (80 keV))×1000-1000
以[-50，100]窗显示所得图像。
