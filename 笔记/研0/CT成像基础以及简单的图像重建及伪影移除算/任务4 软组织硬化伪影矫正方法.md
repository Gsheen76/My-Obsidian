> 记录 CT 成像课程任务中的理论、操作步骤、参数和结果。

# step1

进入 [https://physics.nist.gov/PhysRefData/XrayMassCoef/tab4.html](https://physics.nist.gov/PhysRefData/XrayMassCoef/tab4.html) 页面获得 水、血液（blood）、肌肉（Muscle）、脑组织（brain white grey matter）和 骨头（Bone Cortical）的随能量变化的质量衰减系数（$\frac{μ}{ρ}$），做出（$\frac{μ}{ρ}$）（E）vs能量E的曲线，判断哪些组织的质量衰减系数（$\frac{μ}{ρ}$）随能量的依赖比较类似，那些差异较大。结合之前学的内容，思考其中的物理原因（提示：某一反应截面和原子序数相关）。

# step2

阅读 “软组织硬化伪影矫正.docx” ，理解当物体不包含高原子序数材料时的硬化伪影矫正。

# step3

重建sgm/sgm_brain.raw文件，这是一个去掉头盖骨的脑部CT正投影数据的模拟，生成该数据的正投影参数如下：
```json
  *********************************************************
  * geometry and detector parameters
  *********************************************************

  // source to isocenter distance [mm]
  "SourceIsocenterDistance": 500,

  // source to detector distance [mm]
  "SourceDetectorDistance": 1000,

  // number of detector elements
  "DetectorElementCount": 1000,

  // number of views for reconstruction
  "Views": 1000,

  // the physical size of detector element size [mm]
  "DetectorElementSize": 0.4,
```
正投影光谱同之前作业的120 kVp光谱（不加铜滤片，光谱附在spectrum.txt中）。要求重建图为$512*512$，像素大小为0.4 mm。根据以上参数和要求，自行更改`config_mgfbp.jsonc`配置文件，进行重建，并将重建图转换为HU值。注：在`config_mgfbp.jsonc`加入参数 "WaterMu":0.0265, （单位为$mm^{-1}$） 可在重建的同时直接根据此值将重建图转为HU值，用窗\[-180 , -100]显示重建所得图像，并观察硬化伪影。
![475](assets/任务4%20软组织硬化伪影矫正方法/file-20260510121122090.png)
图像统计：Min=-1077, Max=-24, Mean=-727 HU
观察到明显的硬化伪影

# step4

硬化伪影矫正参数的获取。根据之前的作业，获取硬化伪影软件矫正参数，思路大致和之前一致，在此做一些微调：用于矫正的水厚度为0,1,2,…, 20 cm（之前为0 - 30cm），并且做3次拟合（之前为2次拟合）。
![](assets/任务4%20软组织硬化伪影矫正方法/file-20260510121839302.png)

# step5

用获得的硬化伪影矫正参数矫正正弦图，并重建矫正后的正弦图。用窗\[-50 , 50]显示重建所得图像。

| 指标    | 原始     | 矫正后    | 改善     |
| ----- | ------ | ------ | ------ |
| 中心点HU | -130.1 | 48.2   | +178.3 |
| 最大值   | -24.0  | 78.6   | +102.6 |
| 均值    | -727.5 | -689.7 | +37.8  |
- 中心点HU值显著提升，接近真实脑组织（~40-50 HU）
- 图像动态范围恢复
- 对软组织（水等效材料）矫正效果好

# step 6

重建`sgm/sgm_brain_skull.raw`文件，这是一个带有头盖骨的脑部CT正投影数据的模拟。重建参数同`sgm/sgm_brain.raw`。用窗\[-180 , -100]显示重建所得图像。相比于sgm_brain生成的重建图，`sgm_brain_skull`对应 的 重建图的伪影是减轻了还是严重了？
![](assets/任务4%20软组织硬化伪影矫正方法/file-20260510122831520.png)

| 数据   | 脑部区域均值    | 脑部区域标准差  | 伪影程度 |
| ---- | --------- | -------- | ---- |
| 无头盖骨 | -248.6 HU | 229.8 HU | 较轻   |
| 带头盖骨 | -125.6 HU | 305.6 HU | 严重   |
- 带头盖骨的重建图伪影更严重
- 标准差增加：75.9 HU
- 原因：骨头的存在加剧了射束硬化

# step7

利用你在第4问中获取的硬化伪影矫正系数矫正`sgm_brain_skull.raw`文件，并重建矫正后的正弦图。用窗\[-50 , 50]显示重建所得图像。回答问题：利用水获得的矫正系数能矫正骨头产生的硬化伪影吗？为什么？
![670](assets/任务4%20软组织硬化伪影矫正方法/file-20260510123230689.png)


|   指标    | 带骨原始  | 带骨矫正后 |
| :-----: | :---: | :---: |
|   最小值   | -1148 | -1133 |
|   最大值   | 1557  | 2051  |
| 脑部区域标准差 | 305.6 | 390.9 |
- 矫正后标准差反而增加：305 → 391 HU
- 最大值异常升高：1557 → 2051 HU
- 说明矫正产生了新的误差

关键问题： 利用水获得的矫正系数能矫正骨头产生的硬化伪影吗？
答案：❌ 不能
原因分析：
1. 有效原子序数差异
- 水：   Z_eff ≈ 7.4  （H₂O）
- 骨头： Z_eff ≈ 13.8 （含Ca） 
2. 衰减机制不同
- 光电效应截面 ∝ Z^n  (n ≈ 3-4)
- 骨头/水的光电效应比值 ≈ (13.8/7.4)^3.5 ≈ 10倍
3. 能谱依赖性不同
- 水的μ(E)：主要在低能端变化
- 骨头的μ(E)：在整个能谱都有强变化（光电效应主导）
