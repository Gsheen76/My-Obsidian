# ASCII 基础信息

### ASCII 字符分类（0-127）

| 范围      | 类别   | 说明                            |
| ------- | ---- | ----------------------------- |
| 0-31    | 控制字符 | 不可打印，如NULL(0)、LF(10)、CR(13)   |
| 32      | 空格   | 可打印字符的开始                      |
| 33-47   | 标点符号 | ! " # $ % & ' ( ) * + , - . / |
| 48-57   | 数字   | 0-9                           |
| 58-64   | 标点符号 | : ; < = > ? @                 |
| 65-90   | 大写字母 | A-Z                           |
| 91-96   | 标点符号 | [ \ ] ^ _ ` \|                |
| 97-122  | 小写字母 | a-z                           |
| 123-126 | 标点符号 | { \| } ~                      |
| 127     | 控制字符 | DEL                           |
