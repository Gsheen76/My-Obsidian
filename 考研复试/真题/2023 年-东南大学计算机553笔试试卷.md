# 三、编程题

### 1. 对给定的字符串 b，使用 c 来代替 b 中出现的 a 子串。
比如 b 为 I love nanjing, I love China, a 为 love, c 为 like，则替换之后为 I like nanjing, I like China。函数原型为 `void replace(char* b, const char* a, const char* c)`（不可以使用标准模板）。
```c++
#include <iostream>
#include <cstring>
using namespace std;

void replace(char* b, const char* a, const char* c) {
    int lenB = strlen(b);
    int lenA = strlen(a);
    int lenC = strlen(c);
    
    // 统计需要替换的次数
    int count = 0;
    char* pos = b;
    while ((pos = strstr(pos, a)) != NULL) {
        count++;
        pos += lenA;
    }
    
    int newLen = lenB + count * (lenC - lenA);
    char* temp = new char[newLen + 1];
    
    int i = 0;  // b 的索引
    int k = 0;  // temp 的索引
    
    while (b[i] != '\0') {
        bool match = true;
        for (int j = 0; j < lenA; j++) { // 检查当前位置是否匹配子串 a
            if (b[i + j] != a[j]) {
                match = false;
                break;
            }
        }
        
        if (match) {
            // 匹配成功，替换为 c
            for (int j = 0; j < lenC; j++) {
                temp[k++] = c[j];
            }
            i += lenA;  // 跳过 a 子串
        } else {
            temp[k++] = b[i++];
        }
    }
    temp[k] = '\0';   
    strcpy(b, temp);
    delete[] temp;
}
```
