
4. (10分)如何声明和使用虚函数？说明它在多态性中的具体作用和意义。 
```text
虚函数通过基类成员函数前加virtual关键字声明，在派生类中重写该函数。
使用方法是通过基类指针或引用调用虚函数，实现动态绑定。
虚函数在多态中的作用：实现运行多态时，允许统一接口调用不同派生类的实现。当用基类指针指向不同的派生对象时，调用虚函数会根据实际对象类型执行对应版本。
```

5. (10分)说明函数模板（Function Template）和函数模板实例化（function-template specification）的区别和联系。
```text
函数模板是一种通用的函数描述，使用泛型类型参数定义，不生成时即可执行代码，仅作为代码生成的蓝图。函数模板实例化是编译器根据具体类型参数从函数模板生成实际函数的过程，生成的可执行代码成为模板函数。
区别：函数模板是源代码级别的抽象定义，不占用存储空间；函数模板实例化是编译阶段生成的具体函数代码，占用存储空间。
联系：函数模板是实例化的基础，实例化是模板函数的必然结果，通过模板定义一次，编译器根据不同类型需求实例化多次，实现了代码的复用。没有模板函数，就无法进行函数模板实例化。
```

2. （15 分）编写一个程序，利用以下公式计算$\pi$的值，要求小数点后位数尽量达到 计算机可表达的最大范围。$$\pi=4-\frac{4}{3}+\frac{4}{5}-\frac{4}{7}+\frac{4}{9}-\cdots$$
```c++
#include<bits/stdc++.h>
using namespace std;

int main() { // 泰勒展开求pi
    double pi = 0.0;
    double term = 0.0;
    int sign = 1; 
    for (int i = 0 ; abs(term) >= 1e-15 ; i++) {
        term = 4.0 / (2.0 * i + 1.0);
        pi += sign * term;
        sign *= -1; // 切换符号
    }
    cout << fixed << setprecision(15) << pi << endl; // 提高输出精度
    return 0;
}
```

```c++
#include <bits/stdc++.h> // 使用标准头文件
using namespace std;

// 递归函数来找到数组中的最小元素
template<class T>
int findMinRecursive(T arr[], int n, int currentIndex, int minIndex) {
    if (currentIndex == n) 
        return minIndex;
    if (arr[currentIndex] < arr[minIndex])
        minIndex = currentIndex;
    return findMinRecursive(arr, n, currentIndex + 1, minIndex);
}

template<class T>
int findMin(T arr[], int n) {
    if (n <= 0)
        return -1;
    return findMinRecursive(arr, n, 1, 0);
}
```

```c++
using namespace std;    

void SortOne(char str[]) { // 插入排序
    for(int i=1;str[i];i++){
        char temp=str[i];
        int j=i-1;      
        while(j>=0 && str[j]>temp){
            str[j+1]=str[j];
            j--;
        }
        str[j+1]=temp;
    }
}

void SortTwo(char str[]) { // 选择排序
    for(int i=0;str[i];i++){
        int minIndex=i;
        for(int j=i+1;str[j];j++){
            if(str[j]<str[minIndex]){
                minIndex=j;
            }
        }
        swap(str[i],str[minIndex]);
    }
  
}
```
