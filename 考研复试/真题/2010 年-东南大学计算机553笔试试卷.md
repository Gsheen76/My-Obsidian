2. ADT（ Abstract Data Type）是什么？结合“数据抽象”和“信息隐蔽”的概念，谈谈你对 ADT的认识。 
```text
ADT:抽象数据类型，是指一个数据模型以及定义在该模型的一组操作。
定义格式：
ADT抽象数据类型名{
	数据对象：<定义>
	数据关系：<定义>
	基本操作：<定义>
}
数据抽象：对具体事物描述的一个概括，可以将数据的类型的定义和他的实现分开。c++的类是一种数据抽象，类是具有相同属性和服务的一组对象的集合。
信息隐藏：尽可能的隐藏对象的内部细节，对外形成一个边界，只保留有限的对外接口使之与外部发生关系。
c++中的封装就是信息隐藏的一种。
```

3. C++ 中的 const 和 static 有什么作用？说明它们分别在变量、成员函数或全局 作用域中的典型用法和影响。
```text
const：
1.变量
（1）普通变量：必须初始化，编译器会阻止修改，定义只读数据，提高程序安全性。
（2）指针变量：指向常量的指针、指针常量、常量指针。
2.成员函数
用于保证函数不会修改对象的数据。
3.函数参数
用于防止函数修改参数，更常见的是引用参数。
4.全局变量
默认内部链接，只在当前文件可见。

static：
1.局部变量
生命周期整个程序运行期间，只初始化一次，作用域仍然是局部。
2.全局变量
生命周期仅当前文件，生命周期程序运行期间，实现文件私有变量。
3.类成员变量
表示所有对象共享一份数据。
4.成员函数
不属于对象属于类，无 this 指针，只能访问 static 成员。
```

```text
缺点（问题）：友元的正确使用能提高程序的运行效率，但同时也破坏了类的封装性和数据的隐藏性，导致程序可维护性变差。
```

5、 C++ 多态的实现、结合虚函数、动态绑定等概念，简要说明 C++ 实现多态的机制 及要点。 
```text
声明：在基类中声明成员函数时在前面加上关键词virtual。
```

4、 设计并实现一个多项式类 Polynomial，包括构造函数、复制构造函数、析构函数、 赋值函数，实现多项式的加法运算（要求实现两个多项式相加）。 
```c++
#include<bits/stdc++.h>
using namespace std;
const int SIZE = 100 ; //多项式最多 100 项

class Polynomial{
private:
	double coe[SIZE];
	int maxExp;
public:
	Polynomial() { //默认构造函数
        for (int i = 0; i < SIZE; i++)
            coe[i] = 0;
        maxExp = 0;
    }
    Polynomial(const Polynomial& a){ //复制构造函数
	    maxExp=a.maxExp;
	    for(int i=0;i<=maxExp;i++)
		    coe[i]=a.coe[i];
		for(int i=maxExp+1;i<SIZE;i++)
			coe[i]=0;
    }
    ~Polynomial() {} //析构函数
    Polynomial operator=(const Polynomial& a){ //赋值运算符重载
        if(this!=&a){
            maxExp=a.maxExp;
            for(int i=0;i<=maxExp;i++)
                coe[i]=a.coe[i];
            for(int i=maxExp+1;i<SIZE;i++)
                coe[i]=0;
        }
        return *this;
    }
    Polynomial operator+(const Polynomial& a){ //多项式加法
        Polynomial result;
        result.maxExp = max(maxExp, a.maxExp);
        for(int i=0; i<=result.maxExp; i++)
            result.coe[i] = coe[i] + a.coe[i];
        return result;
    }
};
```
