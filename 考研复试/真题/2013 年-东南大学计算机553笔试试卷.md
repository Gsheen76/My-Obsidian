# 一、 简答题 

1. 什么是逻辑错误？什么是语法错误？请举例说明。 
```text
逻辑错误：是指程序能够正常运行，但结果不符合预期的错误。编译器无法检测这类错误，因为语法是正确的。例如：要计算圆的面积，本应使用公式`πr²`，但错误地写成了`2πr`（周长公式）。程序可以运行，但结果永远是错误的值。
语法错误：是指程序违反了编程语言的语法规则，导致编译无法通过。编译器能够检测这类错误。例如：在C++中，语句末尾忘记写分号`;`，或者错误地写成`cout << "Hello"`（缺少分号），编译器会提示错误并拒绝生成可执行文件。
```

2. 控制语句有哪几种？请画出常见几种控制语句的流程图或 UML 图。 
```text
1. 顺序结构：程序按代码书写顺序依次执行，是最基本的流程。流程图表现为一个接一个的处理框，从上到下串联。

2. 选择结构：根据条件判断决定执行路径。
- if语句：流程图呈现为一个菱形判断框，条件为真时走一个分支，为假时走另一个分支（或跳过）。
- if-else语句：双分支结构，真和假各对应不同的处理框。
- switch语句：多分支结构，根据表达式的值跳转到对应的case分支执行。  

3. 循环结构：根据条件重复执行代码块。
- while循环：先判断条件，为真时执行循环体，然后再判断。流程图表现为判断框在前，执行框在后，执行后返回判断框。
- do-while循环：先执行一次循环体，再判断条件。流程图表现为执行框在前，判断框在后。
- for循环：包含初始化、条件判断和循环变量更新三部分，适用于已知循环次数的情况。
```

3. 什么是运算符重载？它如何增强了 C++ 的扩展性？ 
```text
运算符重载:是指赋予 C++ 中已有的运算符（如 `+`、`-`、`<<` 等）新的含义，使其能够用于用户自定义的类类型（如复数、矩阵等）的操作。
它增强了 C++ 的扩展性，主要体现在：
1. 代码直观性：使得用户自定义类型的操作方式与内置基本类型保持一致。例如，可以直接用c3 = c1 + c2来表示两个复数对象相加，而不是调用 `c1.add(c2)` 这种函数调用方式，代码更符合直觉、更易读写。
2. 抽象数据类型的支持：让开发者能够创建出像内置类型一样自然的“类类型”，从而将语言的应用领域扩展到解决特定问题的“领域特定语言”，极大提升了语言的表达能力和灵活性。
```
 
4. 为什么说“继承”是 C++ 面向对象的主要特征之一？请简要说明。 
```text
继承实现了代码复用，派生类可以直接继承基类的属性和方法，建立了类之间的层次关系；
继承是运行时多态的基础，只有通过继承，才能使用基类指针指向派生类，结合虚函数实现动态绑定；
继承支持开闭原则，可以在不修改原有基类的前提下，通过派生类扩展新功能。
```

6. 已知 Person 类包含以下： 3 个数据成员：name, nationality, sex 若干成员函数：构造函数、printName()、printNationality() 等 其中 name 的数据类型为另一个类 Name，Name 类包含 first, middle, last 等并有 相应的打印函数和构造函数。 要求：定义并实现 Person 类与 Name 类的接口，并编写测试。
```c++
#include<iostream>
#include<string>
using namespace std;

class Name {
private:
    string first;
    string middle;
    string last;
public:
    Name(string f, string m, string l): first(f), middle(m), last(l) {}
    void printName() {
        cout << first << " " << middle << " " << last << endl;
    }
};

class Person{   
private:
    Name name;
    string nationality;
    string sex;
public:
    Person(Name n, string nat, string s): name(n), nationality(nat), sex(s) {}
    void printName() {
        name.printName();
    }
    void printNationality() {
        cout << "Nationality: " << nationality << endl;
    }
};

int main() {
    // 创建 Name 对象
    Name myName("John", "Smith", "Doe");
    
    // 创建 Person 对象
    Person person(myName, "American", "Male");
    
    // 测试各种操作
    cout << "Person's name: ";
    person.printName();
    person.printNationality();
    
    return 0;
}
```
