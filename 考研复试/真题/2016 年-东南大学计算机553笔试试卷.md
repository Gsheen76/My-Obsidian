#### 1、 函数从哪里开始执行？ 
```text
在C/C++等编程语言中，程序并不是直接从main函数开始执行的。实际上，程序的入口点要早于main，真正的起始位置是入口函数（如_start）。
当程序运行时，操作系统会加载程序并跳转到这个预设的入口地址。_start函数通常由C运行时库提供，它负责建立程序运行的初始环境，包括：
1. 初始化静态/全局变量。
2. 加载程序运行所需的依赖库。
3. 准备好命令行参数。
```

# 二、 读程序 

#### 1、 题目给出如下代码，请说明它的功能，若输入 This is a test，分析对给定输入的输出结果： 
```c++
#include <iostream> 
#include <iomanip> 
#include <string> 
using namespace std; 
 
int main() { 
    string s; 
    getline(cin, s);    
    string word; 
    cout << setw(6) << "word" 
         << setw(8) << "length" << endl; 
    while (!s.empty()) { 
        if (s.find(" ") == s.npos) { 
            word = s.substr(0); 
            cout << setw(6) << word 
                 << setw(8) << word.length() << endl; 
            break; 
        } 
 
        word = s.substr(0, s.find(" ")); 
        cout << setw(6) << word 
             << setw(8) << word.length() << endl; 
        s.erase(0, s.find(" ") + 1); 
    } 
    return 0; 
}
```
- **输出：**
```c++
  word  length
  This       4       
    is       2
     a       1
  test       4
```
