# 一、 简述 

#### 1. 函数从哪里开始执行？ 
```text
在C/C++等编程语言中，程序并不是直接从main函数开始执行的。实际上，程序的入口点要早于main，真正的起始位置是入口函数（如_start）。
当程序运行时，操作系统会加载程序并跳转到这个预设的入口地址。_start函数通常由C运行时库提供，它负责建立程序运行的初始环境，包括：
1. 初始化静态/全局变量。
2. 加载程序运行所需的依赖库。
3. 准备好命令行参数。
```

#### 2. 给指针初始化的值有哪三种？ 
(1) 赋值为变量的地址
这是最常用的初始化方式，通过取地址运算符&将指针指向一个已存在的同类型变量，使其拥有确定的指向。
```c++
int a = 10;
int *p = &a;  // p指向变量a
```
(2) 赋值为动态分配的内存地址
在堆区申请内存，将返回的首地址赋给指针。这种方式常用于需要灵活管理生命周期的场景。
```c++
int *p = new int;                     // C++语言
```
(3) 赋值为空指针
若暂时没有合法的指向，可将指针赋值为NULL（C/C++）或nullptr（C++11及以后），表示指针当前不指向任何有效的内存位置。这是一种安全的占位方式，便于后续判断和重用。

#### 3. 简述下三种程序控制结构？ 
```text
1. 顺序结构
这是程序中最简单的结构，指代码按照书写的先后顺序逐条执行。在没有跳转或判断的情况下，程序会从上到下、从左到右依次运行每一条语句。
2. 选择结构 
也称为分支结构，程序根据特定条件的真假来决定执行哪一段代码。它使程序具有了判断能力，常见的有if-else语句和switch语句。
3. 循环结构
当需要重复执行某段代码时使用。在满足给定条件的情况下，程序会反复执行特定的代码块，直到条件不成立为止。常见的循环语句有while、do-while和for。
```

#### 4. 用户自定义类型的实体叫什么？ 
```text
用户自定义类型的实体被称为对象。
在面向对象编程或数据结构中，当我们定义了一个类（Class）或结构体（Structure），这仅仅是创建了一个新的数据类型模板，规定了这类数据将拥有什么样的属性和行为。而根据这个模板在内存中开辟空间、创建出的具体实例，就是对象。
```

#### 5. 对象看不到其他对象的实现的属性叫什么？ 
```text
对象看不到其他对象的实现，这种属性被称为‘封装性’或信息隐藏。
封装是面向对象编程的三大核心特性之一。它将对象的数据（属性）和操作数据的方法（行为）绑定在一起，形成一个独立的整体。同时，封装会刻意对外隐藏对象内部的复杂实现细节，仅对外公开一个可控的接口来让其他对象与之交互。
```

#### 6. 实现多态的方法有哪些？ 
```text
1. 函数重载
在同一作用域内，允许多个函数拥有相同的名字，但参数列表（个数、类型或顺序）必须不同。编译器会根据调用时传入的实参类型在编译阶段就确定具体调用哪一个函数。
2. 运算符重载 
赋予已有的运算符（如`+`、`-`）新的含义，使其能够用于用户自定义类型的对象之间的运算，本质上是特殊的函数重载。
3. 虚函数
这是实现运行时多态的核心机制。在基类中使用`virtual`关键字声明函数，并在派生类中对其进行重写。当通过基类的指针或引用调用该函数时，程序会在运行时根据实际指向的对象类型来决定调用哪个版本的函数。
```

#### 7. std::cin、std::cout、std::cerr 三个对象分别代表什么？ 
```text
1. std::cin
代表标准输入流，通常关联到键盘。它配合提取运算符>>使用，用于从输入设备读取数据并存储到变量中。例如，std::cin >> x;会等待用户从键盘输入一个值赋给变量x。
2. std::cout
代表标准输出流，通常关联到控制台屏幕。它配合插入运算符<<使用，用于将数据输出到屏幕显示给用户。这是最常用的输出方式。
3. std::cerr
代表标准错误流，同样关联到屏幕。但它专门用于输出错误信息或诊断信息。一个关键区别是，std::cerr是无缓冲的，这意味着发送给它的信息会立即显示，无需等待缓冲区填满，这对于及时提示程序运行时的错误至关重要。
```

#### 9. 存储类的说明符有哪些？
```text
1. auto
在C++11之前，用于声明自动变量，即局部变量，但现在它主要用于自动类型推导。
2. register
建议编译器将变量存储在CPU寄存器中以加速访问，但现代编译器通常忽略此关键字，已逐渐废弃。
3. static
用于修饰局部变量时，使其生命周期贯穿整个程序运行，但作用域不变；修饰全局变量或函数时，则限制其只能在当前文件中访问。
4. extern
用于声明变量或函数是在其他文件中定义的，常用于跨文件共享全局变量。
5. mutable
用于类的成员变量，即使对象被声明为const，被mutable修饰的成员变量仍然可以被修改。
```

#### 10. 运算符有哪些含义？ 
```text
1. 赋值运算符，如`=`，用于将右侧的值传递给左侧的变量。
2. 算术运算符，如`+`、`-`、`*`、`/`，用于执行基本的数学运算。
3. 关系运算符，如`>`、`<`、`==`，用于比较两个值的大小或是否相等，结果通常为布尔值。
4. 逻辑运算符，如`&&`、`||`、`!`，用于组合或取反布尔表达式，构建复杂的条件判断。
5. 位运算符，如`&`、`|`、`<<`，用于直接操作整数的二进制位。
6. 其他特殊运算符，包括用于取地址的`&`、用于指针成员的`->`、用于条件判断的`? :`以及用于获取字节大小的`sizeof`等。
```

#### 11. 为什么要进行运算符重载？有哪些运算符不能重载？ 
```text
运算符重载的主要目的是让用户自定义类型（如类对象）能够像内置数据类型一样使用运算符，使代码更直观、自然。例如，可以通过重载`+`运算符来实现两个复数对象的加法，直接写`c3 = c1 + c2`，而不是调用`c3 = c1.add(c2)`这种函数形式。这提高了代码的可读性和可维护性，让程序逻辑更贴近人类的思维习惯。
五个运算符禁止重载：
1. `::`（作用域解析运算符）
2. `.`（成员访问运算符）
3. `.*`（成员指针访问运算符）
4. `?:`（三元条件运算符）
5. `sizeof`（类型大小运算符）  
    此外，`=`（赋值）、`[]`（下标）、`()`（函数调用）和`->`（指针访问）虽然可以重载，但必须作为类的成员函数，不能是全局函数。
```

#### 1、 题目给出如下代码，请说明它的功能，若输入 This is a test，分析对给定输入的输出结果： 
```c++
#include <iostream> 
#include <iomanip> 
#include <string> 
using namespace std; 
 
int main() { 
    string s; 
    getline(cin, s);    
    string word; 
    cout << setw(6) << "word" 
         << setw(8) << "length" << endl; 
    while (!s.empty()) { 
        if (s.find(" ") == s.npos) { 
            word = s.substr(0); 
            cout << setw(6) << word 
                 << setw(8) << word.length() << endl; 
            break; 
        } 
 
        word = s.substr(0, s.find(" ")); 
        cout << setw(6) << word 
             << setw(8) << word.length() << endl; 
        s.erase(0, s.find(" ") + 1); 
    } 
    return 0; 
}
```
- **输出：**
```c++
  word  length
  This       4       
    is       2
     a       1
  test       4
```
