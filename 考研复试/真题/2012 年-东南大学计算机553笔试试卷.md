1. 编写语句说明枚举类型是如何定义和使用的。 
```c++
enum 枚举类型名 { 变量值列表 }
```

```text
3) 整数值也不能赋给枚举变量，如确实需要可进行强制类型转换。 
4) 枚举变量可以进行关系运算。
```

3. 一个函数模板（Function Template）和模板函数（Template Function）之间的区别。
```text
函数模板是一种通用的函数描述，使用泛型类型参数定义，不生成时即可执行代码，仅作为代码生成的蓝图。
模板函数则是函数模板实例化而来的具体函数。当编译器遇到对函数模板的调用时，会根据传入的实际类型参数，生成一个具体的函数实例，这个生成的函数就是模板函数。
```

4. 为什么说“继承”是面向对象的主要特征之一？请简要说明理由。 
```text
继承实现了代码复用，派生类可以直接继承基类的属性和方法，建立了类之间的层次关系；
继承是运行时多态的基础，只有通过继承，才能使用基类指针指向派生类，结合虚函数实现动态绑定；
继承支持开闭原则，可以在不修改原有基类的前提下，通过派生类扩展新功能。
```

5. 如何声明并使用虚函数？请说明它在多态性中的作用和意义。 
```text
虚函数通过基类成员函数前加virtual关键字声明，在派生类中重写该函数。
使用方法是通过基类指针或引用调用虚函数，实现动态绑定。
虚函数在多态中的作用和意义：虚函数是实现运行时多态的核心机制。实现运行多态时，允许统一接口调用不同派生类的实现。当用基类指针指向不同的派生对象时，调用虚函数会根据实际对象类型执行对应版本。这增强了代码的灵活性和可扩展性，使程序能够面向抽象编程，而非具体实现。
```

1. 编写程序，求最小公倍数。 输入：一对整数 输出：求出它们的最小公倍数 
```c++
#include<bits/stdc++.h>
using namespace std;

// 求最大公约数
int gcd(int a,int b){
    if(b==0) return a;
    if(a<b) swap(a,b);
    return gcd(b,a%b);
}

// 求最小公倍数
int lcm(int a,int b){
    return a/gcd(a,b)*b;
}

int main(){
    int x,y;
    cin>>x>>y;
    cout<<lcm(x,y)<<endl;
    return 0;
}
```

3. 编写程序，读入一行文本并打印一张表格，显示各单词在文本中出现的次数。 例如：输入 Welcome to C++ world! Happy birthday to you. This is the weather report across the world for tomorrow, talk about it in pairs following the model below. 输出：每个不同单词及其出现次数，格式可自定。结果如 “Welcome” 出现 1 次； “to” 出现 2 次；“C++” 出现 1 次；“world” 出现 2 次；等等。
```c++
#include <iostream>
#include <iomanip>
#include <cstring>
using namespace std;
const int SIZE = 80;
//Welcome to C++ world! Happy birthday to you. This is the weather report across the world for tomorrow, talk about it in pairs following the model below.
int main()
{
    int count[100] = {0};
    char text[SIZE], *temp, words[100][20] = {""};
    cout << "Enter one line of text:\n";
    cin.getline(text, SIZE);
    temp = strtok(text, "!,. \n");

    while (temp)
    {
        int j;
        for (j = 0; words[j][0] && strcmp(temp, &words[j][0]) != 0; ++j)
            ; // empty body

        ++count[j];
        if (!words[j][0])
            strcpy(&words[j][0], temp);

        temp = strtok(0, "!,. \n");
    }

    cout << '\n';

    cout << setw(10) << "Words" << setw(10) << "times" << endl;

    for (int k = 0; words[k][0] && k <= 99; ++k)
        cout << setw(10) << &words[k][0] << setw(10) << count[k] << "\n";

    cout << endl;

    return 0;
}
```

```c++
#include<iostream>
#include<string>
using namespace std;

class Name {
private:
    string first;
    string middle;
    string last;
public:
    Name(string f, string m, string l): first(f), middle(m), last(l) {}
    void printName() {
        cout << first << " " << middle << " " << last << endl;
    }
};

class Person{   
private:
    Name name;
    string nationality;
    string sex;
public:
    Person(Name n, string nat, string s): name(n), nationality(nat), sex(s) {}
    void printName() {
        name.printName();
    }
    void printNationality() {
        cout << "Nationality: " << nationality << endl;
    }
};

int main() {
    // 创建 Name 对象
    Name myName("John", "Smith", "Doe");
    
    // 创建 Person 对象
    Person person(myName, "American", "Male");
    
    // 测试各种操作
    cout << "Person's name: ";
    person.printName();
    person.printNationality();
    
    return 0;
}
```
