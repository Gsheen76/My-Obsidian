#### 1. 求$e^x$的值
要求：$|\frac{x^n}{n!}-\frac{x^{n-1}}{n-1!}|>10^{-7}$ ，已知： $e^x = 1 + \frac{x^1}{1!} + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots$
题意推测：根据级数展开计算 xe，当前后两项之差小于某阈值时终止， 输出计算结果。
```c++
#include<bits/stdc++.h>
using namesapce std;

int main(){
	double x,ans=1.0,temp=1.0;
	cin>>x;
	for(int i=1;;i++){
		double t;
		temp=temp*x/i;
		ans+=temp;
		if(fabs(temp-t)<=1e-7)
			break;
	}
	return 0;
}
```
