### 2. 写出下面程序输出结果（考察引用、传递、运算符顺序）
```c++
#include <iostream>
using namespace std;
int f(int *m, int &n){
    static int a = 10;
    cout << a++ << endl;
    return *m *= a + n; // (大概这样) //2+11
}
int main() {
	int *x, *y;
	x = new int(1);
	y = new int(2);
	f(x, *y);
	cout << *x << ' ' << *y << endl;
	cout << f(y, *x);
	return 0;
}
```
- **输出：**
```text
10
13 2
11
50
```
