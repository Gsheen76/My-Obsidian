### 1. 写出下面程序输出结果（考察switch语句和全局、局部变量）

```c++
#include <iostream>
using namespace std;
int num = 2;
int main(){
	int num=3;
	while (num) {
		switch ( -- num){
			case 2:cout << "first num:" << num << endl;
			case 1:cout << "second num:" << num << endl; break;
			case 0:cout << "third num." << ::mum << endl;
		}
	}
	return 0;
}
```
- **输出：**
```text
first num:2
second num:2
second num:1
third num:2
```
