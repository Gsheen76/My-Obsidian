# 一. 琐碎知识

### 1. 类型命名
```c++
typedef 已有类型名 新类型名表
	typedef double Area,Volume;
	Area a;
	Volume v;

using 新类型名 = 已有类型名
	using Area = double;
```

### 2. 枚举类型enum
```c++
enum 枚举类型名 {变量值列表}
	enum weekday {sun,mon,tue,wed,thu,fri,sat};
```
枚举元素按常量处理，不能对他们赋值；枚举元素具有默认值，以此为：0，1，2，...；

### 3. 汉诺塔
```c++
void hanoi(int n,char A,char B,char C){
	if(n==1) 
		move(A,C);
	else{
		hanoi(n-1,A,C,B);
		move(A,C);
		hanoi(n-1,B,A,C);
	}
}
```
