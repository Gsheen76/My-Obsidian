# My-Obsidian

我的个人 Obsidian 知识库，用于记录学习笔记、研究进展、项目档案与日常维护日志。

## 目录结构

```
├── 笔记/                  # 知识笔记
│   ├── MOC/               # 主题地图（Map of Content）
│   ├── 知识库/            # 全库索引与总览
│   ├── 心得/              # 工具与技巧类速查笔记
│   ├── 研0/               # 研究生入学前学习：CT成像、AI图像恢复等
│   ├── 考研/              # 考研真题与知识整理
│   ├── 日记/              # 日记与项目维护日志
│   └── 我的Markdown笔记规范与模板.md   # 全库写作规范
└── 项目/                  # 项目档案
    ├── Petpet/            # 桌面宠物应用（PyQt5）
    ├── 学习项目/          # 本科阶段 / 研究生阶段的学习与科研笔记
    ├── 实习经历/
    └── 超级英雄/
```

## 内容方向

- **医学影像 / CT 成像**：CT 重建、伪影去除、低剂量 CT 深度学习去噪等论文阅读与实验记录。
- **深度学习与生成模型**：DDPM、流匹配、DETR 等学习笔记。
- **项目实践**：桌面宠物应用 Petpet 的设计、开发记录与发布档案。

## 维护方式

- 全库笔记遵循《[我的Markdown笔记规范与模板](笔记/我的Markdown笔记规范与模板.md)》：统一 frontmatter 元数据、Summary 摘要、标题层级与 `[[双链]]` 关联。
- 每日执行一次维护：检查新增内容是否符合规范、修复不规范之处，并在 `笔记/日记/项目维护日志/` 记录当日维护日志，作为一次 Git 版本记录。
