# 一、课题概述

### 1.1 研究背景

- 智慧教育与课堂行为分析的快速发展
- 传统动作识别模型在真实课堂场景中面临：光照变化、噪声干扰、图像模糊、遮挡等挑战
- 训练数据与测试数据分布偏移导致模型性能下降
- 高斯噪声严重程度5时准确率仅21.3%，接近随机猜测水平

### 1.2 研究目标

通过引入测试时自适应（Test-Time Adaptation, TTA）技术，使模型能够在推理阶段根据测试数据自我调整，恢复因分布偏移而下降的识别性能。

### 1.3 主要成果

- 构建EduAction课堂动作数据集（837段视频，7类动作）
- 训练R(2+1)D模型，干净数据准确率94.47%
- 实现三种TTA方法（TENT、ViTTA、CoTTA）
- 高斯噪声S=5时准确率从21.3%提升至84.6%，提升63.3个百分点

# 三、技术方案

### 3.1 骨干网络：R(2+1)D-18

**核心特点**:
1. **卷积分解**: 将3D卷积(t,d,d)分解为2D空间卷积(1,d,d)+1D时间卷积(t,1,1)
2. **参数效率**: 参数量33M，比传统3D卷积减少约30%
3. **计算效率**: FLOPs约40G，比传统3D卷积减少约40%
4. **预训练**: Kinetics-400预训练权重，迁移学习快速收敛

### 3.2 测试时自适应方法

| 范式   | 方法    | 核心机制             | 计算开销     | 适用场景  |
| ---- | ----- | ---------------- | -------- | ----- |
| 第一范式 | TENT  | BN统计量更新          | 最小（1次前向） | 单样本测试 |
| 第二范式 | ViTTA | 统计量更新+特征对齐+时间一致性 | 较大（梯度计算） | 帧间波动大 |
| 第三范式 | CoTTA | 教师-学生架构+置信度阈值    | 中等（双模型）  | 持续学习  |
  
### 3.3 实验采用的自适应流程

步骤1：输入预处理（帧采样、尺寸调整、归一化）
步骤2：前向传播计算预测置信度$p_{max}$
步骤3：若$p_{max}$<0.8触发自适应
步骤4：重新估计各BN层统计量μ̂、σ̂
步骤5：使用更新统计量再次预测
步骤6：恢复初始状态，处理下一个样本

### 5.2 分布偏移基线评估

**表5-1 Source-Only准确率(%)**

|污染类型|S=1|S=2|S=3|S=4|S=5|平均|
|---|---|---|---|---|---|---|
|亮度变化|93.7|93.3|93.3|92.9|94.9|93.6|
|对比度变化|93.7|94.9|95.3|94.9|93.7|94.5|
|高斯模糊|94.1|88.5|79.1|55.7|37.2|70.9|
|高斯噪声|88.1|77.9|60.1|39.5|21.3|57.4|
|JPEG压缩|94.1|92.9|91.7|87.7|70.8|87.4|
|遮挡|92.5|94.1|92.9|92.1|90.5|92.4|
|**平均**|**92.7**|**90.3**|**85.4**|**77.1**|**68.1**|**82.7**|
**关键发现**:
- 高斯模糊和高斯噪声是主要鲁棒性瓶颈
- S=5时高斯噪声准确率仅21.3%，接近随机猜测
- 亮度/对比度/遮挡影响较小，平均准确率>92%

### 5.3 测试时自适应效果

**表5-2 严重污染条件下TTA效果对比(%)**

| 污染类型 | 严重程度 | Source-Only | TENT | ViTTA | CoTTA |
| ---- | ---- | ----------- | ---- | ----- | ----- |
| 高斯模糊 | S=4  | 55.7        | 87.7 | 87.7  | 87.7  |
| 高斯模糊 | S=5  | 37.2        | 85.8 | 85.8  | 85.8  |
| 高斯噪声 | S=4  | 39.5        | 86.6 | 86.6  | 87.0  |
| 高斯噪声 | S=5  | 21.3        | 84.6 | 85.4  | 84.6  |
**关键改进**:
- 高斯模糊S=5: +48.6个百分点（37.2%→85.8%）
- 高斯噪声S=5: +63.3个百分点（21.3%→84.6%）
- 三种TTA方法表现高度一致（差异<0.5%）

### 5.4 三种方法对比

**表5-4 不同严重程度TTA效果(%)**

|严重程度|Source-Only|TENT|ViTTA|CoTTA|
|---|---|---|---|---|
|S=1|92.7|89.9|89.9|90.1|
|S=2|90.3|89.5|89.5|89.8|
|S=3|85.4|89.1|89.2|89.3|
|S=4|77.1|88.5|88.3|88.4|
|S=5|68.1|87.5|87.7|88.0|
**结论**:
- 三种方法准确率差异<0.5%，核心机制都是BN统计量更新
- 轻微污染（S=1,2）TTA反而有轻微负面影响（-3%）
- 严重污染（S=4,5）TTA效果显著（+10-20%）
- TENT计算开销最小，性价比最高

# 六、主要结论

### 6.1 研究贡献

1. **数据集贡献**: 构建EduAction课堂动作数据集（837段视频，7类动作）
2. **基线建立**: R(2+1)D模型干净数据准确率94.47%
3. **有效性验证**: TTA在严重污染下提升准确率60+个百分点
4. **边界揭示**: TTA在轻微污染下可能引入负面效果（-3%）

### 6.2 实践建议

- **严重污染场景**: 启用TTA，推荐TENT方法
- **轻微波动场景**: 不启用TTA，保持原始模型
- **持续视频流场景**: 可考虑CoTTA方法

### 6.3 研究局限

1. 数据集规模有限（837段）
2. 单样本设置，CoTTA持续学习机制未发挥作用
3. TTA方法同质化，额外机制边际收益有限
4. 轻微分布偏移负面效果未解决
