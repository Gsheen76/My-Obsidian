**An MoE-Driven Unified Image Restoration Framework for Adverse Weather Conditions**

# **一、引言 (Introduction)**

- **背景：** 恶劣天气条件（如雨、雪、雾）严重影响户外视觉系统性能，导致图像质量下降。传统方法多专注于单一天气条件下的图像恢复。
- **问题：** 同时部署多个针对单一天气类型的恢复网络计算和硬件负担大。现有统一网络参数方法在处理不同天气类型独特的退化机制时效果不佳。
- **研究方向：** 采用统一网络参数集恢复多种恶劣天气下退化图像的技术。
- **本文贡献 (Key Contributions)：**
    - 提出 **MUIRF (MoE-Driven Unified Image Restoration Framework)**，一个用于多种恶劣天气条件的 MoE 驱动统一图像恢复框架。
    - 引入新颖的**基于浅层特征的 MoE (CPSM) 引导的通道级参数共享策略**。
    - 提出 **Meta-Vector-Guided Gradient Homogenization (MVGH) 算法**，以缓解任务间梯度冲突。
- **核心思想：** 通过MoE动态选择共享参数，捕获天气通用和特定特征，并通过梯度同质化算法解决多任务学习中的梯度冲突。

# **二、相关工作 (Related Work)**

- **A. 单一天气图像恢复 (Single Weather Image Restoration)**
    - 1. **雨水去除 (Rain Removal)：** 现有方法（如基于对抗学习、残差估计、空间-时间交互）
    - 2. **雾霾去除 (Haze Removal)：** 现有方法（如基于 GAN、大气物理约束、多通道预处理、注意力融合）
    - 3. **除雪 (Snow Removal)：** 现有方法（如基于 CNN、分层语义-几何融合、高层语义特征集成、双树小波变换）
- **B. 多天气图像恢复 (Multi-Weather Image Restoration)**
    - 现有方法（如双注意力框架、两阶段学习机制、Transformer-based 编码器-解码器）
    - 本文方法与现有方法的区别：不依赖粗粒度参数共享，而是引入细粒度通道级参数共享和梯度同质化机制。
- **C. 专家混合 (Mixture-of-Experts, MoE)**
    - MoE 系统：动态激活特定专家模块以实现高效自适应学习。
    - 现有 MoE 应用（如 V-MoE、Soft MoE、MoWE），主要应用于 Transformer 架构。
    - 本文 MoE 应用：针对卷积层设计，自适应决定哪些通道共享参数，哪些保持任务特定。

# **三、方法论 (Methodology)**

- **A. 动机 (Motivation)**
    - **多任务学习 (MTL) 的优势：** 跨任务知识迁移、协同参数更新，通过共享表示学习增强模型泛化能力。
    - **图像退化原因：** 大气散射模型解释了恶劣天气下空气中气候颗粒对光传输的干扰（散射、折射），导致图像质量下降。不同天气（雨、雪、雾）具有独特的粒子光学特性。
    - **MUIRF 的设计目标：** 同时建模天气通用和天气特定退化特征，通过动态门控机制选择合适的通道。
- **B. 基于 MoE 的通道级参数共享策略 (Channel-Level Parameter Sharing Guided by MoE, CPSM)**
    - **任务定义：** N 种天气条件下的图像恢复任务 {Fn}，包含共享参数 (θsh) 和独占参数 (θex)。
    - **现有两阶段 MTL 方法的局限：** 训练时间长、学习分数准确性低、可解释性差。
    - **CPSM 核心机制：**
        - 将每个卷积层视为一个 MoE 系统，每个卷积通道作为一个独立专家。
        - **多头门控函数：** 以原始输入图像提取的**浅层特征**作为输入，计算门控分数。
        - **动态选择：** 门控分数动态决定卷积通道权重参数的共享。
        - **数学表达：**
            - Fshallow = Shallow_Feature_Encoder(x_img)
            - Si = Softmax(Gate_i(Fshallow))
            - Ω(Si[j]) = 1 (if Si[j] ≥ λ), 0 (if Si[j] < λ), λ = β/C
            - Mi = Ω(Si)
            - Wi = Mi * θsh + (1 - Mi) * θex
        - **优势：** 细粒度、通道级共享，更精确的特征选择，更好地捕获归纳迁移和跨任务偏差，增强适应性。使用浅层特征作为引导，避免特征与特定任务之间的紧密耦合，降低任务特定过拟合风险。
        - **浅层特征编码器 (Shallow Feature Encoder)：** 包含五个顺序卷积层，提取原始输入图像特征，计算开销小，通过自适应池化层标准化特征图。
        - **门控函数 (Gating Function)：** 多头门控函数嵌套在每个卷积层中，由浅层特征图引导输出判别分数。
- **C. 基于元向量的梯度同质化算法 (Meta-Vector-Guided Gradient Homogenization, MVGH)**
    - **问题：** 多任务学习中，共享参数因任务优化目标不同而产生梯度冲突。
    - **MVGH 机制：**
        - **计算梯度变化率权重 (RWn,i)：** 根据任务 n 在第 i 次迭代前后梯度范数的变化率来加权。RWn,i = (||G_sh_n,i||^2 / (Σ||G_sh_m,i-1||^2 * ||G_sh_n,i-1||^2))
        - **构建元向量 (Meta Vn,i)：** 将方向向量与变化率权重结合。Meta Vn,i = [RW1,i * g1,i, ..., RWN,i * gN,i]
        - **生成引导方向向量 (Gdi)：** 结合所有任务的元向量并归一化。Gdi = Normalization(Meta V1 + ... + Meta VN)
        - **梯度投影与增强：** 将每个任务梯度 (G_sh_n) 投影到引导方向向量 (Gdi) 上，得到投影分量 (pG_sh_n) 和正交分量 (G_sh_n_perp)。
        - **增强方向分量：** 将投影分量 pG_sh_n 乘以增强系数 α (pG_sh_n = α * pG_sh_n)。
        - **重组与规范化：** 将增强后的投影分量与正交分量合并，并缩放其范数与原始梯度范数一致，得到同质化梯度 (G_sh_n_homogenized)。
        - **冲突缓解：** 促进梯度向量向共同方向收敛，减少方向冲突。
        - **负余弦相似度过滤：** 当任务梯度与引导方向向量的余弦相似度 < 0 时，直接保留原始梯度，避免反向下降。
- **D. 损失函数 (Loss Function)**
    - **单任务损失 (Ln)：**
        - L1 损失 (LL1)：恢复图像与真值图像之间的像素级差异。
        - 深度损失 (Adep||D(Yn) – D(Tn)||1)：通过预训练深度估计网络评估，防止深度失真。
        - 感知损失 (Areg||R(Yn) – R(Tn)||1)：通过卷积神经网络计算，更好地对齐人类图像质量评估。
    - **总损失 (Ltotal)：** 所有任务损失的加权和。Ltotal = Σ wnLn

# **四、实验 (Experiment)**

- **A. 实现细节 (Implementation Details)**
    - 基于 PyTorch 实现，使用 DDP 分布式训练。
    - 采用 U-Net 作为骨干网络。
    - 不同的数据集设置和训练配置（学习率、迭代次数）。
- **B. 基准数据集 (Benchmark Datasets)**
    - Outdoor-Rain (雨、雾霾)，RainDrop (雨滴)，Snow100K (雪，S/M/L 子集)，RESIDE (雾霾，OTS/SOTS)，SPA+ (雨)，RealSnow (雪)，REVIDE (雾霾)。
- **C. 评估指标 (Evaluation Metrics)**
    - PSNR (峰值信噪比)、SSIM (结构相似性指数)、LPIPS (学习感知图像块相似度)、NIQE (自然图像质量评估器)。
- **D. 广泛基准上的比较 (Comparisons on Widespread Utilized Benchmarks)**
    - **1) 数据集设置 1 (Setting1) 下的评估：** 包含 Raindrop、Outdoor-Rain、Snow100K-L。MUIRF 优于大多数 SOTA 方法，包括 Transformer-based 方法，证明了参数共享和梯度同质化策略的有效性。
    - **2) 数据集设置 2 (Setting2) 下的评估：** 包含 Outdoor-Rain、Raindrop、Snow100K-L、RESIDE。MUIRF 在所有数据集和指标上持续优于基线 WGWS，表现出更强的泛化能力。
    - **3) 数据集设置 3 (Setting3) 下的评估：** 包含 SPA+、RealSnow、REVIDE。MUIRF 在真实世界场景下的泛化能力和鲁棒性。
- **E. 消融研究 (Ablation Study)**
    - **1) MUIRF 组件消融研究：** 验证 CPSM 和 MVGH 的独立及组合贡献。结果显示两者均提升性能，MVGH 尤其能缓解梯度冲突，加速训练收敛。
    - **2) CPSM 中参数共享方案消融研究：** 比较“全任务共享”与 CPSM。CPSM 的动态通道选择机制提供了更高的灵活性和准确性。
    - **3) MoE 中门控输入类型消融研究：** 比较深层特征、层输入特征和浅层特征作为门控输入。浅层特征作为引导表现最佳，因为它与任务特定语义的纠缠较少。
    - **4) 超参数 β 消融研究：** 验证 β 对通道共享比例和恢复性能的影响。β=1 达到最佳权衡。
    - **5) 超参数 α 消融研究：** 验证 α 对梯度同质化效果的影响。α=1.2 表现最佳。
    - **6) 特征表示消融研究：** t-SNE 可视化证明 MUIRF 能够学习天气通用和天气特定的特征。
    - **7) 恢复图像对下游视觉任务的影响：** 使用 YOLOv10 进行目标检测，MUIRF 恢复的图像显著提升了检测准确性。

# **五、结论 (Conclusion)**

- **总结：** MUIRF 是一个 MoE 驱动的统一图像恢复框架，通过新颖的参数共享策略和梯度同质化机制，有效平衡了鲁棒性和准确性，在多个基准上实现了出色的图像恢复。
- **优点：** 减少模型参数冗余，提供可扩展的多任务图像恢复范式。
- **局限性：** 卷积网络的固有局部性限制，在处理全局特征（如整体对比度、亮度）显著退化的场景下（如大雨、雾霾）存在局限。
- **未来工作：** 结合基于 Transformer 的架构，以联合建模局部细节和全局依赖，进一步提升恢复质量和适用性。
