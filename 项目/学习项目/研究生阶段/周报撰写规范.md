# 周报撰写规范

> [!summary] Summary
> 每周一篇、双格式交付（Obsidian md + Word）、固定四段模板、量化成果、问题具体、计划带目标与时间。写之前先读本规范。

## 1. 频率与覆盖范围

- **每周一篇**，覆盖本周一至周五的工作；周五晚或周末完成。
- 周次编号 `WXX` 从学期起连续递增（W01 = 2026-08-28 那周），跨假期不停号，是否撰写按导师要求。

## 2. 双格式与存放位置

| 格式 | 文件名 | 位置 |
|---|---|---|
| Obsidian md | `周报-YYYY-MM-DD.md`（日期=周五） | `项目/学习项目/研究生阶段/周报/` |
| Word | `2026-秋季-WXX_潘耀辉_周报.docx` | `D:\资料\研究生阶段\周报\` |

- md 版按 Obsidian 笔记规范写：frontmatter（`type: diary`、tags、summary）+ Summary callout，双链相关项目文档。
- Word 版结构严格对齐 `周报模板.docx`，由脚本生成（可交给 AI 助手，模板脚本在 `D:\projects\condconv\tools\` 下维护），生成后跑 postcheck 校验。

## 3. 固定模板（四段，顺序不可变）

```
抬头：周 报 / 姓名：潘耀辉 / 时间：YYYY年MM月DD日—MM月DD日 / 文件命名说明行

一、本周工作总结
  1. 研究方向/任务N：<主题>
     1.1 工作内容（编号分点，每点一件事）
     1.2 当前进展（已完成：…；进行中：…）
     1.3 实验结果/阶段成果（优先图表和量化数字；无实验则写阶段产物）
二、论文阅读与技术调研
  每条固定字段：名称 / Title / 主要内容 / 研究问题 / 核心方法 / 主要贡献 / 对当前工作的启发
三、当前问题与讨论
  遇到的问题（现象+定位+对策）；需要讨论的问题（要导师拍板的具体决策点）
四、下周工作计划
  表格三列：工作内容 / 目标 / 时间安排
```

## 4. 内容原则

1. **核心是"本周干了什么"**——按成果组织，不按时间流水账；
2. **一切量化**：PSNR/体积/耗时/完成度给数字，实验结果优先表格图；
3. **问题写三件套**：现象、定位过程、对策/规避方案；需要讨论的写清决策选项；
4. **计划可验收**：每项有明确目标和时间安排，下周可对照检查；
5. 涉及项目文档的双链（条件参数体系等），保持知识库联通；
6. 内容素材来源：本周的 Obsidian 文档变更、服务器/本机工作记录、与导师的交流结论。

## 5. 质量自查清单

- [ ] 四段结构齐全、抬头信息正确、WXX 编号连续；
- [ ] md 与 Word 内容一致，双格式都已落位；
- [ ] 成果有数字、问题有对策、计划有目标+时间；
- [ ] 双链了本周更新的项目文档。
