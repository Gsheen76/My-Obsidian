# 医学影像条件转换研究框架

## 一、二维分类

|         | **单物理条件**              | **多物理条件**                                 |
| ------- | ---------------------- | ----------------------------------------- |
| **单模态** | CT 80 kVp → CT 120 kVp | CT 80 kVp + 50 mAs → CT 120 kVp + 200 mAs |
| **跨模态** | CT → MRI               | CT（多条件）→ MRI（多条件）                         |

## 二、核心模态与物理条件

|类别|代表对象|典型条件 / 转换|
|---|---|---|
|**模态**|CT|计算机断层成像|
||MRI|磁共振成像|
||DR|数字X射线摄影|
|**CT 条件**|管电压|80 / 100 / 120 kVp|
||管电流/曝光量|低 mAs / 高 mAs|
||剂量|Low-dose / Normal-dose|
|**MRI 条件**|磁场强度|1.5T / 3T|
||扫描参数|TR / TE / TI|
|**DR 条件**|管电压|不同 kVp|
||曝光量|不同 mAs|

## 三、研究路线

**① 单模态 + 单物理条件**  
→ CT 80 kVp → CT 120 kVp

**② 单模态 + 多物理条件**  
→ CT 80 kVp + 50 mAs → CT 120 kVp + 200 mAs

**③ 跨模态 + 单物理条件**  
→ CT → MRI

**④ 跨模态 + 多物理条件**  
→ CT（kVp + mAs）→ MRI（多参数）

## 四、统一表达

$$
It=G(Is,Ms,Ps,Mt,Pt)I_t = G(I_s, M_s, P_s, M_t, P_t)
$$
其中：

- $M$：模态条件（CT / MRI / DR）
    
- $P$：物理/采集条件（kVp / mAs / 剂量 / 1.5T / 3T / TR / TE / TI）
    
- $G$：条件生成模型
