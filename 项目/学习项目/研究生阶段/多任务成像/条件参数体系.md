# 条件参数体系

> [!summary] Summary
> 统一条件转换框架 $G_\theta(I_s, C_s, C_t) \rightarrow I_t$ 的条件参数最终方案：CT 8 项、MRI 5 项、跨模态模态标识 1 项，按 P0（核心）/P1（扩展）/P2（进阶）分级实施；每项参数均给出图像效应、仿真方法与数据支撑，确保可实现。

## 1. 定位与当前状态

- **任务设定**：以条件可控转换为统一框架，覆盖单模态（CT→CT、MRI→MRI）与跨模态（CT↔MRI）两类转换；模态限定 MRI 和 CT，CT 仅考虑扇束（fan-beam），不含螺旋与 Pitch。
- **本文档作用**：确定条件参数的最终清单。选取标准有三：
	1. 参数对单层图像外观有明确、可学习的影响（能建模、能评价）；
	2. 有仿真路径或公开数据支撑（能构造同解剖多条件的配对训练数据）；
	3. 条件标签可从 DICOM/实验配置自动提取，不依赖人工标注。
- **当前状态**：参数体系已确定（2026-09-02），P0 参数的工具链（XRecon/deeprecon 投影器 + momen_data 噪声与视角降采样脚本）已就位。

## 2. CT 条件参数（8 项）

| # | 参数 | 图像效应 | 仿真/实现方法 | 数据支撑 | 优先级 |
|---|---|---|---|---|---|
| C1 | 剂量水平（mAs/光子数） | 量子噪声水平 | 泊松-高斯噪声模型（`addPoissonNoise2`，factor 即剂量比例），剂量网格 {100%, 50%, 25%, 10%} | Mayo 2016 LDCT 挑战赛（真实 1/4 剂量配对可做零样本验证）、LIDC-IDRI | **P0** |
| C2 | 投影数（视角数） | 稀疏视角条纹伪影 | 全视角（2304）均匀降采样至 {96, 64, 32} 后 FBP | 脚本现成（`momen_data2.py`） | **P0** |
| C3 | 重建核 | 频率响应→锐利度与噪声纹理 | FBP 滤波器族（ram-lak / cosine / shepp-logan / hann）作为商用核代理 | DeepLesion DICOM `ConvolutionKernel` 标签 | **P0** |
| C4 | 扫描几何 | 投影几何、放大率、截断 | 子参数：几何类型（fan-arc / fan-flat / parallel）、SOD、SDD、探测器单元数与尺寸；`projector2d` 参数化构造 | XRecon/deeprecon 支持；实验设定对标 PDF 论文 | P1 |
| C5 | 层厚 | z 向分辨率、噪声、跨层解剖混合 | 3D 体数据 z 向加权平均（1mm→3/5mm），噪声按 $\sqrt{T}$ 比例调整 | Mayo 1mm fullImage 体数据 | P1 |
| C6 | FOV / Matrix / 像素间距 | 空间分辨率、视野截断 | 三者强耦合（pixel_spacing = FOV/matrix），作为一组条件；图像域裁剪+重采样，进阶加投影域探测器截断 | DICOM 标签 | P1 |
| C7 | 管电压 kVp | 能谱→衰减与对比度 | 简化多色仿真：TASMIP 能谱 + 水/骨两材料 μ(E) 加权积分；或单色等效能量缩放 | DeepLesion DICOM `KVP` 标签（80–140） | P2 |
| C8 | 重建间隔 | 仅层间距，不改变单层外观 | z 向重采样；仅 3D/体积任务生效 | DICOM 标签 | P2 |

说明：

- **C1–C3 是核心三件套**，仿真管线（momen_data2.py + XRecon）已完全覆盖，构成阶段一 MVP。
- C4 直接延续 PDF 论文的多几何设定，可与 PDF 正面对比。
- C7 是唯一需要超出单色投影器能力的参数，采用两材料简化多色模型并在论文中明确声明；若工作量过大可降级为"仅等效能量缩放"。

## 3. MRI 条件参数（5 项）

| # | 参数 | 图像效应 | 仿真/实现方法 | 数据支撑 | 优先级 |
|---|---|---|---|---|---|
| M1 | 序列/对比度 | 组织对比（T1/T2/FLAIR/PD/DWI） | 类别条件，真实同被试多序列配对数据直接提供；进阶用 Bloch 方程细分 TE/TR/TI | BraTS（T1/T1ce/T2/FLAIR 同被试）、IXI（T1/T2/PD） | **P0** |
| M2 | 加速倍数与采样模式 | k-space 欠采样混叠伪影 | 原始 k-space 上施加采样 mask（R∈{4, 8}，1D uniform / 2D Poisson，含 ACS） | fastMRI（膝/脑，原始 k-space） | **P0** |
| M3 | 分辨率与层厚 | 空间分辨率、体素各向异性 | k-space 高频截断（面内）+ z 向平均（层厚），退路为图像域重采样 | fastMRI / IXI | **P0** |
| M4 | 偏置场 | 强度不均匀 | 低频多项式/随机平滑乘性场叠加（N4 逆过程仿真），强度档位可控 | 任意 MRI 数据可仿真 | P1 |
| M5 | 场强（1.5T/3T） | SNR、T1/T2* 对比度变化 | 同被试配对数据稀缺，仅作弱条件（跨被试评价） | IXI 有 1.5T 与 3T 队列（不同被试） | P2 |

说明：

- **MRI 条件的可控性天然弱于 CT**（强度无物理标定，机器/线圈差异可大于参数差异），因此 MRI 任务的评价以 SSIM/LPIPS 与下游分割一致性为主，逐像素强度误差仅作参考。
- M1 用真实配对数据（同被试不同序列）做监督，是 MRI 侧最可靠的条件轴；TE/TR/TI 的显式数值仿真需要定量参数图（T1/T2 map），真实数据少，列为进阶项。

## 4. 跨模态条件（1 项）

| # | 参数 | 说明 | 数据支撑 | 优先级 |
|---|---|---|---|---|
| X1 | 模态标识 + 目标序列 token | 模态（CT/MRI）作为条件一部分；目标为 MRI 时附加序列 token（指向 M1 类别）；方向含 CT→MRI 与 MRI→CT（sCT，评价 MAE_HU） | SynthRAD2023（配对配准 MR-CT，胸/腹/头） | **P0**（跨模态任务） |

- 跨模态不存在前向物理模型，数据策略是"公开配对数据集 + 潜空间映射"，与单模态的"物理仿真"策略明确区分表述。

## 5. 统一条件编码

- **连续量**（剂量、视角数、加速倍数、FOV、层厚等）：取对数压缩量级 + min-max 归一化，沿用 PDF 论文做法。
- **类别量**（重建核档位、序列类型、几何类型、模态）：embedding。
- **训练时条件随机 dropout（10–20%）**：支持 classifier-free guidance，提升条件可控性与未见组合泛化（对应实验三）。

## 6. 优先级汇总与实施顺序

| 级别 | 参数 | 对应阶段 |
|---|---|---|
| **P0 核心** | C1 剂量、C2 视角、C3 重建核、M1 序列、M2 加速、M3 分辨率、X1 模态 | 阶段一（CT 闭环，工具链现成）→ 阶段二（MRI，公开数据零成本） |
| **P1 扩展** | C4 几何、C5 层厚、C6 FOV/Matrix、M4 偏置场 | 阶段二后半（几何对标 PDF）|
| **P2 进阶** | C7 kVp（简化多色）、C8 重建间隔（仅 3D）、M5 场强、M1 进阶（TE/TR Bloch） | 阶段三，视前两阶段结果取舍 |

## 7. 明确不纳入的参数

- **旋转时间（Rotation Time）**：静态仿真中无图像效应（仅通过运动伪影起作用，需运动模型，超出范围）。
- **Pitch / 螺旋扫描**：任务限定扇束 2D，不做。
- **线圈型号、造影剂时相、床位移**：标签提取难或效应不可控。
- **DWI b 值显式仿真**：需要 ADC 图，数据支撑不足，M1 的 DWI 类别条件已覆盖。

## 8. 条件组合采样策略（实验设计衔接）

- 对每幅源图像，用仿真枚举条件网格，得到**同一解剖结构在 N 个条件下的图像族**——这是仿真独有的严格配对能力，是数据构造的核心卖点。
- 训练对 $(C_s, C_t)$ 采样时随机选取若干条件轴使其不同、其余相同，覆盖单轴与多轴联合变化。
- 实验三（未见组合泛化）：按条件网格划分训练/测试组合集，测试集组合在训练中完全不出现。
