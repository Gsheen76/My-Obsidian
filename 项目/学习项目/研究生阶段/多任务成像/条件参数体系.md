# 条件参数体系

> [!summary] Summary
> 统一条件转换框架 $G_\theta(I_s, C_s, C_t) \rightarrow I_t$ 的条件参数方案：CT 7 项（mAs、电子噪声、视角数、角度范围、探测器 binning、像素比例、kVp），MRI 7 项（加速倍数、ACS 行数、部分 Fourier、分辨率、接收噪声、序列、场强）+ 模态标识；几何固定 fan-arc、统一重建核、仅 2D。

## 1. 定位与设计原则

- **任务设定**：条件可控转换统一框架，覆盖单模态（CT→CT、MRI→MRI）与跨模态（CT↔MRI）；CT 仅做 2D 扇束（fan-arc），几何参数固定。
- **参数入选标准**：① 对单层图像外观有明确可学习影响；② 有仿真路径或公开数据支撑；③ 标签可自动提取。
- **设计决策与理由**：

| 决策 | 理由 |
| --- | --- |
| 剂量以管电流 mAs 为参数（非比例） | 管输出与 mAs 严格线性，物理量直接可查可标定（§2.1） |
| 重建核统一，不作为条件 | 控制变量，聚焦采集侧条件 |
| 仅 2D，不做层厚/重建间隔 | 单层任务下无图像效应，缩小问题规模 |
| 几何固定 fan-arc（SOD/SDD/探测器不变） | 排除几何混杂因素，与参考管线（momen_data2）设定一致 |
| FOV 不单独建模，由像素比例 r 覆盖 | 固定矩阵下两者一一对应，仅差常数 |
| 像素尺寸用虚拟探测器像素比例 r | 无量纲、与绝对几何解耦；固定几何下与 mm 一一对应无信息损失（§2.6） |
| kVp 采用多色能谱仿真 | 唯一能同时改变对比度与束硬化的准确方法（§2.7） |
| MRI 以采样族与场强为核心 | 采样是 MRI 最主要的可控条件；场强决定 SNR 与 T1 对比 |
| 条件轴数量与取值密度尽量加密 | 支撑"多条件联合转换"与未见组合泛化实验（§5） |

## 2. CT 条件参数（7 项 + 1 可选，2D fan-arc）

**固定仿真设定**：fan-arc，SOD = 595 mm，SDD = 1085.6 mm，736 通道 × 1.2858 mm 探测器，512² 图像，统一重建核（FBP cosine），放大率 $M = \mathrm{SDD}/\mathrm{SOD} \approx 1.824$。

| # | 参数 | 类别 | 图像效应 | 仿真成本 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| C1 | 管电流 mAs | 噪声 | 量子噪声水平 | 极低 | **P0** |
| C2 | 电子噪声方差 σe² | 噪声 | 低剂量下噪声底/漂移 | 极低 | **P0** |
| C3 | 投影数（视角数） | 采样 | 稀疏视角条纹伪影 | 中 | **P0** |
| C4 | 扫描角度范围（limited-angle） | 采样 | 边缘缺失/方向性伪影 | 中 | **P0** |
| C5 | 探测器 binning | 采样 | 分辨率↓ 噪声↓ | 中 | P1 |
| C6 | 像素尺寸比例 r | 分辨率 | 空间分辨率/混叠 | 极低 | **P0** |
| C7 | 管电压 kVp | 能谱 | 对比度/束硬化/噪声谱 | 高 | P2 |
| C8 | 环形伪影幅度（探测器增益误差） | 伪影 | 环状条纹 | 低 | P2 可选 |

### 2.1 C1 管电流（mAs）——电流↔光子数对应

- **物理关系**：X 射线管输出与 mAs **严格线性**（TASMIP/TASMICS 能谱按每 mAs 归一化）。
- **映射**：$N_0 = \mathrm{mAs} \cdot \varphi_{\mathrm{det}}(\mathrm{kVp}) \cdot A_{\mathrm{pixel}}$；用 SpekPy v2.0 / spektr 3.0 生成各 kVp 的每 mAs 通量谱制成查找表，校准点取参考设定 I0 = 1e6 对应参考 mAs。
- **网格**：[10, 400] mAs 连续对数均匀采样。
- **实现**：`addPoissonNoise2(p, N0(mAs), factor)`，脚本现成。

### 2.2 C2 电子噪声方差（σe²）

- 与量子噪声**不同源**：量子噪声依赖入射光子（对比度依赖），电子噪声是探测器读出底噪（信号无关、低剂量时占主导），两者叠加规律不同，是独立可学的条件轴。
- **实现**：噪声模型中该参数原为固定值（σe²=10 / N_e=5），放开为条件变量；网格 [0, 50] 连续采样，成本极低。

### 2.3 C3 投影数（视角数）

- 全视角（2304）均匀降采样，视角数在 [48, 2304] 内**连续随机取整数**。
- 实现上视角降采样只需在预生成的完整正弦图上做行抽取，不需要重新投影；每个条件样本随机抽一个视角数后重建即可，连续取值不增加成本。

### 2.4 C4 扫描角度范围（limited-angle）

- 扫描弧段 Θ ∈ [90°, 360°] **连续随机采样**；同样只需在完整正弦图上截取连续视角段，无重新投影成本。
- 与稀疏视角是**不同**的欠采样模式：信息缺失有方向性、伪影形态不同。
- 可与 C3 组合（随机视角数 × 随机弧段），采样族内即构成多条件联合变化。

### 2.5 C5 探测器 binning

- **连续化参数**：等效合并因子 b ∈ [1, 4] 连续采样。物理 binning 只能取整数倍（736 → 368 → 184），条件化时用相邻通道**加权积分**实现任意实数倍合并——物理整数为特例，连续版即"有效探测器采样密度"这一更一般的量。
- 效应：探测器采样变粗（分辨率↓）+ 通道内光子累加（SNR ↑ √b）。与图像域重采样（C6）**不同源**：一个是采集侧、一个是重建侧，二者独立可组合。
- 实现：正弦图相邻列加权求和（噪声按累加规律同步合成）+ 等效 det_size×b 送入 FBP。

### 2.6 C6 像素尺寸（虚拟探测器像素比例 r）

- $r = p_{\mathrm{img}} / (d_{\mathrm{det}}/M)$；固定几何下 $d_{\mathrm{det}}/M \approx 0.705$ mm，参考设定 r ≈ 0.94。
- **用比例而非 mm 的理由**：无量纲、与绝对几何解耦，换设备/几何时语义不变；决定分辨率与混叠的物理量是相对采样密度而非绝对 mm；固定几何下 r↔mm 一一对应，无信息损失（论文报告附 mm 换算表）。
- 实现：重建图像域重采样，r ∈ [0.5, 2.5] 连续采样；编码用 $\log r$。

### 2.7 C7 管电压 kVp（P2）

1. SpekPy / spektr 生成各 kVp（80–140）能谱 S(E)；
2. 源图 HU → 水/骨两基材料分解（阈值 + 分段线性）；
3. NIST XCOM 查 μ(E)；
4. 多色能量积分正投影 $I = \int S(E) e^{-\mu_w(E) l_w - \mu_b(E) l_b} dE$，$p = -\ln(I/I_0)$；
5. 按 C1 的 mAs 加噪（kVp 与 mAs 耦合，N0 查表联定）→ 统一核 FBP。

- 简化退路：等效能量单色近似（不含束硬化，需先验证误差）。
- **连续化取值**：kVp ∈ [80, 140] 连续采样——SpekPy 的 TASMICS 模型本身是插值模型，可生成任意 kVp 的能谱；实现时按 1 kVp 步长预生成能谱缓存，随机 kVp 在相邻缓存间插值，避免逐样本实时算谱。

### 2.8 C8 环形伪影幅度（P2 可选）

- 探测器逐通道增益误差 → 固定角度不变的通道偏置 → 重建出同心环。实现：正弦图乘逐通道随机增益（幅度为条件变量）再重建。成本低、伪影形态独特，增加伪影类条件多样性。

## 3. MRI 条件参数（7 项）

| # | 参数 | 类别 | 图像效应 | 仿真成本 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| M1 | 加速倍数 R + 采样模式族 | 采样 | 欠采样混叠伪影 | 极低 | **P0** |
| M2 | ACS 中心行数 | 采样 | 自校准信息量/伪影残留 | 极低 | **P0** |
| M3 | 部分 Fourier 因子 | 采样 | 共轭对称欠采样伪影 | 极低 | P1 |
| M4 | 分辨率（k 空间截断） | 分辨率 | 空间分辨率/振铃 | 极低 | **P0** |
| M5 | 接收机噪声（SNR） | 噪声 | 复高斯噪声水平 | 极低 | **P0** |
| M6 | 序列/对比度 | 对比度 | 组织对比（T1/T2/FLAIR…） | 数据提供 | P1 |
| M7 | 场强（1.5T/3T） | 对比度+噪声 | SNR、T1 对比度 | 数据受限 | 核心-弱条件 |

- **M1**：fastMRI 原始 k-space 施加 mask，R ∈ [1, 12] 连续随机；mask 族（1D 均匀/变密度、2D Poisson、Equispokes）为类别条件。
- **M2**：ACS 中心行数 [0, 32] 连续——与 R 独立（同 R 下 ACS 越多伪影越轻但有效加速越低），构成采样族内第二根连续轴。
- **M3**：部分 Fourier 因子 [0.5, 1] 连续采样——利用共轭对称只采部分 k 空间，与 R 欠采样伪影形态不同。
- **M4**：k 空间高频置零实现低分辨率，截断比例连续，成本为零。
- **M5**：k 空间加复高斯噪声，σ 连续（等效于 NEX/平均次数：SNR ∝ √NEX）——MRI 的"剂量轴"，与 CT 的 mAs 在类别上对齐。
- **M6**：BraTS 同被试四序列真实配对，类别条件。
- **M7（场强）**：三条候选路线，择一实施——(a) IXI 1.5T/3T 队列跨被试弱标签；(b) HCP 3T/7T 同被试配对子集；(c) 物理近似（SNR ∝ B0、T1 随场强延长 1.3–1.5 倍）。
- 偏置场作为数据增强手段，不占条件轴。

## 4. 跨模态条件（1 项）

| # | 参数 | 数据支撑 | 优先级 |
| --- | --- | --- | --- |
| X1 | 模态标识 + 目标序列 token | SynthRAD2025（配对配准 MR-CT，头颈/胸/腹） | 第二阶段 |

跨模态无前向物理模型，数据策略为"配对数据集 + 潜空间映射"，在单模态框架验证后引入模态条件扩充。

## 5. 条件取值原则：全部连续随机采样

**所有数值型条件轴一律连续随机采样**（整数型轴在取值域内随机取整数），不留离散档位——条件值连续分布是模型学会条件插值、泛化到未见条件的前提（衔接实验三）。类别型条件（mask 族、序列、模态）保持 embedding。

连续化的成本由两个实现技巧消化，离散档位不再必要：

| 技巧 | 覆盖的轴 | 说明 |
| --- | --- | --- |
| 完整正弦图复用 | C3 视角数、C4 角度范围、C5 binning | 每幅源图只投影一次得到 2304 视角完整正弦图；任意视角数/弧段/合并因子都是对它的抽取与加权合并，无需重新投影 |
| 能谱缓存 + 插值 | C7 kVp | 按 1 kVp 预生成 S(E) 与 mAs↔N0 表，随机 kVp 在相邻缓存间插值 |
| 直接连续操作 | C1 mAs、C2 σe、C6 r、M1 R、M2 ACS、M3 PF、M4 截断、M5 噪声 | 加噪/mask/置零/重采样本身就是连续算子 |

每轴取值域汇总：mAs [10, 400]、σe² [0, 50]、视角 [48, 2304]、弧段 [90°, 360°]、binning b [1, 4]、r [0.5, 2.5]、kVp [80, 140]、R [1, 12]、ACS [0, 32]、PF [0.5, 1]、截断比例与噪声 σ 按数据适配。采样分布优先对数均匀（跨越数量级的轴）或线性均匀（比例型轴）。

## 6. 统一条件编码

- 连续量（mAs、σe、r、R、ACS、PF、截断比例、噪声 σ、kVp）：取对数压缩量级 + min-max 归一化；
- 类别量（mask 族、序列、模态）：embedding；
- 训练时条件随机 dropout（10–20%）支持 classifier-free guidance。

## 7. 明确不纳入 / 固定的参数

- **固定**：重建核（统一）、扫描几何（fan-arc，SOD/SDD/探测器固定）；
- **不纳入**：层厚与重建间隔（仅 2D）、FOV（并入 r）、旋转时间与运动伪影（需运动模型）、散射（需散射模型）、Pitch（超范围）、线圈型号、DWI b 值、TE/TR 连续仿真（需定量参数图，由 M6 序列类别覆盖）。

## 8. 条件组合采样策略

- **每幅源图像构造一个条件族**：1 个参考条件（各轴取参考值：mAs_ref、2304 视角、360°、b=1、r≈0.94、σe=0，对应干净图）+ 32–64 个按 §5 分布独立抽取的随机连续条件。参考条件锚定"目标为理想条件"的转换方向。
- 条件族存储为图像栈 `[N+1, 512, 512]`（float16）+ 条件矩阵 `[N+1, 7]`，每张源图一个文件；每图固定随机种子，保证可复现。
- 训练对 $(C_s, C_t)$ **在线配对**：DataLoader 从同一条件族内随机抽两个条件组成样本，不预先落盘（N 个条件的 N² 个对只在内存中出现）。
- 扩数据规模的顺序：**先加源图像数（解剖多样性），再加每图条件数**——同图条件高度相关，每图条件数超过 64 后收益递减。
- 实验三按条件空间划分训练/测试组合，测试组合在训练中不出现。
