# 论文5：CT重建与PDF参数依赖框架

## Abstract 摘要

当前主流的基于深度学习的CT重建方法通常需要固定扫描几何和剂量水平，这极大地增加了训练成本，并需要更多训练数据才能用于实际临床应用。本文提出了一种参数依赖框架（Parameter-Dependent Framework, PDF），同时使用来自多种不同几何和剂量水平的数据训练一个重建网络。在PDF中，几何和剂量水平被参数化后输入两个多层感知机（MLP），MLP的输出用于调制CT重建网络的特征图，从而使网络输出能够适应不同的几何和剂量水平。实验表明，该方法与针对特定几何和剂量水平单独训练或混合数据训练的原始网络相比，能取得具有竞争力的性能，从而有效节省针对多几何、多剂量水平的额外训练成本。

## 1. Introduction 引言

CT扫描存在辐射风险。依据ALARA（as low as reasonably achievable）原则，可通过降低X光管电压/电流（低剂量技术）或减少采样视角数（稀疏视角技术）来降低辐射剂量，但两者都会严重降低成像质量，因此如何以更低剂量获得高质量重建一直是研究热点。

- **迭代重建算法**：压缩传感理论引入后，基于ℓ1范数的迭代方法被广泛使用。Yu等和Sidkii等首先采用离散梯度ℓ1范数（即全变分TV）去除噪声和伪影，但临床医学图像不完全满足TV的分段平滑假设，会产生明显块状效应。随后出现了高阶TV（TGV）、冗余字典学习、双字典学习、低秩惩罚、紧框架约束、变换学习等多种正则化模型，但计算成本过高，难以用于真实临床场景。
- **图像到图像（image-to-image）方法**：直接学习噪声图像到干净图像的映射，本质上是后处理方法，代表工作有RED-CNN（残差编码器-解码器卷积网络）、FBPConvNet（FBP+U-Net）、基于DenseNet与反卷积的DD-Net、GAN及感知损失改进等。优点是绕开扫描仪厂商的数据协议，缺点是推理阶段不使用测量数据，数据一致性无法保证。
- **数据到图像（data-to-image）方法**：将投影数据同时输入网络，逐步校正重建结果，精度相对更高。代表工作有AUTOMAP（全连接+卷积层，参数量过大）、结合CT成像物理的稀疏化网络，以及将系统矩阵嵌入网络的LEARN（展开梯度下降）、 primal-dual交互式CNN、投影梯度下降（PGD）变体、ADMM中用CNN替代正则化等。

上述所有网络都用**特定几何和剂量水平**的数据集训练：当测试数据剂量与训练不匹配时，网络性能下降（如用特定剂量训练的LEARN测试其他剂量数据）；几何不匹配则更严重，会导致数据不一致。实际中不同扫描仪几何不同，同一扫描仪在不同扫描任务中也可能使用不同几何和剂量，为每种情况单独训练网络会显著增加训练成本和数据需求。

为此，本文受条件网络（FiLM）启发提出**参数依赖框架PDF**：将几何和剂量水平参数化后送入MLP，用MLP输出调制重建网络的特征图，使一个统一网络适应多种扫描配置。该框架可应用于图像到图像和数据到图像两类方法，任意重建网络均可作为backbone；对数据到图像模型，扫描几何参数随投影数据一起送入模块，实时计算投影/反投影，实现动态的数据域到图像域映射。

## 2. Methodology 方法

### 2.1 参数化几何与剂量水平

现有深度学习模型可表示为 `x* = F(x; θ)`，其中 `x ∈ R^N` 是在特定几何 `ς` 和X射线强度 `I0`（与剂量水平相关）下由投影数据 `y ∈ R^M` 重建的噪声图像，`F` 是参数为 `θ` 的重建网络。原始网络的参数只针对特定 `(ς, I0)` 优化；一旦噪声水平变化，结果取决于模型鲁棒性、不可预测；对数据到图像方法（AUTOMAP、LEARN、3pADMM等固定输入尺寸或固定系统矩阵），几何不匹配时网络直接无法工作。

PDF将几何和剂量水平参数化为特征向量 `λ = P(ς, I0)` 并送入网络：

1. 拼接扫描参数得到向量 `λ̃ = (ς, I0)`；
2. 对量级较大的参数（视角数、探测器bin数、X射线强度等）取对数以压缩量级，得到 `λ̄`；
3. 按 `λ̄i` 的最小/最大值归一化，得到最终的 `λ`。

网络优化目标为最小化混合数据上的损失，其中条件网络 `Fc` 训练好后，重建性能随 `λ` 变化。

### 2.2 FiLM特征调制

条件归一化（CN）是实现"不同条件下不同网络行为"的常用手段：CBN用MLP得到的嵌入向量做条件BN；AdaIN用风格图像参数实现风格迁移。Perez等证明归一化后直接做仿射变换并非严格必要，提出了更一般的**特征级线性调制（FiLM）**，并指出免归一化形式适用范围更广。本文采用FiLM对网络进行条件化：

- 设第 `l` 层特征图为 `f^l ∈ R^(W×H×C)`，将 `λ` 送入两个MLP `hβ`、`hγ`，得到后验参数 `β ∈ R^C` 和 `γ ∈ R^C`；
- `β` 和 `γ` 是重建网络在特定扫描策略下学习到的后验信息，按通道对特征图做逐通道乘加调制：`f̃^l = β ⊙ f^l + γ`，使滤波器适应该扫描策略下的数据分布；
- 若网络中存在通道数不同的特征图，需要多组MLP；多组MLP之间共享参数以方便训练、节省内存。

## 3. Experiments and Results 实验与结果

### 3.1 实验设置

- **数据集**："2016 NIH-AAPM-Mayo Clinic低剂量CT挑战赛"，含10名患者共5936张全剂量CT图像；从8名患者中随机选400张作为训练集，剩余2名患者中选100张作为测试集。
- **扫描协议**：训练图像平均分为5组，每组使用不同几何和剂量水平模拟投影数据（表I），`I0 = 1e6` 视为正常剂量；#2、#4、#5因视角数太少、不满足FBP采样频率要求，视为稀疏视角情况。加入泊松噪声和电子噪声（方差固定为10）模拟低剂量情形。
- **对比模型**：
	- PDF-based RED-CNN / PDF-based LEARN：用五种几何-剂量混合数据训练的PDF版本（RED-CNN代表图像到图像方法，LEARN代表数据到图像方法）；
	- RED-CNN / LEARN：分别用五组数据单独训练，得到5个模型；
	- RED-CNN-MIX / LEARN-MIX：用混合数据训练的原始网络（无调制）。
- **训练细节**：PyTorch，Intel i5-8400 + GTX 1080Ti；MSE损失，Adam优化器，学习率 `1e-4`；RED-CNN/RED-CNN-MIX/PDF版迭代8000/40000/40000次，LEARN系列相同。PDF版LEARN中投影/反投影算子用CUDA实现；平衡参数 `α̃` 按经验阈值裁剪以保证训练稳定。

### 3.2 PDF-Based RED-CNN（图像到图像）

- RED-CNN为编码器-解码器结构并带残差连接；PDF版用三对MLP分别调制编码层、解码层和输出层（图3中以不同颜色区分）。
- **视觉结果**：RED-CNN结果略模糊，噪声伪影大时细节丢失；PDF版在#1、#5与RED-CNN视觉相当，在#2、#3结构恢复更好，整体噪声和伪影抑制能力更强，但可能过度平滑结构信息（#4中蓝箭头区域）。RED-CNN-MIX因为要训练统一网络均衡处理不同噪声/伪影水平的数据，性能劣于两者。
- **定量结果**：在所有几何和剂量水平上，PDF版RED-CNN的PSNR和SSIM均优于RED-CNN和RED-CNN-MIX，说明一个模型即可处理所有情况。
- **训练动态**：所有模型收敛快速稳定、无过拟合（80个样本即可拟合）；PDF版收敛最快。RED-CNN-MIX虽也用混合数据但性能不佳，支持"简单混合不同噪声/伪影分布的数据扩充训练集并不能提升网络性能"这一推断。

### 3.3 PDF-Based LEARN（数据到图像）

- LEARN将求解CT重建目标函数的梯度下降算法展开为网络，正则化项由CNN模块实现；PDF版用三对MLP调制每次迭代中的三个卷积层，并对平衡参数 `α` 也进行调制（裁剪经验阈值防止训练崩溃）。
- **视觉结果**：低剂量情况#1、#3三者性能相似，转移灶等结构保留良好；稀疏视角情况#2、#4、#5中LEARN和LEARN-MIX无法完全消除伪影，PDF版伪影抑制明显更好、结构更清晰。混合训练使PDF版更鲁棒，LEARN-MIX则比LEARN更模糊、性能无法超越LEARN。
- **定量结果**：低剂量情况下PDF版与LEARN、LEARN-MIX性能相近（训练效率大幅提升的前提下可接受）；稀疏视角数据上PDF版远优于两者，证明框架能增加数据多样性、在数据不足时显著提升性能。ROI均值/标准差分析也显示PDF版最接近真实值。

### 3.4 对未见扫描协议的泛化

用训练好的网络测试两组**未包含在训练集中**的新几何和剂量水平（表IV）：PDF版RED-CNN无法恢复结构；PDF版LEARN稳定性较好，但仍不理想。原因是训练涉及的扫描协议太少、无法覆盖整个采样空间。不过即使对未知扫描协议，PDF版网络仍然优于原始版本。

## 4. Discussions and Conclusion 讨论与结论

- 现有CT重建网络对不同几何和剂量水平的泛化能力弱，需要针对不同设备/任务训练多个模型，严重增加数据量和训练成本。PDF通过FiLM特征调制将重建网络条件化到不同扫描配置，一个统一模型即可达到与特定几何-剂量模型相媲美的性能，某些情况下甚至超过原始版本。
- 作者认为特征图调制的引入可视为一种**特殊形式的数据增强**：原始网络用混合数据集训练时只有固定参数去应对更广的目标数据，本质上加剧了对更大训练集的需求；而PDF用一个统一模型提升了可接受数据类型的数量和多样性，在训练数据不足时显著提升重建性能。
- **局限**：对训练集中未包含的数据类型仍难取得满意结果；LEARN对步长敏感，阈值需经验固定；实验仅考虑扇束情形，图像厚度固定未纳入参数化；实际临床场景的参数化设置需根据实际需求进一步考虑。
- **未来工作**：引入元学习，让MLP准确学习"扫描协议参数 → 特征图后验分布"的映射，从而对训练阶段未涉及的几何和剂量水平也获得满意结果；扩展采样空间并训练神经网络来确定步长阈值。

## 总结

PDF的核心思想是**把扫描配置当作网络的条件输入**，而非数据集的隐含属性：

1. **问题**：主流深度学习CT重建网络绑定特定几何和剂量水平，换配置就需重训，成本和数据需求随配置数线性增长；简单混合多配置数据训练（-MIX）反而劣于单独训练。
2. **方法**：将几何和剂量水平经取对数+归一化参数化为特征向量 `λ`，送入MLP得到逐通道调制参数 `β`、`γ`，用FiLM方式调制重建网络每层特征图；框架与backbone无关，图像到图像（RED-CNN）和数据到图像（LEARN）方法均可套用。
3. **效果**：单一PDF模型在5种几何-剂量配置上达到与单独训练模型相当甚至更优的PSNR/SSIM，收敛更快，训练成本大幅降低；混合训练+调制的收益可视为一种数据增强，在数据不足时尤其有效。
4. **不足**：对训练集中未见过的扫描协议泛化仍有限，需结合元学习等手段扩展覆盖空间。

### 关键概念

- **PDF（参数依赖框架）**：将扫描几何和剂量水平参数化后条件化重建网络的统一训练框架。
- **FiLM（特征级线性调制）**：用条件信息经MLP生成逐通道仿射参数 `β`、`γ`，对特征图做 `β ⊙ f + γ` 调制的条件化技术。
- **低剂量CT / 稀疏视角CT**：分别通过降低X射线强度和减少采样视角数降低辐射剂量的两种手段，均会降低成像质量。
- **图像到图像 / 数据到图像**：两类深度学习CT重建范式，前者做图像域后处理（RED-CNN），后者将投影数据与系统物理嵌入网络（LEARN）。
- **参数化**：对扫描参数做拼接、取对数压缩量级、再归一化，得到网络可用的条件特征向量。
