# 项目文件管理规范

> [!summary] Summary
> 项目代号 **mcond**（multi-condition conversion，多条件可控转换）。目录骨架与命名规则如下，本地与服务器分工明确；新文件落盘前先查本规范。

## 1. 目录骨架

**原则：代码进 home，数据进 /data；本地一个项目一个根目录。**

```
本地  D:\projects\mcond\                     服务器
├── data\        原始数据（只进不改）         /data/panyh/mcond/data/mayo_ldct/   ← 原始 DICOM
│   └── mayo_ldct\                          /data/panyh/mcond/work/              ← 大体量中间产物
├── work\        中间产物（可再生）             ├── gt/        GT 图池
│   ├── gt\                                  ├── families/  条件族
│   ├── families\                            ├── checks/    验证图
│   ├── checks\                              └── runs/      checkpoint/日志
│   └── runs\                                /data/panyh/mcond/tools/wheels/     ← 离线环境轮子
├── scripts\     管线脚本                    /home/panyh/mcond/scripts/          ← 项目代码
├── tools\                                    ~/python311/                        ← Python 解释器（勿动）
│   ├── server_setup\  上传/安装脚本          ~/server_setup/                     ← 安装日志
│   ├── TIGRE\
│   └── wheels\        环境轮子
└── docs\        指向本规范的指针
```

## 2. 命名规则

1. 目录与文件名：小写字母 + 连字符/下划线，英文为主；中文仅用于文档正文。
2. 可版本化产物（条件族、checkpoint）加后缀 `_vN` 或日期 `YYYYMMDD`，如 `families_20260918/`。
3. 临时文件 `tmp_` 前缀并当日删除。
4. 脚本按管线顺序编号（`01_`、`02_`…），路径默认值指向本骨架，支持环境变量覆盖（统一前缀 `MCOND_`，如 `MCOND_GT_DIR`）。

## 3. 跨项目约定

- 每个新项目一个代号：本地 `D:\projects\<代号>\`；服务器代码 `/home/panyh/<代号>/`、数据 `/data/panyh/<代号>/`。
- 跨项目通用工具才放 `D:\tools\`。
- **规则/管理类文档的正式版本放本 Obsidian 库对应项目目录下**（即本文件），本地项目 `docs/` 只留指针，避免双份维护。

## 4. 关键路径速查

| 内容 | 本地 | 服务器 |
|---|---|---|
| Mayo 原始 DICOM | `data\mayo_ldct\{L006,L012,L019}` | `/data/panyh/mcond/data/mayo_ldct/` |
| GT 图池 | `work\gt\` | `/data/panyh/mcond/work/gt/` |

| 环境轮子 | `tools\wheels\`（+`wheels_add\`） | `/data/panyh/mcond/tools/wheels/` |
| 服务器 SSH | `panyh@10.201.150.232`（密钥已装） | — |

## 5. 服务器环境（离线安装）

```bash
setsid nohup ~/python311/bin/python3 -m pip install \
  --no-index --find-links /data/panyh/mcond/tools/wheels \
  torch numpy pydicom matplotlib einops tqdm h5py scipy tensorboard diffusers accelerate \
  </dev/null > ~/server_setup/pip_install.log 2>&1 &
```

运行管线（服务器）：`cd /home/panyh/mcond/scripts && ~/python311/bin/python3 03_check_sanity.py`
