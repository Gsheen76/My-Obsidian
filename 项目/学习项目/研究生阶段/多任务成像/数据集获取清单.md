## 1. Mayo 2016 NIH-AAPM-Mayo Clinic 低剂量 CT 挑战赛

- **入口**：<https://www.aapm.org/GrandChallenge/LowDoseCT/>
- **流程**：按页面指引提交数据使用申请（个人信息 + 机构 + 导师 + 用途），获批后获取下载链接。
- **要下载的部分**：full-dose 1mm 图像（C5 层厚仿真要 3D 体数据）+ 官方配对的 1/4 剂量真实数据（sim-to-real 零样本验证用）。
- **体量**：约 100 GB。

**用途文案（可直接粘贴）：**

```text
This data will be used solely for non-commercial academic research on
controllable CT image conversion. We are developing a conditional
diffusion model that converts CT images between different imaging
conditions (dose level, projection number, reconstruction kernel,
geometry). The full-dose images serve as source images from which
multi-condition training pairs are constructed via physics-based
simulation, and the real paired quarter-dose data will be used to
evaluate the cross-domain generalization of our method. No data will
be redistributed; all data will be stored on a secured university
research server.
```

## 2. SynthRAD2025（跨模态 MR-CT）

- **入口**：<https://synthrad2025.grand-challenge.org/>（注册 grand-challenge.org 账号后加入挑战并签许可）
- **流程**：注册 → 加入 challenge → 签署 Limited Use License → 获得下载授权。
- **要下载的部分**：三个解剖区域（head-and-neck / thorax / abdomen）的 mr-ct 配对子集；cbct-ct 可一并下载备用。
- **体量**：约 300 GB，确认磁盘余量后再开。

**用途文案：**

```text
This dataset will be used solely for non-commercial academic research
on cross-modality medical image conversion. We are developing a
conditional diffusion model for controllable CT<->MRI conversion. The
paired and registered MR-CT images will be used to train and evaluate
the cross-modality conversion task. No data will be redistributed; all
data will be stored on a secured university research server.
```

## 3. fastMRI（原始 k-space）

- **入口**：<https://fastmri.med.nyu.edu/>（注册并接受使用条款，获 AWS S3 下载凭据）
- **要下载的部分**：knee single-coil + brain 两个子集（脑部与其他 MRI 数据解剖一致，膝部数据量小可先打通管线）。
- **体量**：子集约 100–200 GB；只下 multicoil train/test，不下 singlecoil 全量。
- **后续自动化**：拿到 S3 凭据后用 aws cli 断点续传，交给我跑后台。

**用途文案（如页面要求描述）：**

```text
Non-commercial academic research on controllable MRI image conversion.
Raw k-space data will be used to simulate undersampled acquisitions
(acceleration factors and sampling masks) so that paired
full-sampled / accelerated images can be constructed for training a
conditional diffusion model. No data will be redistributed.
```

## 4. BraTS 2023（多序列配对）

- **入口**：<https://www.synapse.org/brats>（注册 synapse.org 账号 → 进入项目页接受数据使用条款）
- **要下载的部分**：BraTS-MET / BraTS-SSA 等任一子集即可，关键是同被试 t1/t1c/t2/flair 四序列 + 分割标注。
- **后续自动化**：装 `synapse` CLI，用个人 token 直接命令行拉取。
- **注**：若只要多序列转换而不要病灶标注，2021 版（<https://www.synapse.org/#!Synapse:syn27046444>）数据更干净，二选一即可。

## 5. LIDC-IDRI（第二 CT 源）

- **入口**：<https://www.cancerimagingarchive.net/>，在 TCIA 搜索 LIDC-IDRI 集合页申请访问（受限集合，需签 TCIA 数据使用协议）
- **要下载的部分**：CT 序列（DICOM，含元数据）。
- **体量**：全集合约 300 GB，可只先下 100–200 例打通管线。

## 6. DeepLesion（条件标签来源，可延后）

- **入口**：<https://nihcc.app.box.com/v/DeepLesion>（按页面指引签 Data Use Agreement 后获取下载权限）
- **要下载的部分**：只需 DICOM 元数据中的 `KVP`、`ConvolutionKernel`、`PixelSpacing`、`SliceThickness` 标签和对应少量图像——用于 C7/C3 的条件一致性评价，不必下全量。
- **状态**：P1/P2 阶段才需要，前面五个没批下来之前不用管它。
