## 0. 四篇论文的脉络（先看这张图）

```
离散马尔可夫链    →    连续 SDE   →    连续 ODE/CNF（向量场回归）  →  训练时演化推前分布
 DDPM (2020)      Score-SDE (2020)     Flow Matching (2022)         Drifting (2026)
  T=1000步            连续时间               免仿真训练                   一步生成
 预测噪声 ε         分数 s=∇log p           向量场 v_t                   漂移场 V
  多步采样             PC sampler             ODE求解器                     1-NFE
```

演进主线：
1. **DDPM** 把生成建模成「加噪声 → 去噪声」的有限步马尔可夫链，提出**ε-预测**参数化。
2. **Score-SDE** 把噪声尺度从有限个推广到连续时间 SDE，发现 DDPM/SMLD 都是同一 SDE 的离散化；引入**概率流 ODE** 与 **PC 采样器**。
3. **Flow Matching** 把 SDE 进一步推广到「任意概率路径」的 CNF，证明**条件流匹配（CFM）与边际 FM 梯度等价**，并提出**OT 路径**让轨迹变直，训练/采样更快。
4. **Drifting Models** 反转思路：不靠推理时迭代，而靠训练时 SGD 演化推前分布；通过**反对称漂移场**在 p=q 时归零达到平衡，天然实现**一步生成**。

## 1. 论文1：DDPM — 离散扩散的工程化模板

### 1.1 前向过程（加噪，无学习参数）

固定方差计划 $\beta_1,\dots,\beta_T$（Ho et al. 用 $T=1000$，$\beta_1=10^{-4}$ 线性增至 $\beta_T=0.02$，针对像素值归一到 $[-1,1]$）。每步：

$$q(x_t\mid x_{t-1})=\mathcal{N}\!\left(\sqrt{1-\beta_t}\,x_{t-1},\;\beta_t I\right).$$

记 $\alpha_t=1-\beta_t$，$\bar\alpha_t=\prod_{s=1}^t \alpha_s$。**关键闭式**（用来一步生成训练样本）：

$$q(x_t\mid x_0)=\mathcal{N}\!\left(\sqrt{\bar\alpha_t}\,x_0,\;(1-\bar\alpha_t)I\right).$$

即 $x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon$，$\epsilon\sim\mathcal N(0,I)$。这是后面所有论文一致采用的「加噪训练样本」构造方式。

### 1.2 反向过程（学习参数）

参数化反向链：

$$p_\theta(x_{t-1}\mid x_t)=\mathcal N(\mu_\theta(x_t,t),\,\Sigma_\theta(x_t,t)),\quad \Sigma_\theta=\sigma_t^2 I\;\text{（固定，不学习）}.$$

**两种方差选择**都行（实验相近）：
- $\sigma_t^2=\beta_t$（对 $x_0\sim\mathcal N(0,I)$ 最优）；
- $\sigma_t^2=\tilde\beta_t=\dfrac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t$（对确定性 $x_0$ 最优）。

> **重要工程结论**：学习 $\Sigma_\theta$ 反而让训练不稳定、样本质量变差；固定方差更省心。

### 1.3 ε-预测参数化（核心贡献）

将前向后验 $q(x_{t-1}\mid x_t,x_0)$ 闭式展开：
$$\tilde\mu_t(x_t,x_0)=\frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}x_0+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t.$$

把 $x_0$ 用 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$ 反解，得到与 ε 预测直接挂钩的均值表达式：

$$\mu_\theta(x_t,t)=\frac{1}{\sqrt{\alpha_t}}\!\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\right).$$

**采样公式**（Algorithm 2）：

$$x_{t-1}=\frac{1}{\sqrt{\alpha_t}}\!\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\right)+\sigma_t z,\quad z\sim\mathcal N(0,I).$$

### 1.4 简化训练目标（Algorithm 1）

$$\mathcal L_{\text{simple}}=\mathbb E_{t\sim\mathcal U(1,T),\,x_0,\,\epsilon}\!\left[\big\|\epsilon-\epsilon_\theta\!\left(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\,t\right)\big\|^2\right].$$

> 丢弃权重的结果：**小 t 项被相对降权**（让网络少花时间在「极小噪声」上，多花在「大噪声去噪」上），样本质量反而更好。代价是 log-likelihood 变差，但样本质量是关键。

### 1.5 网络结构与超参

- **Backbone**：U-Net（仿非掩蔽 PixelCNN++），全程 GroupNorm。
- **时间条件**：Transformer 正弦位置嵌入（$\forall t$ 共享参数）。
- **自注意力**：仅在 $16\times16$ 特征图分辨率使用。
- 数据 $\{0,\dots,255\}$ 线性归一到 $[-1,1]$，$x_T$ 近似标准正态（KL $\approx 10^{-5}$ bit/dim）。
- 末端用**离散解码器**：把 $p(x_0\mid x_1)$ 看作以 $\mu_\theta(x_1,1)$ 为中心、每个 bin 宽上的概率（保证是离散数据无损码长）。

### 1.6 与去噪分数匹配的等价性

将式 (12) 与去噪分数匹配目标比较：**ε-预测 ⟺ 多噪声尺度上的去噪分数匹配**；采样过程类似退火 Langevin 动力学。这为论文 2 打下基础。

### 1.7 结论要点

- FID 3.17（CIFAR10），但 NLL 不具竞争力。
- 主要价值在于**作为有损压缩器**：1.78 bit/维 速率、1.97 bit/维 失真；超过一半码长花在人眼不可察觉的细节。
- **渐进有损解压缩**可看作「广义自回归解码」——bit 序列不再按像素，而是按扩散时间。

**调试要点 / 实操 cheat-sheet：**

| 项         | 值                                        |
| --------- | ---------------------------------------- |
| T         | 1000                                     |
| β 调度      | linear, 1e-4 → 0.02                      |
| 已归一化像素    | ∈ [−1,1]                                 |
| 反向方差 σ²_t | 固定 β_t 或 β̃_t                            |
| 网络输出      | 预测噪声 ε（不预测 x0、不预测 μ̃）                    |
| 训练简化目标    | L_simple = E‖ε − εθ(√ᾱ·x0+√(1−ᾱ)·ε, t)‖² |

## 2. 论文2：Score-SDE — 把扩散搬到连续时间

### 2.1 统一的两类先驱方法

- **SMLD**（Song & Ermon 2019）：离散尺度 $\sigma_1<\dots<\sigma_N$，每尺度训分数 $\mathbf s_\theta(x,\sigma_i)$，按 Langevin MCMC 采样。损失 $\sum\sigma_i^2\,\mathbb E[\|\mathbf s_\theta-\nabla\log p_{\sigma_i}(\tilde x|x)\|^2]$。
- **DDPM**（Ho 2020）：离散步 $\alpha_i=\prod(1-\beta_j)$，损失 $\sum(1-\alpha_i)\,\mathbb E[\|\mathbf s_\theta-\nabla\log p_{\alpha_i}\|^2]$。

注意**权重都与扰动核方差成正比**：$\sigma_i^2\propto$ VE 噪声方差；$(1-\alpha_i)\propto$ VP 噪声方差。两者本质都是 **「加权的去噪分数匹配」**。

**DDPM 的 ε 与分数关系**：$\mathbf s_{\theta^*}(\tilde x,i)=-\frac{\epsilon_\theta(\tilde x,i)}{\sqrt{1-\alpha_i}}$。这就是「为什么 ε-预测 = 训练分数模型」。

### 2.2 前向 SDE（一般形式）

$$d\mathbf x=\mathbf f(\mathbf x,t)dt+g(t)d\mathbf w,\quad t\in[0,T].$$
- $\mathbf f$: 漂移；$g$: 扩散系数（标量，不依赖 x）。
- Lipschitz 条件下解存在唯一。
- $p_t$ 表示边缘密度，$p_{0t}(x(t)\mid x(0))$ 表示转移核。

### 2.3 反向时间 SDE（Anderson 1982）

$$d\mathbf x=[\mathbf f(\mathbf x,t)-g(t)^2\,\nabla_{\mathbf x}\log p_t(\mathbf x)]dt+g(t)d\bar{\mathbf w}.$$

**只要知道 score $\nabla\log p_t$，就能反推过程**。

### 2.4 三种具体 SDE

| 名称 | SDE | 对应 |
|---|---|---|
| **VE** | $d\mathbf x=\sqrt{\frac{d[\sigma^2(t)]}{dt}}\,d\mathbf w$ | SMLD 的连续化 |
| **VP** | $d\mathbf x=-\tfrac12\beta(t)\mathbf x\,dt+\sqrt{\beta(t)}\,d\mathbf w$ | DDPM 的连续化 |
| **sub-VP** | $d\mathbf x=-\tfrac12\beta(t)\mathbf x\,dt+\sqrt{\beta(t)(1-e^{-2\int_0^t\beta})}\,d\mathbf w$ | 本文新提，似然好 |

由于都有 **仿射漂移**，转移核 $p_{0t}(x(t)\mid x(0))$ 都是高斯，闭式可算（直接拿来算 score matching 损失）。

### 2.5 训练目标（连续时间）

$$\theta^*=\arg\min_\theta\mathbb E_t\Big[\lambda(t)\,\mathbb E_{x(0),x(t)\mid x(0)}\big\|\mathbf s_\theta(x(t),t)-\nabla\log p_{0t}(x(t)\mid x(0))\big\|^2\Big].$$

权重通常 $\lambda(t)\propto 1/\mathbb E[\|\nabla\log p_{0t}\|^2]$，相当于「按噪声大自适应归一」。

### 2.6 采样方法（关键点，要会选）

**① 通用数值求解器**：Euler-Maruyama、随机 Runge-Kutta 直接积分。
- **祖先采样**（DDPM 式）= VP SDE 的一种特殊离散化。
- **反向扩散采样器**：以前向相同方式离散化反向（对新 SDE 推导友好）。表中略优于祖先采样。

**② Predictor-Corrector (PC) 采样器**：
1. **Predictor**：数值 SDE 求解器，从 $x_i$ 估 $x_{i-1}$。
2. **Corrector**：基于分数的 MCMC（Langevin / HMC）在 $p_{i}$ 处校正边缘分布。
- SMLD = 恒等预测器 + Langevin 校正器（特例）。
- DDPM = 祖先预测器 + 恒等校正器（特例）。
- 实测：reverse diffusion 总是优于 ancestral；同计算量下 PC > Predictor-only > Corrector-only。

**③ 概率流 ODE**（可逆、确定性、似然）：

$$d\mathbf x=\Big[\mathbf f(\mathbf x,t)-\frac12 g(t)^2\nabla_{\mathbf x}\log p_t(\mathbf x)\Big]dt.$$

与原 SDE 共享边际密度 $\{p_t\}$，是 **神经 ODE** 的特例。
- 优点：**精确似然**（瞬时变量变换）、**唯一可识别编码**（前向 SDE 无可训参数）、**自适应步长黑盒 ODE 求解器**可大幅减少 NFE（90%+）而不伤质量。
- 缺点：对纯样本质量，PC 略优于 ODE（见表 1）。

### 2.7 条件生成（重要！多任务成像相关）

修改反向 SDE 即可控制生成：

$$d\mathbf x=\{\mathbf f-g^2[\nabla\log p_t(x)+\nabla\log p_t(y\mid x)]\}dt+g\,d\bar w.$$

关键：**只需估计 $\nabla\log p_t(y\mid x)$**。
- **类别条件**：训练时间依赖分类器 $p_t(y\mid x(t))$（数据 $x(t)\sim p_{0t}(x(t)\mid x(0))$）。
- **Inpainting**：$y$ 是已知子集，$p_t(y\mid x(t))=p_t(\Omega y\mid \Omega x(t))$。
- **Colorization**：在线性变换解耦维度后做条件 inpainting。
- **优势**：用同一个无条件模型即可处理多种逆问题，无需重训。

### 2.8 架构改进要点

- **VE** 架构名 **NCSN++**；**VP/sub-VP** 名 **DDPM++**。
- 加 `cont.` 后缀 = 切换到式 (7) 的**连续训练目标**。
- 改进项：FIR 上/下采样、跳跃连接缩放、BigGAN 残差块、加深网络。
- 最佳：NCSN++ cont. (deep, VE) → 2.20 FID, 9.89 IS（CIFAR10）；首张 1024×1024 score-based 高保真图。sub-VP deep → 2.99 bits/dim。

### 2.9 vs DDPM 一句话总结

> 把 $T$ 步离散链换成连续 SDE → 可用任意采样器、可算精确似然、可条件生成不变模型；DDPM 退化成本框架里 VP SDE 的祖先采样离散化。

## 3. 论文3：Flow Matching — 让 CNF 训得动、采得快

### 3.1 CNF 框架

向量场 $v_t(x;\theta)$ 通过 ODE $d\phi_t/dt=v_t(\phi_t)$ 生成流 $\phi_t$，推前 $p_t=[\phi_t]_\#p_0$。学习目标是让 $p_1\approx q$。

### 3.2 FM 与 CFM（核心！）

**FM 目标**（难算，因为 $p_t, u_t$ 无闭式）：
$$\mathcal L_{\mathrm{FM}}(\theta)=\mathbb E_{t,p_t(x)}\|v_t(x)-u_t(x)\|^2.$$

**条件 FM**（可算，逐样本）：
$$\mathcal L_{\mathrm{CFM}}(\theta)=\mathbb E_{t,q(x_1),p_t(x\mid x_1)}\|v_t(x)-u_t(x\mid x_1)\|^2.$$

**定理 2（最关键！）**：在 $p_t(x)>0$ 条件下：
$$\nabla_\theta\mathcal L_{\mathrm{FM}}=\nabla_\theta\mathcal L_{\mathrm{CFM}}.$$

> 工程含义：**直接用条件目标训，等价于优化边际目标**。和论文 2 的 score matching 同样"逐样本无偏"，但更直接——回归向量场而不绕"分数"。

### 3.3 高斯条件路径

$$p_t(x\mid x_1)=\mathcal N(x\mid \mu_t(x_1),\,\sigma_t(x_1)^2 I).$$

边界条件：
- $t=0$：$\mu_0=0,\,\sigma_0=1$（标准正态先验，所有样本汇聚）；
- $t=1$：$\mu_1=x_1,\,\sigma_1=\sigma_{\min}$（在数据点附近）。

**仿射流**（最常用）：$\psi_t(x)=\sigma_t(x_1)\,x+\mu_t(x_1)$。

**定理 3**：唯一向量场为
$$u_t(x\mid x_1)=\frac{\sigma'_t}{\sigma_t}\!\left(x-\mu_t\right)+\mu'_t.$$

### 3.4 两个特例

#### 示例 I — 扩散向量场（VE/VP 都能写）
- VE 反向：$p_t=\mathcal N(x\mid x_1,\sigma_{1-t}^2 I)$，$u_t=-\frac{\sigma'_{1-t}}{\sigma_{1-t}}(x-x_1)$。
- VP 反向：$\alpha_t=e^{-T(t)/2}$，$p_t=\mathcal N(\alpha_{1-t}x_1,(1-\alpha_{1-t}^2)I)$，$u_t=\frac{\alpha'_{1-t}}{1-\alpha_{1-t}^2}(\alpha_{1-t}x-x_1)$。
- 这些向量场与 score-SDE 中确定性概率流 ODE 的向量场**完全一致**——即 FM 在扩散路径上只是稳定替代的训法。

#### 示例 II — OT 向量场（重点！）
线性插值：
$$\mu_t=t x_1,\quad \sigma_t=1-(1-\sigma_{\min})t.$$
$$u_t(x\mid x_1)=\frac{x_1-(1-\sigma_{\min})x}{1-(1-\sigma_{\min})t},$$
$$\psi_t(x)=(1-(1-\sigma_{\min})t)\,x+t x_1.$$

CFM 损失（**最常用、最易实现版本**）：
$$\mathcal L_{\mathrm{CFM}}=\mathbb E_{t,q(x_1),p(x_0)}\|v_t(\psi_t(x_0))-\big[x_1-(1-\sigma_{\min})x_0\big]\|^2.$$

> 直观：粒子沿**直线以恒速**移动，轨迹最简单，向量场方向不随时间反转 / 不弯曲，最容易拟合 → 训练稳、收敛快、采样 NFE 显著下降。

### 3.5 为什么比扩散强？

| 维度 | 扩散路径 | OT 路径 |
|---|---|---|
| 轨迹形状 | 弯曲、可能回退 | 直线 |
| 训练稳定性 | 中（DSM 噪声大） | FM 更稳 |
| NFE（采样步数） | 大（≥ 100–1000） | 小（可 < 10–20） |
| 似然 | 可但需 ODE | 同上但更快 |

### 3.6 实操

- 求解器：`dopri5`，容差 $10^{-5}$。
- 评估：BPD、FID、NFE。
- 条件采样任务（超分）：低分辨率图作为条件，FM-OT 表现接近或优于扩散。

### 3.7 用 FM 复现一个生成器的最小脚步

```
for iter:
    sample t ~ U[0,1], x1 ~ data, x0 ~ N(0,I)
    psi = (1-(1-sigma_min)*t)*x0 + t*x1           # OT conditional flow
    target = x1 - (1-sigma_min)*x0                # vector field target
    x_t = psi
    loss = ||v_t(x_t; θ, t) - target||^2           # regression
    backprop
sample:
    x0 ~ N(0,I), solve ODE dx/dt = v_t(x;θ) from t=0 to 1   # dopri5/Euler
```

> 此即论文 4+ rectified flow 一类的最小核。**之后做扩散/流模型，都建议默认先上 FM-OT**。

## 4. 论文4：Drifting Models — 把迭代搬到训练时

### 4.1 核心转向

之前三种范式：**推理时**通过迭代更新 $x_{i+1}=x_i+\Delta x_i$ 把噪声压成数据。
漂移模型：**训练时**通过 SGD 更新网络参数，等价地"漂移"了每一个 $\epsilon$ 对应的样本 $x=f_\theta(\epsilon)$。当 $q=f_\#p_\mathrm{prior}\approx p_\mathrm{data}$ 时不再漂移 → 训练完→ **一次前向 = 完整生成（1-NFE）**。

### 4.2 漂移场与反对称

记 $x_i=f_i(\epsilon)$，定义
$$x_{i+1}=x_i+\mathbf V_{p,q_i}(x_i).$$

**命题 3.1**：若 $\mathbf V_{p,q}=-\mathbf V_{q,p}$，则 $q=p\Rightarrow\mathbf V=0$（停止演化）。
> 反对称 = 交换 $p$ 与 $q$ 仅翻转方向。这是「匹配 = 平衡」的关键。

### 4.3 Mean-Shift 式构造（实操核心）

$$\mathbf V_p^+(x)=\frac{1}{Z_p}\mathbb E_{y^+\sim p}[k(x,y^+)(y^+-x)],$$
$$\mathbf V_q^-(x)=\frac{1}{Z_q}\mathbb E_{y^-\sim q}[k(x,y^-)(y^- -x)],$$
$$\mathbf V_{p,q}(x)=\mathbf V_p^+(x)-\mathbf V_q^-(x).$$

化简（双线性）：
$$\mathbf V_{p,q}(x)=\frac{1}{Z_p Z_q}\mathbb E_{p,q}\!\left[k(x,y^+)k(x,y^-)(y^+-y^-)\right].$$

**直观**：每个 $x$ 被数据样本**吸引**、被生成样本自身**排斥**。两者在 $p=q$ 时严格抵消。

**核函数**：$k(x,y)=\exp(-\|x-y\|/\tau)$（$\ell_2$ 距离，温度 $\tau$），用 softmax 实现归一化（logits=$-\|x-y\|/\tau$）。

### 4.4 训练目标（自监督 + 冻结目标）

$$\mathcal L=\mathbb E_\epsilon\!\left[\big\|f_\theta(\epsilon)-\text{stopgrad}\!\big(f_\theta(\epsilon)+\mathbf V_{p,q_\theta}(f_\theta(\epsilon))\big)\big\|^2\right].$$

- 等价于 $\mathbb E[\|\mathbf V\|^2]$（因被 stopgrad）。
- **stopgrad 关键**：因为 $V$ 依赖 $q_\theta$，直接反传不可行，所以用「漂移后位置」作**冻结目标**。
- 实操：同 mini-batch 的生成样本互作负样本，再从数据集采正样本（$N_{\mathrm{pos}}$ 与 $N$ 个）。

### 4.5 特征空间漂移（重要工程点）

$$\mathcal L=\mathbb E\!\left[\|\phi(x)-\text{stopgrad}(\phi(x)+\mathbf V(\phi(x)))\|^2\right].$$

- $\phi$：自监督编码器（MoCo / SimCLR / latent-MAE）。
- 多尺度：$\sum_j$ 跨层级特征 → 更稳、更好。
- **特征编码只在训练用，推理丢掉**（保留一步生成 ）。

> 这一步决定高维图像生成质量。论文 4 表 3 显示 latent-MAE 经分类微调后效果最佳。

### 4.6 CFG 整合（训练时）

设计混合负样本：
$$\tilde q(\cdot\mid c)=(1-\gamma)q_\theta(\cdot\mid c)+\gamma\,p_\mathrm{data}(\cdot\mid\varnothing).$$
对应生成器学到：
$$q_\theta(\cdot\mid c)=\alpha\,p_\mathrm{data}(\cdot\mid c)-(\alpha-1)p_\mathrm{data}(\cdot\mid\varnothing),\quad\alpha=\frac{1}{1-\gamma}\ge1.$$
- **训练时随机采 $\alpha$ 作为条件**；推理时可任意指定，无需重训。
- 这是把 CFG 从推理时引导改为训练时构造负样本的巧妙做法。

### 4.7 ImageNet 256×256 实现要点

| 项 | 值 |
|---|---|
| Tokenizer | SD-VAE，潜空间 32×32×4 |
| 生成器 | DiT-like, patch size 2, adaLN-zero（类条件） |
| 损失特征 | latent-MAE 多尺度 + 可选 SimCLR/MoCo |
| 潜空间 FID | 1.54 |
| 像素空间 FID | 1.61 |
| 推理 NFE | **1** |
| 训练 CFG | 随机 α→ 条件输入 |

## 5. 三个最容易混 / 容易记错的点

1. **DDPM 的 ε 和 Score 的对应**：
   $\mathbf s_\theta(x,t)=-\epsilon_\theta(x,t)/\sqrt{1-\bar\alpha_t}$（VP），别漏了负号和分母。

2. **Score-SDE 反向 SDE 与 Flow Matching ODE 的差别**：
   - 反向 SDE（含 $dt$ 为负）：$dx=[f-g^2\nabla\log p]dt+g\,d\bar w$。
   - 概率流 ODE：$dx=[f-\frac12 g^2\nabla\log p]dt$（系数折半、无布朗）。
   - FM 用的是向量场 $v_t$ 而非 score：在 OT 路径上 $u_t=(x_1-(1-\sigma_{\min})x)/(1-(1-\sigma_{\min})t)$，**别拿 DDPM 的 ε 公式硬套**。

3. **Drifting 的 stopgrad 位置**：
   冻结的是「$x+V$」整段；若误把 $V$ 自己求导进反向，目标塌缩到 $x$，等价于无操作训练 → 模型不学。

## 6. 实操 cheat-sheet（按任务选型）

| 你想做的事 | 推荐 |
|---|---|
| 教科 / 复现 / 对基线最熟悉 | **DDPM** + ε 预测 + linear β |
| 想要连续控制、精确似然、可条件逆问题 | **Score-SDE** + 概率流 ODE / PC |
| ImageNet-class 大规模高质量 + 快采样 | **Flow Matching + OT 路径**（FM-OT） |
| 极致单步推理 / 实时 / 机器人控制 | **Drifting Models** |
| 多任务成像中需要条件信号融合 | 先用 Score-SDE（条件 SDE 已成熟）；若要快，迁移到 Drifting 的 CFG 负样本构造 |
