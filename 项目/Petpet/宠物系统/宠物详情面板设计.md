# 宠物详情面板设计

> [!summary] Summary
> 高频入口的宠物详情面板：左右分栏展示两只宠物的立绘、昵称（可改名）、好感度进度条、等级经验、介绍与套装区；点击即切换宠物，套装面板内直接装备/卸下，未拥有跳商店。

## 背景

当前宠物的信息散落在各处：改名在桌面状态卡、切宠物在商店宠物页、套装在商店套装页、好感度只在记录页出现。用户需要一个聚合入口，且使用频率高，要求入口放在**右键直接弹出的径向气泡菜单**里。

## 决策结论（grilling 2026-09-01，用户逐条确认）

| # | 决策点 | 结论 |
|---|---|---|
| Q1 | 入口 | 右键气泡菜单（`PRIMARY_ACTIONS` 加「宠物」按钮，高频直达）+ 家园场景菜单 |
| Q2 | 形态 | 独立窗口（`CozyProgressWindow` 基类），左右分栏：左栏宠物头像切换，右栏详情 |
| Q3/Q8 | 改名 | 复用现有 `PetNameEditDialog`（与桌面状态卡同款交互） |
| Q4 | 未拥有宠物 | 灰色剪影 + 价格 + 「去商店」按钮（面板即图鉴） |
| Q5 | 切换 | 点击头像即切换（走 `TrayApp.set_active_pet` 全同步链路），当前宠物加「使用中」角标 |
| Q6 | 好感度 | 「好感度 Lv.X」+ 圆角进度条（当前点/升级所需，与记录页同源） |
| Q7 | 套装 | 已拥有：面板内装备/卸下（复用 progression API）；未拥有：价格 + 「去商店」；冰淇凌显示「套装准备中」占位 |
| Q9 | 托盘菜单 | 不动（现状托盘本来就没有商店/成就/记录） |
| Q10 | 等级经验 | 名字下方「Lv.X」+ 细经验条，仅展示不交互 |

## 右栏布局（自上而下）

1. 宠物立绘（`preview` 大图，居中）
2. 昵称 + 铅笔改名按钮；下方一行「Lv.X」+ 细经验条
3. 「好感度 Lv.X」+ 圆角进度条
4. 介绍文字（`description`，包裹换行）
5. 套装区（卡片横排：预览图 + 名称 + 装备/卸下/去商店按钮）

## 视觉约束（沿用 AGENTS.md 锁定风格）

奶油底 `#fff9ee`、珊瑚主色 `#f28f76`、圆角、pill 控件、幼圆字体（走 `petpet/app/fonts.py`）、面板内容居中；窗口不改变其他窗口尺寸。

## 数据与代码事实（探索代理 2026-09-01 核实）

- 好感度：`affection_level` / `affection_points`（state.py），曲线 `min(200, 20+level*10)`（core.py `affection_to_next`）
- 昵称：profile `pet_name`，`PetWindow.set_pet_name`；对话框 `petpet/ui/desktop.py` `PetNameEditDialog(current, callback, parent)`
- 套装：`OUTFIT_DEFINITIONS` 仅 lunch_meat 两套；`outfit_owned` / `equipped_outfit` / `equip_outfit` / `unequip_outfit`（progression/core.py）
- 切换：`TrayApp.set_active_pet(pet_id)`（pet.py，含家窗/聊天/商店全刷新）；商店已有同名按钮可参照
- 头像/立绘：`pet_avatar_path(pet_id)`、manifest `preview` 字段；两只宠物资源齐全
- 窗口基类：`CozyProgressWindow(pet, title, subtitle, preferred_size, shop_theme)`（progression/ui.py）
