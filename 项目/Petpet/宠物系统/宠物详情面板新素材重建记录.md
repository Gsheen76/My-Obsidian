## 本轮实现（`petpet/ui/pet_profile.py` 重写为壳）

- `ART_W/H = 1201×1304`（= background 原生），`_resolve_scale` 上限 1:1、小屏收缩下限 0.55——**用户屏（逻辑 1707×960）放不下 1304 高，实际显示约 0.67 比例**，更大屏幕恢复 1:1。
- `CORNER_RADIUS = 30`（与 base_UI 卡片圆角语言一致）；`WA_TranslucentBackground` + paintEvent `addRoundedRect` 裁剪，四角真透明。
- base_UI 原生比页面高 5px：按宽度等比缩放绘制，底部溢出被圆角裁剪切掉（内容止于 y875 无视觉影响），**避免 5px 纵向压扁**（审查修复）。
- 保留：`pet_profile_snapshot` 数据层（含套装预览路径修复）、`PetProfileWindow(pet, save_state)` + `show_near_pet()` 入口、`configure_name_dialog_factory` 注入位、`refresh()` 空占位（后续轮填充）。
- 删除：旧布局全部（旧素材目录 `ui/pet_profile/` 暂留，待新面板成型后按用户意思清理）。

## 长期规则（用户定，已入 AGENTS.md UI 约定）

**所有按键必须带悬停与点击两态反馈，无例外**——悬停有明显视觉变化（提亮/放大/描边），点击有按压反馈（缩小/变暗/回弹后触发）；贴图按钮缺反馈素材时程序绘制补齐。参考实现：家园胶囊按键两段式反馈（`HomeSceneWindow.BUTTON_PRESS_FLASH_MS/BUTTON_CLICK_DEFER_MS`）。

## 第四轮：减法与放大（同日追加，提交 `a5a1c25`）

## 第五轮：素材还原（同日追加，提交 `f48f4f8`）

用户反馈第四轮的 X「太丑、还原到最开始的样子」。根因：克隆圆钮的裁剪框 (1076,24,78,78) 与真实圆钮 bbox (1090,30,62,63) 偏差 ~14px，把横幅边缘像素裁进副本、又漏掉圆钮柔边，加上奶油盖色补丁——三处修补痕迹叠加导致丑。

**还原方案**：background 与 base_UI **原样绘制**（顶部 X、圆钮 X 都不再擦除/克隆/盖色）；关闭交互改为纯透明覆盖层——悬停白洗（alpha 80）、按压暗洗（alpha 120、微缩）→ 回弹白洗 → 80ms 关闭，两态反馈保留且零像素修改。**教训：烘焙素材上的按键，交互层永远用覆盖洗色，不要克隆/移动/擦除原画。**

验证：全量 **690 passed**（还原断言：两处 X 均可见 38/117 深色像素）；Windows 实测悬停亮度变化 (252,170,144)→(253,196,176)、两段反馈关闭正常；重启 PID 13324。
