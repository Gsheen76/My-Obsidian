# 宠物详情面板布局重设计实施记录

> [!warning] 用户评估：效果一般，本套布局已搁置（2026-09-01）
> 用户将重新上传素材并给出新做法，届时整体替换布局层；本轮提交（`2e59452`，未推送）保留在本地历史可随时回看。快照数据层、切换/装备/改名回调语义与「套装预览路径」bug 修复与新素材无关，预计可继续沿用。


## 背景

用户反馈初版面板 UI 不完美，要求按 `pet_profile` 素材重新设计布局；过程中两轮尺寸反馈：先要求加大 40%（恰好等于艺术稿原生尺寸），再定稿整体缩小 20%（即显示比例 80%）。

## 关键考证：main_panel 是拼贴图不是合成稿

初版与重设计初期都误把 `main_panel.png`（1201×1309）当成完整界面稿。网格锚定逐格分析 + cv2 带掩码模板匹配交叉验证后发现：**它是素材拼贴展示图**——名牌与描述条出现两次、关闭按钮悬在中上部、图标散布；模板匹配中只有 name_plate(0.4) 与 description_bg(0.2) 低误差真命中且都在底部拼贴区。真实可用的组合件只有 `left_panel.png`（297×1007，圆窗+名牌槽+小圆钮位+两处空白胶囊区）与 `outfit_panel.png`（783×314，底板+左侧一张示例卡）。教训：**视觉模型自由描述区域位置不可信，网格逐格 + 模板匹配量化才是定位手段**（已记入 HANDOFF 坑位表）。

## 新布局（艺术稿像素坐标）

- **窗口**：`ART_W/H = 1201×1309` 布局基准，`DISPLAY_SCALE = 0.8` 显示比例 → 961×1047；`_resolve_scale` 小屏收缩（下限 0.55）。
- **左列**（left_panel 放 (36,150)）：圆窗 Ø190 = 选中宠物头像（锁定灰阶）；名牌 = 动态昵称 + edit_icon 改名铅笔；橙色「装备」按钮（equip_button_orange 素材）= 把选中宠物设为当前使用，选中==当前或未拥有时禁用；下方 rename_button 素材改名钮。
- **右列**：自绘标题木牌 + title_text 副标题 + 关闭钮；立绘（idle 全身 + 粉蕾丝站垫）；右上**双宠切换卡**（pet_icon_1/2 圆头像 + in_use_tag 徽章 / 灰阶+未拥有锁 + 动态名），点击仅选中查看，切换动作收敛到装备按钮；信息三行（level/exp/affection 烘焙标签素材 + 数值 + ArtBar + heart 装饰）；description_bg 描述胶囊；outfit_panel 底板承载套装卡（示例卡几何：圆窗 Ø88/名字/按钮位），按钮用 equip_button_orange(装备)/green(卸下)/珊瑚胶囊「商店·N币」。
- **锁定页**：立绘灰阶 + 描述价格提示 + 去商店按钮，按新布局摆位。

## 存量 bug 修复

`pet_profile_snapshot` 组装套装字典时丢弃 `asset_folder/preview_asset` → `_outfit_preview_path` 恒为 None → **初版面板的套装预览图从未显示过**（渲染里卡 1 圆窗的"内容"实为 outfit_panel 自带示例卡透出）。修复：快照保留两字段，新增回归测试 `test_outfit_snapshot_keeps_asset_paths`。

## 双轴审查采纳的修复

关闭按钮图标未按 `_S` 缩放（溢出裁切）；套装「商店·N币」胶囊漏接 `clicked`（死按钮）；`_art_button` 图标比按钮宽 40px（两侧裁切）且语义靠文件名猜（改显式参数）；灰阶转换统一走 PIL+numpy 保 alpha 版（消除 `Format_Grayscale8` 透明变黑坑 + 逐像素慢循环）；paintEvent 标题补 `APP_FONT_FAMILY`；立绘加载回退逻辑去重为 `_load_preview_pixmap`。

未采纳（记录理由）：`name_plate.png`/`pet_1_name.png` 烘焙字素材（宠物可改名，动态文字必须覆盖显示，名牌比例 4.98 与左栏槽位 3.05 不合）；`_S` 模块级全局（沿用既有模式，单窗口场景）；测试 `_window()` 三处重复（跟随既有文件风格）。
