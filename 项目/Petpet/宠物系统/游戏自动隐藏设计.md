# 游戏自动隐藏设计

> [!summary] Summary
> 用户需求（2026-09-08）："检测到有其他游戏启动时自动隐藏，在设置里增加开关"。实现为 `petpet/app/game_guard.py`（win32 前台采集 + 纯函数判定）+ PetWindow 2 秒轮询隐藏/恢复 + 设置页开关 `hide_in_game`（默认开）。当天即被用户真实游戏会话（英雄联盟全屏）验证生效。

## 1. 判定：游戏路径单信号（2026-09-09 收紧定稿）

**唯一信号**：前台进程可执行文件路径命中游戏平台/直装游戏目录关键词（`GAME_PLATFORM_MARKERS`，小写归一匹配）——steamapps、Epic Games、WeGame、Riot、Battle.net、GOG、`\games\`，以及米哈游系（genshin/yuanshen/starrail/honkai/zenless/\mihoyo）、库洛系（wuthering waves/\kurogames）等常见直装目录。再过一道**非游戏程序黑名单**（`NON_GAME_EXES`：浏览器/播放器/PPT/PDF/远程桌面/OBS 等）双保险——黑名单进程即使路径撞上关键词也不算。

**全屏覆盖不再独立触发**（初版双信号之一，2026-09-09 弃用）：用户定稿"只有启动游戏的时候才会隐藏，别的应用不会隐藏"——起因是 ZCode（Electron）全屏使用时被前台全屏覆盖判定误隐藏；黑名单补丁治标不治本（IDE/任意新应用都会漏），遂移除全屏独立信号，`fullscreen_coverage` 保留为诊断函数。窗口化游戏靠路径信号照常触发（与全屏无关）。

排除项不变：自身窗口（winId）、自身进程（sys.executable + 源码目录）、桌面壁纸层（Progman/WorkerW 类）、explorer.exe。

采集与判定分离：`collect_foreground_info()`（win32 ctypes）返回普通 dict，`is_game_present(info, ...)` 纯函数可离线测试；非 Windows 平台采集恒 None → 功能空转。

## 2. PetWindow 状态机

- 2 秒 QTimer（`_game_guard_timer`）→ `_on_game_guard_tick`：游戏中且可见 → `hide_overlays()+hide()` 并置 `_game_auto_hidden=True`；游戏结束且 `_game_auto_hidden` → `show()+raise_()` 清标记。
- **只恢复自己藏的**：手动隐藏走 `set_user_visible(False)`（`_user_hidden` 标记），游戏结束不会把手动藏的小狗拉出来；反之自动隐藏期间用户手动显示/隐藏也不被覆盖。
- `_maintain_desktop_presence`（5 秒存在守卫）新增放行：`_game_auto_hidden` 时不把自动隐藏拉回来。
- 设置 `hide_in_game` 关闭时：停表 + 若正处自动隐藏则立即恢复。

## 3. 设置

`DEFAULT_SETTINGS["hide_in_game"] = True`（旧存档无键默认开）；设置页 `SWITCHES` 一行「游戏中自动隐藏 · 检测到其他游戏运行时藏起小狗，游戏退出后自动回来」，保存即 `apply_runtime_settings → _sync_game_guard_timer` 启停。

## 4. 验证

- **2026-09-09 收紧定稿**：offscreen 全量 **757 passed**（旧双信号断言改写：窗口化平台游戏/直装米哈游=True，全屏未知程序/IDE/浏览器/播放器/PPT/黑名单撞关键词=False）+ 真机探针——ZCode 全屏前台判定 False（改前 True）、宠物保持可见；WeGame 英雄联盟路径单测恒 True
- offscreen 全量 **756 passed**（初版 2026-09-08，新 `tests/test_game_guard.py` 12 条：判定纯函数 6 + 设置默认/往返 + 窗口隐藏/恢复/手动互不打扰/启停）
- Windows 跨进程端到端：独立 pythonw 全屏辅助窗（避开自身进程排除）→ 宠物真隐藏 → 辅助窗退出 → 真恢复，PASS
- **真实会话验证**：重启后用户正在运行英雄联盟（RiotWindowClass 全屏 + WeGame 路径双命中），宠物窗口即全部自动隐藏——功能上线即实战生效
- 设置页截图验收：新开关行与说明文字正常

## 5. 已知边界

- **直装且目录不含已知关键词的游戏检不到**（如独立游戏放在自定义目录）——在 `GAME_PLATFORM_MARKERS` 加一行路径关键词即可（用户可自行提出补充）
- 检测有 ≤2 秒轮询延迟（游戏启动到隐藏最多 2 秒）
- Windows 专用；macOS 端开关可见但空转
