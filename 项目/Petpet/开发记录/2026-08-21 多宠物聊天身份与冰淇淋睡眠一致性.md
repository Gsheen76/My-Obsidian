# 多宠物聊天身份与冰淇淋睡眠一致性

关联：[[Petpet 总档案]]、[[2026-08-21 宠物界面与动画一致性修复]]、[[2026-08-21 家园待机稳定与睡眠尺寸修复]]。

## 需求

- 聊天的助手头像、真实名和人格始终由稳定的 `pet_id` 决定；昵称仅用于展示。
- 午餐肉使用活泼开朗的人格，冰淇淋使用温柔可爱的人格；改名不会串人格。
- 助手回复折叠连续空行，同时保留正常换行；玩家原始文本不变。
- 冰淇淋桌面睡眠复用家园的同一张八帧 spritesheet，以 3 FPS、0.62 缩放和底部锚定播放；午餐肉原有睡眠动画不变。

## 架构决策

宠物注册表是身份的唯一来源：`default_name` 和 `chat_personality` 由 `pet_id` 解析；聊天 API 显式传递 `pet_id`，服务层只组合传入的人格。桌面动画清单声明相对 spritesheet 路径，通用加载器按行优先切帧，不复制睡眠 PNG。

> [!info] 回退与安全边界
> 缺少人格时回退到通用陪伴小狗人格；待机图不可读取时保留既有头像占位。Spritesheet 在完整解码前由 `QImageReader` 预检尺寸，源图上限为 `16_777_216` 像素、帧数上限为 64；元数据、尺寸、裁剪范围或任一空帧/残缺帧非法时，整组动画不缓存并负缓存至资源刷新，界面继续使用当前宠物静态姿势。应用重启留待最终整分支审查并合并至 `main` 后执行，安全源码入口是 `D:\Agent_project\Petpet\pet.py`，工作目录为 `D:\Agent_project\Petpet`。

## 改动

- `assets/runtime/pets/manifest.json`：为午餐肉、冰淇淋登记独立 `chat_personality`。
- `petpet/chat/api.py`、`petpet/chat/service.py`：根据同一个有效 `pet_id` 选择记忆与人格，兼容 `chat(..., pet_id=..., profile=...)`，并按行清理助手回复的空白行及连续空格/制表符。
- `petpet/ui/chat.py`：标题显示“昵称（真实名）”，助手头像读取当前宠物桌面待机图。
- `assets/runtime/pets/ice_cream/desktop/animations/manifest.json`、`petpet/app/pet_window.py`：从家园 spritesheet 裁出八帧冰淇淋桌面睡眠动画，并在解码、切帧和缓存前后实施有界、全有或全无的失败处理。
- `tests/test_ai_config.py`、`tests/test_chat_service.py`、`tests/test_chat_memory.py`、`tests/test_chat_tools.py`、`tests/test_chat_profile.py`、`tests/test_chat_window_boundary.py`、`tests/test_pet_window_boundary.py`、`tests/test_home_window_boundary.py`、`tests/test_sleep_interaction.py`：覆盖人格、兼容 API、文本、真实宠物切换、标题、历史头像、第八帧行优先裁剪、零坐标、资源上限、残缺帧、负缓存与睡眠回退路径。
