# 2026-09-12 四项功能（生日提醒+季节节日+聊天导出+档案导入导出）

> [!summary] Summary
> 用户从「现在有什么可以做的」菜单一次选定四项。核心设计决定：提醒走「重要的事」文本保守匹配（周年关键词+公历月日同时出现才算，防止「3月5日交材料」被误祝贺）；节日只收公历固定日（不算农历，算错日子比没有更糟）；聊天导出/档案导入导出均为本地文件，不碰密钥。

## 1. 生日/纪念日主动提醒

- `memory.py`：`extract_dated_facts`（关键词 `生日|纪念日|周年` × 正则 `(\d+)月(\d+)[日号]`，月日范围校验）、`due_reminder(facts, month, day)`、`reminder_line`（安全引述原话+祝贺）。
- `api.py maybe_nudge` 重排：睡眠/深夜门 → **提醒检查（先于久坐/间隔门槛——一年一次的事必须能冒出来）** → 久坐/间隔门 → 普通池。当日已发记录在 `mem["reminder_fired"] = {fact: "YYYY-MM-DD"}`，随 `save_memory` 持久化。
- 回归注意：旧「池子测试」期望集必须补 `month=9, day=11`，否则新季节行会让断言变随机。

## 2. 搭话季节/节日扩容

- `nudge_lines` 增可选参 `month/day`：命中 `SOLAR_FESTIVALS`（元旦/情人节/劳动节/儿童节/国庆/圣诞）→ 祝福行 `insert(0, …)` 置顶；未命中 → `season_flavor(month)`（3-5 春/6-8 夏/9-11 秋/12-2 冬，各两条）混入普通池。不传参 → 行为与旧四参完全一致（向后兼容）。
- **农历节日明确不做**（春节/中秋不进表）：换算表一旦写错就是用户可见的错误祝贺，等有可靠数据源再说。

## 3. 聊天记录导出

- `memory.py::format_chat_export(entries, pet_display)`：头部宠物名+导出时间，逐条 `[YYYY-MM-DD HH:MM] 我/宠物：内容`，图片条目标 `[图片]`，空历史给占位句。
- `chat.py`：工具行新增「导出」键（FeedbackButton，objectName `exportTool`，置 ⚙ 前），`export_chat_history` 走 `getSaveFileName`（默认名 `Petpet聊天记录_YYYYMMDD_HHMM.txt`，落「文档」目录），成功/失败用 chat_notice 气泡反馈。

## 4. 档案六栏导入导出

- `memory.py::facts_to_json/facts_from_json`：导出 `{"pet", "facts": 六栏}`；导入兼容包裹/裸六栏两种结构，结构不对抛中文 `ValueError`，条目过 `sanitize_edited_facts` 同一张清洗网，未知栏丢弃。
- `memory_profile.py`：底排新增「导出/导入」两键（objectName `profileExport/profileImport`）；导入经 `_apply_facts` 整体重铺 UI（清现行行→逐栏按内容重建，栏头保留），**仍需按「保存」才落盘**——用户保持最终控制权，与既有保存流一致。
