# 2026-09-24 低危清偿四项与每日任务梦境气泡

> [!summary] Summary
> Bug 清欠 + 吸引力更新双轨：§9 低⑪~⑭ 全部清偿后，新增「每日任务」（留存向游戏循环）与「梦境气泡」（氛围彩蛋）两个零素材依赖功能。

## 改动

### 低危清偿（TDD/逐项验证）
- **⑪ 聊天搜索不一致**：`_begin_reply` 发送即清空 chatSearch——搜索是看历史的动作，发消息自然回到实时视图；流式直显→完成又消失的前后矛盾根除。
- **⑫ QTimer 泄漏**：单击去抖定时器在 TrayApp.__init__ 建一次常驻复用（start/stop），不再每击 `new QTimer(self.app)`。
- **⑬ aliyun-chat 限流**：`overLimit` 双滑窗（每装机 ID `RATE_LIMIT_MAX`=20/分、每 IP `RATE_LIMIT_MAX_PER_IP`=120/分，env 可调），实例内 Map 计数，超限 429 `rate_limited`；`node --test` 10/10（含 400 不占额度断言）。
- **⑭ 还原原子性**：`restore_backup_zip` 重写为「整体解包 staging → 存回滚副本 → 逐文件 copyfile+os.replace 原子替换 → 异常回滚」；模拟中途 OSError 测试证明全量回滚。

### 创新甲·每日任务系统
- 池五选三（pettings×5/feedings×1/play_sessions×1/ai_replies×3/gifts_given×1），**日期种子确定性抽样**（同日全员同题，免存 rng 状态）；`ensure_daily_quests` 同日幂等、跨日惰性重置。
- **进度钩子挂 record_action 单漏斗**——喂/摸/玩/聊/礼所有调用点零改造自动累积。
- 领取：`claim_daily_quest`（完成才发 20 币）/`claim_daily_bonus`（三条全领后 +30，一次性）。
- UI：记录页总计 tab 顶部「今日任务」卡（周报卡同款样式；FeedbackButton 三态：进行中禁用/领取+N/已领取）。
- 设计取舍：奖励走 `add_coins` 正规路径；不做「每日签到」独立弹窗（任务即签到，少一层打扰）。

### 创新乙·梦境气泡
- `on_decay` 睡眠分支调 `_maybe_dream`：~2%/tick、120s 冷却、`say()` 自带隐藏门；DREAM_LINES 五条梦话。
- 防护两层：调用点 try(AttributeError, RuntimeError) + 函数体 try(RuntimeError)——氛围彩蛋绝不拖垮 decay；两个测试壳坑（PyQt 壳 getattr 默认值失效、SimpleNamespace 壳无方法）都在这里显形。
