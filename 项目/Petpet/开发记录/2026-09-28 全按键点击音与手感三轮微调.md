# 2026-09-28 全按键点击音与手感三轮微调

> [!summary] Summary
> 用户圈出商店「宠物/家居/礼物」分栏键没有音效，定稿所有可点击按键都要响；同轮三调：回弹加快、按压幅度减小、压暗减淡。全量 1016 passed，真机验证分栏键有声。

## 背景

上一轮点击音只覆盖 FeedbackButton 非 checkable + 家园/贴图键/头像/气泡菜单的显式调用面；checkable 页签按旧规则静音。用户拍商店分栏条反馈「这几个按键没有音效，所有可以点击的按键都要音效（包括分栏的按键）」，并要求回弹再加快、按压幅度减小、按压阴影减淡。

## 改动

1. **豁免废除 + 两层覆盖**（`petpet/app/sounds.py`）：
   - `play_click` 加 **25ms 节流**（`_LAST_PLAY_TS`）——显式调用层与应用级过滤器同时命中同一次点击时只响一次；
   - 新 `install_click_sound_filter(app)`（pet.py main 安装，幂等挂 `app._petpet_click_sound_filter`）：应用级 eventFilter，命中 **QAbstractButton 全家（含 checkable 页签）/QTabBar/设 PointingHandCursor 的自绘键 widget** 的键内左键松开 → `play_click`；键外松开/非按键/非左键不响；try/except 兜底绝不拖垮事件分发。游戏画布（金币雨/打地鼠）用 Arrow 光标，刻意不在覆盖面。
   - FeedbackButton docstring 同步（checkable 豁免废除）。
2. **回弹加快**：`RECOVER_MS` 与 `BUTTON_PRESS_FLASH_MS` 15→8ms（触发延迟随回弹同步缩短）。
3. **按压幅度减小**：面板/贴图/家园键 5→4px、`_AvatarButton` 6→5、装修分类签/放置键 3→2。
4. **压暗减淡**：FeedbackButton (150,60,40,70→45)、pet_profile 三处 60→40、家园 150→95。

## 验证

- 新 `tests/test_click_sound_filter.py`：过滤器命中（按钮/分栏/手势键）恰一次、非按键与键外不响、25ms 节流防双响。
- pure_scale pin 更新（场景键 -10→-8、头像 6→5）。
- 真机：商店 5 个 checkable 页签（宠物/套装/家居/强化/礼物）release 键内播放 1 次、键外 0 次；QSoundEffect Ready。
- 全量 **1016 passed**。

## 评审修正（同日）

- **游戏画布误响**：金币雨/猜猜看整幅画布设 PointingHandCursor，被过滤器当按键全程点音——新增 `petpetNoClickSound` 布尔属性豁免（CoinCatchCanvas/ShellShuffleCanvas `__init__` 设置，过滤器先查属性），pin 测试补「豁免画布不得响」。
- AGENTS 残留旧值（家园条目 15ms）修正为 8ms。
- 评审确认无恙：节流时间戳只在真实播放时刷新（无双响路径）；过滤器安装位、幂等性、异常兜底均正确；手感常量无残留。

## 坑位沉淀

- 应用级 eventFilter 里引用模块级函数名（`play_click()`）在运行时解析——`patch.object(sounds, "play_click")` 可测；闭包捕获才测不了。
- 音效多层覆盖的正确解法是**节流去重**而不是小心翼翼地保证只有一层命中——新接入面不再需要审计是否双响。
