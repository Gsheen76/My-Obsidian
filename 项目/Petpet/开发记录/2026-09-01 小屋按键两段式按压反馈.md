# 2026-09-01 小屋按键两段式按压反馈

## 背景

v1.6.3 的胶囊按键反馈是单段的：按下缩小 3px + 灰黑块，180ms 闪动、100ms 后才触发动作。用户要求：

1. 缩短按住时变暗变小的时长；
2. 变暗段结束后**回弹到原大小并显示悬浮高亮色**（描边 + 白洗），形成"按下去 → 弹回来亮一下"的节奏；
3. 回弹段播完**再关闭菜单、再执行指令**；
4. 整套反馈总时长要比旧版 100ms **更短**，提升交互感与流畅感。

## 改动（`petpet/home/window.py`）

- **时序常量上提到类级**：`HomeSceneWindow.BUTTON_PRESS_FLASH_MS = 40`、`BUTTON_CLICK_DEFER_MS = 80`，两段均分（40+40=80ms < 100ms）。
- **两段式状态机**：`mousePressEvent` 同时记录 `_button_flash_phase_deadline`（前段截止，now+40ms）与 `_button_flash_until`（总截止，now+80ms）；`_button_state()` 在总窗口内按当前时间返回 `"pressed"`（变暗缩小）或 `"recover"`（回弹+悬浮色）。相位切换由 `time.monotonic()` 直接计算，不依赖 QTimer 精度（家园 33ms 场景定时器持续重绘，相位边界自然呈现）。
- **触发时点对齐**：`_click_defer_timer.start(80)` —— 回弹段播完的同一时刻菜单才关闭、动作才执行，符合"播完反馈 → 关闭 → 执行"的顺序；清尾定时器改为 `DEFER+20ms`。
- **绘制新增 recover 态**：`_draw_action_button` / `_draw_scene_button` 中 `recover` = **原大小**（不放大不缩小）+ 悬浮的描边 `#d9976b` 3px + 白洗；pressed 态视觉不变。
- 顺手修正 `AGENTS.md` UI 约定里过时的"在按钮内松开才触发"描述（v1.6.3 起实为按下即延迟触发）。

## 验证

- **offscreen 全量**：`668 passed`（667 旧 + 新增 1 条回归测试 `test_button_flash_runs_pressed_then_recover_within_shorter_total`，锁住 pressed→recover→过期三态时序与"总时长 < 100ms"约束）。
- **Windows 平台像素实测**（真实桌面渲染，冻结时序采样"抚摸"按钮区域）：
  - pressed：内区均亮 ≈121（深色块压暗生效），边缘描边色命中 0 像素；
  - recover：内区均亮 ≈223（回弹提亮），边缘命中 #d9976b 描边 228 像素。
- **精确重启**：停旧 PID 8992 → 新 PID 9196，EnumWindows 按进程校验主窗口可见（127×147 桌宠窗口 + 聊天/覆盖层窗口均 visible）✓。
- 中途踩坑：PS5.1 脚本里反引号续行被 CRLF 破坏导致 `Start-Process` 没执行（宠物被停后未拉起）——改为单行命令重新启动成功；另 `Write-Output [WinEnum]::Result` 在参数位被当字面量打印，改用变量赋值后再输出。
