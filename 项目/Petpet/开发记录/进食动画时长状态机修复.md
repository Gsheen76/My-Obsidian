# 进食动画时长状态机修复

> [!summary] Summary
> 修复进食动作到期后仍停留在 `eat` 状态的问题，并将默认和当前进食动作时长统一为 `1.5 秒`。

## 根因与修复

`on_autonomy()` 原本只在行为到期时结束 `walk`，未处理 `eat`。因此即使 `feed_animation_duration` 已到期，小狗仍会保持进食姿态，直到下一次自治行为选择。

- 到期的 `eat` 状态现在立即恢复为 `idle`。
- `feed_animation_duration` 默认值由 `1.8` 调整为 `1.5`。
- 当前保存配置：进食时长 `1.5 秒`，进食和抚摸动画均为 `10 FPS`。

## 验证结果

- 回归测试先复现进食状态无法结束，再验证修复。
- `QT_QPA_PLATFORM=offscreen python -m pytest -q`：`167 passed`。
- `compileall`：通过。
- 重启后的实际 `PetWindow` 验证：`duration=1.5`、`eat_fps=10`、`pet_fps=10`、过期行为状态为 `idle`。
- 源码进程 PID：`17488`。
