# 聊天界面与 API Key 配置提示设计

> [!summary] Summary
> 强化聊天中小狗消息的底纹与文字可读性，让气泡文字完整跟随聊天字体设置；API Key 未配置时在聊天入口和主菜单设置入口同时显示状态与红点提醒。

## 目标

- 小狗消息气泡与聊天页面背景有明确层次，不再视觉融为一体。
- 聊天消息、输入框和工具按钮使用同一套 `chat_font_size` 缩放逻辑，设置修改后即时生效。
- 没有 API Key 时明确显示“未配置”，并在聊天 API Key 入口与主菜单“设置”入口同时显示右上角红点。
- API Key 保存、移除或改由环境变量提供后，两个入口的状态立即同步。

## 界面方案

### 小狗消息与字体

- 小狗消息气泡使用浅杏底色、较深的暖灰文字和细边框；用户消息保持现有的右侧浅粉风格。
- 消息气泡字体以 `chat_font_size` 为唯一来源，并与输入框、工具按钮一起在运行时设置刷新时重新应用。
- 消息气泡保留可选择文本与自动换行；不改变聊天历史、滚动到底部和流式输出逻辑。

### API Key 状态与提醒

- `ai.get_api_key_source()` 是唯一状态来源：环境变量或本机配置均视为已配置。
- 未配置：聊天入口显示 `API Key：未配置` 并带红点；主菜单“设置”入口带红点。
- 已配置：聊天入口显示现有来源文案，不显示红点；主菜单红点消失。
- 红点仅表示未配置，不阻止本地话术聊天，也不自动弹出配置窗口。

## 实现边界

- 修改 `pet.py`：`ChatWindow` 样式、字体计算、API Key 入口状态和 `BubbleMenu` 设置入口的红点绘制。
- 修改既有聊天/设置测试，增加 API Key 未配置与已配置的双入口状态断言，以及聊天字体设置的即时应用断言。
- 不修改 API Key 存储格式、环境变量优先级、模型配置或聊天接口。

## 验收与测试

- 未配置 API Key 时，聊天入口文本为“未配置”且两个入口显示红点。
- 保存 API Key 或设置环境变量后，两个红点都消失且入口文案切换到已配置状态。
- 改变聊天字体设置后，已打开聊天窗口的消息、输入和工具按钮字体同步变化。
- 聊天截图中小狗消息气泡相对页面背景可辨，文字与输入内容尺寸协调。
