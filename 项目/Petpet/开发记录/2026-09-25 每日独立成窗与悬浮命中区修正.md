# 2026-09-25 每日独立成窗与悬浮命中区修正

> [!summary] Summary
悬浮命中区改为固定整格（不随缩放、高亮铺满）；「签到」改名「每日」并完全独立成 DailyWindow（记录窗回归纯记录）。

## 改动

### ① 悬浮命中区 = 整格（手感一致）
- 原实现：命中矩形=随悬浮缩放的格子（悬浮时格子长大、触发范围跟着漂），且高亮框比格子矮 24px（名称胶囊区不在高亮内）——用户感知为「只有图标区可点、各键手感不一致」。
- 修：`_bubble_rects` 改存**固定基础格**（`QRectF(bx, by, button_w, button_h)`，不随 hover scale）；缩放纯视觉。高亮框铺满整格（含胶囊区）——所见高亮区 == 触发区。

### ② 「每日」完全独立成窗
- 新 `DailyWindow(CozyProgressWindow)`（progression/ui.py）：700×800，竖排「签到横幅卡 → 月历卡 → 今日任务卡」，复用迁出的构建器/领取链/翻月逻辑。
- RecordsWindow 回归纯记录：删除页签条、daily 分支、落地页判定、日历锚点；保留「每开 refresh」防旧内容。
- pet_window：`open_daily_window()`（惰性 `daily_win`、`daily_open` 诊断埋点含可领态）；分发 `daily_rewards` → 独立窗；`open_records` 撤掉 force_daily。
- 红点：`daily_ready` 集合 = `daily_rewards + more`（记录键不再提示，规格断言反转）。
- 坑位：pet.py `_dependency` 解析是 `globals()[name]`——新窗口类必须进 pet.py 门面 import，否则运行时 KeyError。

### ③ 改名
- 主菜单键「签到」→「每日」，窗标题「每日」（副题：签到、日历和今日任务，每天来看我一眼）。

## 追记：零点自动刷新（同日三轮）

- 用户定稿「零点一到就自动刷新」（消除「零点后、开每日窗之前的互动不计入新一天」的缺口）。
- `daily.py` 新增 `ms_until_next_midnight`（纯函数，1s 下限防抖）；`PetWindow` 起动即排零点 singleShot，`_midnight_rollover`：重置任务/签到块 → 落盘 → 失效菜单红点缓存（含预热）→ 刷新开着的每日窗 → 重排下一零点；全程防炸 + `midnight_rollover` 埋点。
