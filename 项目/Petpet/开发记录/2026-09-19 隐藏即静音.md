# 2026-09-19 隐藏即静音

> [!summary] Summary
> 用户在游戏（宠物自动隐藏）期间仍听到宠物声音。取证：`say()` 气泡有 `interface_anchor_visible()` 门，但 `play_sound` 完全没有隐藏检查——自治动作音效（`on_autonomy`）与**自动睡醒的汪声**（精力睡满 `_wake_from_auto_sleep` → bark）由常驻定时器驱动，隐藏时照常触发。

## 取证

- `play_sound`（pet_window.py）原实现只查 `settings["sound_enabled"]`。
- 隐藏状态位 `_game_auto_hidden` / `_user_hidden` 存在且由 game guard tick 维护，但声音路径不读。
- 隐藏期间仍在跑的触发源：on_tick 自治行为（动作音效）、on_decay 自动睡醒链（"bark"/"sleep"）、延迟 singleShot 的汪叫。

## 改动

- `PetWindow.play_sound` 入口加统一隐藏门：`_game_auto_hidden` 或 `_user_hidden` 任一为真即静音返回——覆盖全部 11 处调用点（交互/睡觉/唤醒/切换/自治/挖宝音效），隐藏解除后恢复出声。
- `tests/test_game_guard.py` 新增 `HiddenPetSilenceTests` 三测：自动隐藏静音 / 手动隐藏静音 / 可见时照常播放（护栏）。

## 验证

- TDD：双隐藏态 RED（声音穿出）→ 加门 GREEN；护栏测过。
- 全量 offscreen：**904 passed**（前值 901，+3）。
- 真平台（windows QPA）：`_game_auto_hidden=True` 时 bark 不响、清标志后照常响，SMOKE PASS。
- 重启：旧 PID 16120 → 新 PID 32764 存活（用户游戏进行中，隐藏=预期态，静音门恰在该态生效）。
