# 长期记忆与提醒音效与CI

> [!summary] Summary
> 用户从待办选定三件：长期记忆、提醒音效、CI。结构化档案（称呼/作息/喜欢/讨厌/重要的事/其他六栏）替代旧一句话总结，满栏丢最旧、旧记忆自动迁移；numpy 合成三枚暖色提醒音接 `play_sound`（尊重 sound_enabled）；`test.yml` 让全量 pytest 在每次 push 的 Windows runner 上自动跑（首跑两次失败后转绿）。

## 1. 长期记忆（结构化档案）

- **纯函数层**（`petpet/chat/memory.py`，9 条测试）：`merge_profile_facts`（去重保序、称呼栏 incoming 在前、其余栏旧值在前、**满栏丢最旧取尾部 cap 条**——新事实永远保留）、`render_profile_facts`（分栏中文行注入提示词）、`parse_profile_extraction`（容忍 ```json 包裹/前后废话）、`ensure_profile_facts`（旧 user_profile 字符串一次性迁入「其他」栏，幂等不重复）。
- **api 层**：`_default_memory` 加 `profile_facts: {}`；`load_memory` 返回前迁移；`_refresh_user_profile` 重写——每 6 轮用户消息后台触发（沿用原节奏），LLM 以「记忆抽取器」身份输出 JSON（单引号字符串承载双引号示例，零转义），解析→合并→legacy user_profile 同步为分栏渲染文本（旧版本回退可读）。
- **service 层**：system prompt 的 `{user_profile}` 优先注入分栏渲染，空档案回退旧字符串。
- 设计要点：档案每栏有条数上限（称呼3/作息4/喜欢8/讨厌6/重要的事8/其他4），单条≤60字；「重要的事」语义上 newer matters more——满栏挤掉最旧。

## 2. 提醒专属音效

numpy 正弦合成三枚 44.1kHz 单声道 wav（`assets/runtime/sounds/`）：`drink.wav`（0.38s 双水滴滑频）、`rest.wav`（0.7s 柔和低铃双谐波）、`stand.wav`（0.32s 上行双音）。接线：音效名列表 +8→5 个；`on_health_check` 各类提醒触发时播对应音效（多类同发取最后触发类），`play_sound` 内部尊重 `sound_enabled`。资产守卫通过（文件名在代码引用链中）。

## 3. CI（GitHub Actions）

`.github/workflows/test.yml`：windows-latest + Python 3.12 + `QT_QPA_PLATFORM=offscreen` 全量 pytest，push/PR 触发，20 分钟超时。**首跑两坑**：① `cache: pip` 默认找根目录 requirements.txt——本仓库在 `requirements/` 子目录，需 `cache-dependency-path: requirements/*.txt`；② 一次性修复脚本 `fix_api_memory.py` 误入提交（临时脚本要即用即删，commit 前看 `git status` 全表）。第二次修复后 **CI 全绿**（远端 767 通过，与本地一致）。

## 本轮大坑（工具层）

**Write/Bash 工具会折叠 `\\n` → `\n`**：给 api.py 写含转义序列的代码时，Python 脚本里的 `\\n` 被吃一层成真换行 → 写出的 api.py 语法错误（unterminated string）。三层绕法都不行（heredoc 折叠、Write 折叠、chr(92) 拼接到最后还是被 Write 吃掉一次）——**最终正解：含转义内容的代码改动一律用 Edit 工具直接改目标文件**（Edit 不经过任何再转义层），JSON 示例改用单引号 Python 字符串承载双引号（全程零反斜杠）。
