# 2026-09-28 菜单消失修复与光环恢复及零延迟音效

> [!summary] Summary
> 用户三反馈：菜单点完消失（修复）、气泡菜单保留旧光环交互、音效柔和+零延迟。菜单消失实证为页面切换时 activateWindow 的状态翻转击中新菜单失活自杀逻辑；音效三轮卡顿的最后一个元凶是「播放中 restart」~300ms 同步段，3 实例轮换后 20 连点最坏 3.15ms。全量 1017 passed。

## 背景

全按键音效轮后用户反馈：①「右键菜单栏的那些效果还是保持之前的效果（我喜欢之前那样的交互方式），现在互动和更多点完就消失了（修复）」②「声音太尖锐了，柔和一点（你去专门的游戏素材音效网站学习一下）」③「点击之后还是有明显的卡顿，绝对是音效的问题，修复，我要的 0 延迟体感」。

## 菜单消失：复现→实证→双保险修复

- **复现**：真平台 `_run_action("more")` 耗 1169ms 后 `pet._bubble_menu = None`——菜单自灭。
- **排错**：类属性替换法禁用 `_on_application_state_changed` **无效**（PyQt connect 时已绑定旧函数对象，替换类属性不影响已连接的绑定方法）——验证信号行为必须 disconnect。
- **实证**（信号断开对照）：断开 `applicationStateChanged` 后 factory 菜单存活。完整链条：页面切换 factory 的 `show() + activateWindow()` 引发应用状态翻转，**Inactive 事件打到刚 born 的新菜单**（焦点仲裁慢时 >0.5s 才送达），失活自杀逻辑 `_close()` 并清空 `pet._bubble_menu`。
- **修复（双保险）**：①显示后 1.5s 宽限 `_suppress_state_close_until`（构造 show 与 factory 弹出两路径都设——预热菜单构造时未 show，宽限必须由 factory 补）；②**光标在菜单内永不自杀**（`_cursor_inside()`，取不到光标信息按"在内"——守卫宁可漏关不可误杀；本质修：用户点菜单键时光标本就在菜单内，此时的失活必是翻转不是"点到外"）。
- **验证**：更多→互动→返回全流程存活，宽限过期后仍活（光标守卫兜住）。

## 光环恢复

气泡菜单 hover 光环（白洗 `242,143,118,34` + 珊瑚描边 `#f28f76` 2.2px，画在整格内、无越界裁角）按用户定稿恢复——「我喜欢之前那样的交互方式」。纯缩放规范对面板/家园继续有效，气泡菜单为**用户点名例外**；`test_button_feedback_pure_scale.py` 的静态守卫反转为「halo 必须存在」，防未来统一轮再误删。

## 音效：柔和化 + 零延迟

- **柔和化**：学习 UI 音效库（Kenney/freesound 常见 soft click/pop）特征重新合成 click.wav——320→150Hz **音高下滑正弦**（pop 的"噗"感来自 pitch drop）+ 指数衰减 τ=24ms + 2ms 淡入防爆音 + 一阶低通，85ms，替换原 1150Hz 尖锐版；音量 0.35→0.30。
- **零延迟（用户两判全对）**：继续剖析发现 **QSoundEffect「播放中再 play()」= restart 路径有 ~300ms 同步段**（播完再 play 仅 0.01ms）——85ms 音效被快速连点（间隔 <85ms）必撞；上一轮去掉的 stop() 反而曾掩盖此问题的一半。修=**3 实例轮换**（同实例最小间隔 255ms = 3×音长，永不 restart）+ 保持无 stop。实测 20 次连点（30ms 间隔、绕节流）最坏 **3.15ms**（修前 288ms）。

## 音效卡顿三部曲（本日三轮收束）

1. 预热冻结 5s（启动后 2s singleShot 同步 for）→ 启动期一次付清；
2. `stop()` 每次同步 ~240ms → 去 stop（play 自带 restart 语义）；
3. 「播放中 restart」~300ms 同步段 → 3 实例轮换。

## 评审二轮补丁

- 轮换 3→4 实例：25ms 节流下同实例最小间隔 100ms > 85ms 音长，数学闭环（3 实例时 75ms<85ms 有连点器级理论边缘）。
- `_drain_close_grace` 排空余量 +30→150ms（曾与 singleShot 竞态闪失败）。
- 评审确认：宽限覆盖全部 show 路径（构造/factory pop/RuntimeError 回退均设）；点外关闭走 eventFilter 独立路径不受宽限影响；无 `_EFFECT` 旧名残留。

## 验证

全量 **1017 passed**（+宽限 pin +halo 反转 pin，老失活测试壳补 `_cursor_inside`）；真机菜单全流程存活；重启 PID 27868。

## 坑位沉淀

- QSoundEffect **播放中再 play()=restart（~300ms 同步段）**、播完 play=0.01ms——短音效连点必须多实例轮换（轮换数×音长 > 最快连点间隔）。
- **类属性替换禁用已连接 PyQt 信号无效**——connect 求值时已绑定旧函数对象；验证信号行为必须 disconnect。
- `activateWindow()` 的状态翻转事件可能 >0.5s 延迟送达——刚显示窗口的失活守卫宽限要 ≥1s，且"光标在内不关"是更本质的语义修。
