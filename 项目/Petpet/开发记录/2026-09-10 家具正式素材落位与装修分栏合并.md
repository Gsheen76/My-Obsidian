# 家具正式素材落位与装修分栏合并

> [!summary] Summary
> 全量 **773 passed** + 重启 PID 15812。八件家具（四新 + 旧四重制）正式素材同名替换占位稿；装修面板分栏从 7 类收敛到 4 类（全部/家具/装饰/玩具）。

## 1. 两张生成图的归属判定（视觉 CDN 失效 → 程序化特征判图）

视觉模型 `analyze_image` 对本机图片的 CDN 直链 400（路径含反斜杠/中文无法解析），改用 PIL/numpy 逐格特征分析，两张图格子顺序均与拆分器预设完全吻合：

| 图 | 时间戳 | 判定依据 | 结论 |
|---|---|---|---|
| ChatGPT Image …19_53_52.png | 19:53 | TL 高瘦 2.28（落地灯）、BL 扁宽 0.54（茶几），全图零绿色 | **new**（灯/书架/茶几/藤篮） |
| ChatGPT Image …20_02_20.png | 20:02 | BL 格 18.8% 绿色像素（绿植）、TL 扁宽（地毯） | **legacy**（地毯/沙发/绿植/墙画） |

时间戳先验（先要新四件提示词、后要旧四件重制提示词）与特征判定互证。**方法备忘：AI 九宫格判归属时，绿色占比/长宽比/不透明度三特征足够区分家具类别，不必依赖视觉模型。**

## 2. 拆分落位与验收

```
python tools/split_furniture_sheet.py "<19_53_52.png>"            # new
python tools/split_furniture_sheet.py "<20_02_20.png>" --set legacy
```

8 格全部非空写入 `assets/runtime/furniture/home/`。三重校验：① 尺寸与 `HOME_DECORATION_DEFINITIONS` 逐一相等；② 不透明像素健康（占位稿退役）；③ **内容框内部空洞率**符合各剪影天然形状（书架 94%/墙画 92%/地毯 92% 实心，落地灯 44% 是灯杆留空、绿植 37% 是叶隙）——确认白阈值 240 没把奶油色主体误蚀出斑点洞。对照图：`Temp/furniture_final_review.png`（奶油底 2×4 带名标签）。

**实平台渲染差分验收**（非 offscreen，真实字体）：空屋 vs 全家具双渲染，按默认位逐件框内差分——**8/8 OK**（地毯 32.3%/沙发 28.1%/绿植 49.2%/墙画 45.9%/落地灯 7.5%（=稀疏剪影占比，自洽）/书架 62.1%/茶几 58.3%/藤篮 40.0%）。快照：`Temp/home_furnished_{left,mid,right}.png` + 装修面板 `Temp/home_deco_panel.png`（4 分栏实字体）。原始素材表归档 `assets/source/references/furniture_sheet_{new,legacy}_source.png`。

## 3. 装修分栏合并（用户定稿："同类的合并"）

`petpet/home/rendering.py`：

- `HOME_DECORATION_CATEGORIES` 7 类 → **4 类**：全部(8) / 家具(沙发+灯+书架+茶几,4) / 装饰(地毯+墙画+绿植+状态卡,4) / 玩具(藤篮,1)
- `HOME_DECORATION_CATEGORY_BY_ID` 旧类目键 `rug/sofa/plant/wall_art` 全部收编进 `furniture`/`decor`；`furniture`/`toy` 键保持不变（新四件映射零改动）
- 分栏键宽 `(panel.width()-24)//len(CATEGORIES)` 自动适配 7→4，无需改 `window.py`

`test_home_furniture_expansion.py` 的类目断言是通用形式（每个映射值必须出现在标签表里），合并后自然通过，未改测试。
