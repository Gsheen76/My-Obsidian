# 装修全景与小屋置顶

> [!summary] Summary
> 全量 **774 passed**（+3）+ 实平台渲染验证 + 重启 PID 30344。用户定稿三条：装修看全景、平移键不要了、小屋改回置顶。

## 用户原话与解读

「装修的时候会切换成全景就是整个长度完全展示出来，左移和右移就不需要了，小屋改回保持置顶」

- **全景 = 1:1 加宽而非缩放**：实测用户屏 2560×1440，全景窗口 338（左栏装修面板）+ 1800（整幅世界）= 2138 放得下；背景图本就是 1800×768 整幅——加宽后**家具拖拽/命中链路零改动**（只是 `canvas.width()` 从 700 变 1800、镜头恒 0），缩放方案（0.39 倍）会牵连整条命中测试被否。
- **平移键"不需要"= 整链路移除**：查证 `view_pan_enabled()` 本就只在装修态为真（正常模式镜头自动跟随小狗），全景落地后此功能彻底无用 → `pan_view/begin_pan/end_pan/_repeat_pan/_pan_timer`、geometry 的 `pan_viewport_x/_clamp_viewport_x/HOME_CAMERA_PAN_STEP/HOME_CAMERA_REPEAT_STEP` 全删。
- **置顶**：翻转早期「家园窗口不置顶」决定（AGENTS.md 已同步改写）。

## 实现

| 位置 | 改动 |
|---|---|
| `rendering.py` | 新增 `decoration_scene_window_geometry(screen)`：右缘贴屏、窄屏 `max(screen.left(), …)` 钳左缘（宁可溢出不裁世界） |
| `window.py` | `scene_canvas_rect()` 装修态返回 `(338, 0, 1800, 768)`；`_sync_scene` 改走 `_target_scene_geometry()/_apply_scene_geometry()`（装修态每 tick 强制全景几何，防止被常规几何顶回）；`toggle_decoration_mode` ON：镜头归零存档 + 即刻应用几何，OFF：还原 1038 窗口 + 镜头回跟小狗；`setWindowFlags` 加 `WindowStaysOnTopHint` |
| `geometry.py` | 删 `pan_viewport_x/_clamp_viewport_x/HOME_CAMERA_PAN_STEP/HOME_CAMERA_REPEAT_STEP`（`viewport_pinned` 等存档键保留，schema 兼容） |
| 测试 | 平移步进测试 → 全景几何测试（宽 2138/右贴/窄屏钳左）；平移行为测试 → 全景切换测试（镜头 0、画布 1800、退出还原 550/700/1038）；新增置顶 flag + 平移 API 移除守卫 |

**坑位**：根 `scene_system.py` facade 是 4 行 star-import（只透传 geometry），装修几何在 rendering → 测试直接 `from petpet.home import rendering` 引用；`.worktrees/home-scene-system/scene_system.py` 是旧变体（带显式导入长版），grep 时勿混淆。

## 验证

- 全量 **774 passed**。
