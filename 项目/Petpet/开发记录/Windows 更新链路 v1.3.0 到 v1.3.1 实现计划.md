# Windows 更新链路 v1.3.0 到 v1.3.1 实现计划

> [!summary] Summary
> 以隔离的真实发布资产升级为主验证，依据失败证据补充最小修复和自动化回归测试。

## 执行步骤

- [ ] 下载并校验 `v1.3.0`、`v1.3.1` Windows 发布资产。
- [ ] 建立临时隔离安装目录并启动 `v1.3.0`。
- [ ] 通过更新器执行 `v1.3.1` 下载、原位替换和新版重启。
- [ ] 对比替换前后哈希、进程、临时文件和用户数据目录。
- [ ] 为复现的失败路径写失败测试。
- [ ] 实现最小更新器修复并运行完整测试。
- [ ] 再执行一次真实隔离升级，记录最终证据。
