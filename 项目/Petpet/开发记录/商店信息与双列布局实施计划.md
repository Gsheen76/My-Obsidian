## 价格标签与强化平衡

- [x] 用原生奶油金边价格组件替换会裁切文字的四张运行时贴图；统一保留 34px 最小高度与左右文字安全区。
- [x] 让价格标签只渲染动态文字：普通为“售价：X Pet币”，免费为“免费赠送”；首购折扣为删除线原价、现价和 `round((1 - price / original_price) * 100)` 计算的“-Z%”。
- [x] 落实玩耍公式：心情 `20 + 3 * level`、精力 `max(0, 10 - 2 * level)`、饱腹 `max(0, 5 - level)`；睡眠每 2 秒为精力 `+4`、饱腹 `max(0, 2 - 0.4 * level)`。
- [x] 睡眠在该次结算前精力为 100 时不扣饱腹；精力未满时才恢复并扣除，满级消耗保持零。
- [x] 睡眠强化文案统一为“每2s睡眠：精力+4点，饱腹-X点”，不改变每 2 秒一次的实际结算频率。
- [x] 执行最终验证：`python -m pytest -q` 为 `611 passed in 76.48s`；`python -m compileall -q petpet pet.py tests` 无输出、退出码 0；`git diff --check` 退出码 0，仅有项目文档的 LF/CRLF 转换警告、无空白错误。
