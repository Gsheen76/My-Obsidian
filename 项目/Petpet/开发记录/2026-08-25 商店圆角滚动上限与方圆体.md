# 商店圆角滚动上限与方圆体

> [!success] 已完成

## 字体接入

- 全局字体使用系统自带的**幼圆**（`petpet/app/fonts.py`：`APP_FONT_FAMILY = "幼圆"`，`apply_app_font(app)` 设为应用默认字体，`pet.py main()` 启动时调用）；`PANEL_STYLE` font-family 首位为幼圆。
- 曾从阿里官方 CDN 下载方圆体打包接入，后按用户要求改回幼圆，字体文件已移除。
- [!warning] 注意：`QFontDatabase.addApplicationFont` 在 `QT_QPA_PLATFORM=offscreen` 下会 access violation 崩溃，禁止在模块导入期调用。

## 标签栏固定

- 用户要求头部（标题/币量/关闭）与标签栏位置固定不随内容滚动：标签栏从滚动区内容移出，改为 `root_layout.insertWidget(1, tab_bar)` 固定在标题栏下方，`refresh()` 只同步选中态与可见性（`_sync_tab_bar`）。
- 滚动区封顶后布局会把剩余空间上下居中导致头部下移：在滚动区与状态栏之间插入 `addStretch(0)` 弹性占位——未封顶时滚动区（stretch 1）吃掉全部空间，封顶时占位吸收剩余，四页标签栏 y 恒定（105）。
- 商店主题卡片统一暖黄：`SHOP_THEME_STYLE` 中 decorationCard/upgradeCard/placeholderCard/dataCard/achievementCard 与 shopCard 同为 `#fff9ee` + `#f0d8ba` 边框。
- 六枚烘焙文字素材接入：`currency_bg`（币量胶囊，遮盖占位数字后绘制真实余额，`CoinPillLabel`）、`free_gift_button`（免费赠送标签）、`price_bg`（普通价格签 border-image，去掉 🪙 emoji 前缀）、`status_owned`/`status_in_use`（已拥有/使用中徽章贴图）、`switch_pet_button`（切换宠物按钮 border-image，文字透明）。文本用 `PreservedTextLabel` 保留（QLabel 设 pixmap 会清空 text）。
- 商店字号整体加大：shop 主题 `QWidget 21px / 600`。
- 配套收窄防溢出：价格签 14px + padding-left 34、宠物/家居购买按钮简化为「购买」、宠物卡边距 14/16。四页 content 宽度均 ≤ 视口。
- 测试同步：页签文本断言过滤隐藏按钮；家居预览宽 150；家居购买按钮断言「购买」。
- [!warning] `QLabel.setPixmap` 会清空内部 text，需要保留 text() 的标签须用子类存储。

## 排查：重启后「没有变化」（同日）

- 现象：多次重启后用户看不到任何改动。排查：`EnumWindows` 发现进程活着但**所有窗口 IsWindowVisible=0**（小狗整个隐藏），并非代码未生效。
- 处理：再启动一个实例触发单实例「召回」（`activate_existing_instance` → recall+show），小狗恢复显示；用户截图确认全部改动已生效。
- 教训：强制 Stop-Process 后重启，若窗口仍隐藏，用「二次启动召回」而不是反复重启；验证用 EnumWindows 查窗口可见性，而不是只看进程存在。

## 卡顿根修/尺寸回调/精确等大（同日续三）

- 卡顿根因：alpha 包围盒裁剪对 2172×724 大图做纯 Python 逐像素扫描（~157 万次 pixelColor），且每个价格标签创建都扫一遍 → 切页/刷新巨卡（边界测试 93s）。
- 修复：`_alpha_bounds()` 用 numpy 向量化扫描（`constBits().asarray` + reshape，注意 sip.voidptr 不能直接 frombuffer），加 `_CROPPED_PIXMAP_CACHE` 模块缓存 → 边界测试 3.7s、四页切换 0.55s。
- 尺寸回调：价格框/免费赠送内容高 54→46（54 视觉过大），价格字号上限 22。
- 徽章 1-2px 差与右对齐偏差根因：缩略图扫描外扩 ~2 缩略像素透明边。numpy 精确 bbox 后：in_use 122×46 / owned 124×46 严格等高；徽章 contentsMargins 右侧 4→0，套装/家居页徽章与按钮右缘 diff=0（几何实测）。
- 家居徽章被上下剪裁：卡内容高超出固定高 310 被压缩 → 卡高 310→330，测试断言同步。
- 重启时再次出现窗口隐藏，二次启动召回生效（可见窗口 0→5）。
