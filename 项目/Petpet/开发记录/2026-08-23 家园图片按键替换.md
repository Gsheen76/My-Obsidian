# 家园图片按键替换

> [!success] 已完成
> 家园右下角上拉菜单的程序绘制按钮全部替换为 ChatGPT 参考图的透明 PNG 素材，收起态「菜单⌃」由「收起⌄」派生。

## 素材结果

- 运行资源：`assets/runtime/scenes/home/buttons/`，共 11 张 `240×92`（2 倍逻辑尺寸）透明 PNG。
- 主菜单：`exit`（退出）、`decorate`（装修）、`interaction`（互动）、`shop`（商店）、`collapse`（收起⌄）。
- 互动二级：`pet`（抚摸）、`feed`（喂食）、`play`（玩耍）、`sleep`（睡觉）、`back`（返回⌄）。
- 派生：`menu.png`（菜单⌃）取自「收起⌄」原图，擦除原文字后按行插值重建底色，再用微软雅黑粗体烘焙「菜单」与手绘折角。
- 制作源图存档于 `assets/source/references/home-action-buttons-main.png` 与 `home-action-buttons-interaction.png`。

## 抠图脚本

- `tools/import_home_action_buttons.py` 可从两张源图重复生成全部按键。
- 背景剔除使用「亮度归一化色度距离 + 边界洪泛填充」：木板、板缝与投影与木纹同色相，可被洪泛穿透；按钮描边色相不同，阻挡洪泛并保留完整主体。
- 残渣清理使用「stadium 轮廓拟合 + 突出物连通域厚度判断」：板缝碎片厚度小于 11 像素被删除，屋顶、蝴蝶结、爱心、星星等合法图案厚度更大得以保留。
- 「收起⌄」文字擦除区域限制在图标与爪印水印之间，整行插值重建，避免白色抗锯齿残影。

## 运行逻辑

- `petpet/home/rendering.py` 新增 `HOME_BUTTON_SIZE = (120, 46)` 与 `HOME_BUTTON_PATHS` 注册表。
- `HomeSceneWindow` 启动时加载按键贴图；`paintEvent` 按菜单状态绘制 `menu` / `collapse` / `back` 与对应菜单项贴图。
- 主按钮与菜单项统一为 `120×46` 逻辑尺寸；贴图缺失时回退到原程序绘制按钮，不阻断启动。
- 「左移」「右移」装修视口按钮保持程序绘制，不在本次替换范围。
