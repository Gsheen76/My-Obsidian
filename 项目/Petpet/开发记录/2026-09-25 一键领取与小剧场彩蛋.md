# 2026-09-25 一键领取与小剧场彩蛋

> [!summary] Summary
一键领取把「逐条点领取」压成一下；小剧场给桌面常驻的宠物加久置随机表演的生命感；顺带把上轮 code-review 登记的两笔 JS 债清掉。

## 改动

### ① 一键领取
- `DailyWindow._claim_all_ready(now)`：领全部完成任务 + 全勤，聚合一次反应「一口气领了 +N 宠物币，赚翻啦！」，save+refresh，返回总额。
- 任务卡在**可领 ≥2** 时显示「一键领取全部（N）」；单条可领时原有单独领取键已足够，不堆按钮。

### ② 小剧场彩蛋
- `PetWindow._maybe_skit` 挂 on_decay（醒睡统一区、报信之后）：醒着 + 冷却 20 分钟 + 每 tick 0.6% 概率 → 随机选 (动画, 台词) 表演一段：
  - happy「嘿嘿，今天也是元气满满的一天！」
  - play「看我！我会翻跟头哦——好啦其实是转个圈～」
  - eat「呜……好像闻到了什么好吃的味道……」
  - dig_reward「我挖到了一个小秘密：其实我很喜欢你！」
- 全部用既有交互动画（零新素材）；say 隐藏门复用（游戏/隐藏不打扰）。

### ③ JS 两债（上轮 review 登记）
- `overLimit` 逐出改 **LRU 触活**：`Map` 按插入序逐出且 `set` 不换位——活跃键会被误逐；改为 `delete+set` 刷新到最新端；内层遮蔽变量改名。
- JS 测试加全局 `beforeEach(() => _resetRateLimiter())`：旧测试此前靠 20/分余量通过，套件增长会互染。
