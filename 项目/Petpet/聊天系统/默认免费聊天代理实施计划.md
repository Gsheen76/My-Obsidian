# 默认免费聊天代理实施计划

> [!info] 项目内完整计划
> `docs/superpowers/plans/2026-08-11-default-chat-proxy-plan.md`

## 交付顺序

1. 用失败测试建立 Cloudflare Worker 的请求校验、SSE 转发与安装 ID/IP 双重限额。
2. 补齐 KV 绑定、Secret 设置和安全部署文档，示例不包含真实 Key。
3. 为 Petpet 实现默认聊天与个人 GLM-4.6V 的路由、同意状态和旧模型迁移。
4. 调整聊天窗口：默认文字聊天、首次数据确认、图片限制、额度/上游错误提示。
5. 更新 README、Obsidian 实施记录，并运行 Worker、focused 与全量验证。

> [!warning] 密钥与部署
> 真实 Key 只在 Cloudflare Worker Secret 中配置。项目方自行部署 Worker；本计划不授权把 Key 写入任何代码、配置、笔记或发布包。

## 已确认参数

- 部署：Cloudflare Worker + KV。
- 默认模型：OpenCode Zen 的 `deepseek-v4-flash-free`，可由 Worker 环境变量替换。
- 默认额度：每个安装 ID 和来源 IP 每日各 20 条。
- 单条输出：最多 200 Token。
- 图片：仅个人 GLM-4.6V-Flash Key。
- 首次默认聊天：必须明确同意数据说明。
