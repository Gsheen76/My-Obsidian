# 聊天模式选择与代理容量设计

## 已确认交互

- 聊天窗口底部只保留一个聊天模式按钮。
- 点击后直接选择“免费聊天”或“自己配置 API”。
- 免费聊天固定使用项目方 OpenRouter 免费代理；个人 Key 即使已保存也不会自动启用。
- 选择自己配置 API 时，在同一个弹窗内选择模型并填写 API Key。
- 当前个人模型为 `GLM-4.6V-Flash`，图片上传只在该个人模式中显示。
- 切回免费聊天时保留本机 Key，方便以后再次启用。

## 兼容与安全

- 配置新增 `chat_mode`：`default` 或 `personal`。
- 旧配置按是否存在个人 Key迁移一次，之后完全遵循玩家的显式选择。
- Worker 对系统提示最多允许 4000 字符，对玩家/小狗普通消息每条最多允许 1200 字符。
- 整体请求继续限制为 16 KiB，客户端会优先移除最旧历史并按 UTF-8 字节预算裁剪。
- 免费回复仍限制为最多 200 输出 token。
