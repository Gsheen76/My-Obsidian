# 默认免费聊天代理设计

> [!important] 密钥边界
> 项目方模型密钥只保存为 Cloudflare Worker Secret，绝不写入 Petpet、仓库、截图、Obsidian 或发布包。此前发到对话中的密钥需要撤销并重新生成。

## 目标

无个人 API Key 的玩家可体验默认文字聊天；玩家配置个人 Key 后，使用自己的 GLM-4.6V-Flash 图文聊天。

## 路由

```text
个人智谱 Key -> Petpet 直连 GLM-4.6V-Flash
无 Key -> 首次数据确认 -> Cloudflare Worker -> OpenCode Zen 的 DeepSeek V4 Flash Free
```

## 免费额度

- 每个随机安装 ID 和来源 IP：每日各最多 20 条。
- Worker 固定最多 200 输出 Token，只接受文字与最近六轮对话。
- 达到上限：提示玩家配置个人 Key。
- 上游不可用：显示临时不可用，不泄露供应商报错或密钥。

> [!warning] 数据说明
> OpenCode 的 `deepseek-v4-flash-free` 是限时免费模型，官方说明免费期内内容可能用于模型改进。首次使用默认聊天必须由玩家主动确认；图片不走默认服务。

## 发布维护

1. Worker 使用可替换的模型环境变量，便于免费模型变化时切换。
2. 新增 `cloudflare-worker/` 源码、KV 绑定和部署说明。
3. 由项目方在 Cloudflare 配置新的 Secret 并部署；不把真实密钥提交到任意笔记或仓库。
4. 更新时同步维护客户端、Worker 测试、README 与本笔记。

外部资料：[OpenCode Zen 模型、接口与限时免费说明](https://dev.opencode.ai/docs/zen)
