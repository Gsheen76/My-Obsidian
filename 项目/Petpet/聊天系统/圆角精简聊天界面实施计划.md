# 圆角精简聊天界面实施计划

## 实施顺序

1. 先为 `免费｜自定义` 分段选择、条件工具和取消配置行为编写失败测试。
2. 用两个互斥圆角按钮替换旧模式菜单，统一刷新模式、工具可见性和发送状态。
3. 再为 24/18/15px 圆角层级和精简提示编写失败测试并实现。
4. 运行聊天 focused tests 与完整 `pytest -q`。
5. 启动当前 worktree 的 `pet.py`，截图检查免费态与自定义态。
6. 将最终行为和验证结果同步回 [[圆角精简聊天界面设计]] 与 [[Petpet 总档案]]。

## 不变范围

- 不修改 Worker、聊天额度、模型协议、历史记录和附件数据结构。
- 不批量重构其他游戏窗口。
- 不提交、不推送、不覆盖已有未提交改动。
