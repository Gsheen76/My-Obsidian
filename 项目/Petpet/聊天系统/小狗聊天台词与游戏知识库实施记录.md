# 小狗聊天台词与游戏知识库实施记录

> [!success] 本次完成内容
> 小狗回复不再自动加狗狗图标或括号动作文本，并能根据本地、随版本打包的玩家玩法资料回答游戏相关问题。

## 实现边界

- `assets/knowledge/game_knowledge.json` 保存玩家可见的已发布玩法；其 `version` 必须与 `version.py` 的 `VERSION` 完全一致。
- `game_knowledge.py` 对文件结构和版本做严格校验。损坏、过期或空资料会安全地返回空结果，不影响聊天。
- 关键词按命中数量排序，单次最多注入三条资料；普通闲聊不携带游戏资料。
- 运行时不读取 Obsidian、不请求网络，也不写入 API Key、项目内部路径或未发布计划。

## 当前资料范围

1. 日常互动：抚摸、喂食、玩耍与睡觉。
2. 快捷菜单：聊天、小屋、商店、互动、更多。
3. 小屋与家具：装修、家具变换、左键移动与地毯睡觉。
4. 成长与金币：成长、好感、商店与 Pet 币。
5. 小游戏入口。
6. 文字/图片聊天模型与图片隐私行为。

## 聊天呈现

- 人设提示词要求小狗只说自然台词，不输出舞台动作、旁白或括号内容。
- `clean_assistant_reply` 作为确定性兜底：新助手回复在显示、存档和桌宠说话前都会清理中英文括号段。
- 用户消息与既有历史记录保持原样；聊天标题只显示小狗名字，头像会留待后续单独接入。

## 版本维护

每次新增或调整玩家可见功能时，同步更新知识库条目和版本号，并补充对应测试、README 与本目录记录。
