# 暖色圆角聊天组件设计

> [!success] 已选 B 方案
> 本轮完整替换聊天相关的系统确认框、头像菜单、API 配置和模型选择；文件选择器保留系统原生。

## 风格

- 淡粉为选中态，搭配奶油黄、杏色和鼠尾草绿点缀。
- 暖白卡片、暖棕文字、统一圆角，不显示系统蓝色高亮。
- `免费｜自定义` 固定相同宽高、内边距与字体粗细，切换时不再上下浮动。

## 组件

- 清除记忆：Petpet 自绘圆角确认浮层。
- 头像选项：按钮下方的暖白圆角小卡片。
- API 配置：无系统标题栏的圆角配置卡。
- 单一模型：显示静态模型卡，不出现只有一个重复选项的下拉框。
- 多模型：以后达到两个以上时启用暖色下拉列表。

## 复用原则

提取调色常量、确认浮层与弹出菜单组件；本轮只接入聊天界面，其他窗口后续逐步迁移。

## 实施结果

- `免费｜自定义` 使用 17px 像素字体；按较长标签的实际字宽计算一次尺寸，两项固定同宽，切换不改变字号、字重或几何。
- 选中态改为淡粉 `#F8DCD7`，未选中态保持暖白，不再出现上下浮动。
- 清除记忆改用 `PetpetConfirmDialog`，无系统标题栏、系统问号图标和蓝色焦点框。
- 头像选项改用 `PetpetPopupMenu`；采用透明外壳和内部实体圆角卡，点击外部自动关闭。
- API 配置改为无边框透明顶层与圆角实体卡，使用奶油黄状态卡、杏色模型卡和淡粉主按钮。
- 当前只有一个个人模型，直接显示 `GLM-4.6V-Flash` 静态卡，不再显示重复下拉选项。
- 保存成功直接关闭并刷新状态；移除 Key 使用暖色确认浮层。

## 2026-08-12 字体与提醒修正

- 聊天子界面不再混用 QSS 点字号和系统继承字号，统一使用 DPI 无关的像素字体：标题 21px、正文 18px、按钮与菜单 17px、辅助文字 15px。
- 底部模式、模型、上传、设置与 `DEL` 控件统一为实际 40px 高，避免边框参与尺寸计算后出现 40/42px 混排。
- 清除确认框和头像菜单采用相同按钮字号与高度，解决文字偏小、发虚和页面比例不一致。
- API Key 提醒改为一次性未读状态：首次显示在桌面小狗本体、主菜单“聊天”和聊天页“自定义”，不再显示在“设置”。玩家首次打开自定义配置即保存 `personal_setup_seen=true`；即使 Key 留空，之后也不重复亮红点。
