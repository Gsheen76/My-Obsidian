# 圆角精简聊天界面设计

> [!success] 已确认方向
> 采用 B「分段切换」：聊天窗口底部常驻 `免费｜自定义`，高级选项只在自定义模式出现。

## 本轮范围

- 只重构聊天窗口的视觉和模式选择。
- 不修改聊天服务、额度、模型请求和历史存储逻辑。
- 全游戏界面默认使用圆角风格，作为后续新增或修改界面的长期规范；本轮不批量改动其他窗口。

## 免费模式

- 只显示 `免费｜自定义` 与清除记忆图标。
- 隐藏 API、模型、图片和配置说明。
- 服务异常：`免费聊天暂不可用，请稍后再试。`
- 额度用完：`今日免费次数已用完，可切换自定义。`

## 自定义模式

- 显示模型短名称 `GLM-4.6V`、上传图片、API 设置和清除记忆。
- 未配置 Key 时，选择 `自定义` 直接打开配置窗口。
- 取消配置时不改变原模式；保存成功后切换。
- 图片入口继续只对支持图片的模型显示。

## 圆角与配色

- 主窗口 24px；标题栏、底部编辑区和气泡 18px；输入框与发送按钮 15px。
- 分段按钮用胶囊形，工具按钮用正圆形。
- 延续家园暖米白、浅桃色与暖棕文字，不使用蓝色高亮。
- 标题只显示宠物名；正文按钮移除装饰性 emoji，图标操作使用工具提示。

## 验收

- 测试两个模式按钮、当前态和模式切换。
- 测试免费态隐藏高级工具，自定义态按能力显示工具。
- 测试无 Key 的配置流程与精简错误提示。
- 运行聊天 focused tests、完整 `pytest -q`，并启动当前 worktree 实际截图检查。

## 实施结果

- 旧的单个模式菜单已经替换为 `免费｜自定义` 互斥分段按钮。
- 免费态隐藏模型、图片与 API 设置；自定义态显示 `GLM-4.6V`、上传、设置与清除。
- 发送过程中会禁用模式和工具按钮，完成或失败后统一恢复。
- 主窗口、历史区、工具区、输入框、发送按钮和消息气泡已按 24/18/15px 层级调整。
- 免费额度与服务异常提示已压缩为一行短句。
