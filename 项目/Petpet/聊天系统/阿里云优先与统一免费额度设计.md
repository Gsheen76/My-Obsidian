# 阿里云优先与统一免费额度设计

> [!success] 已确认方向
> 免费聊天统一优先使用中国大陆阿里云函数；仅在阿里云连接阶段失败时使用 Cloudflare Worker。两个入口共享同一份每日 20 次额度。

## 核心决策

- 阿里云函数是大陆玩家默认入口，不依赖玩家开启代理。
- Cloudflare 是灾备入口，不根据“代理是否开启”硬切换，而只根据阿里云真实连接结果兜底。
- Cloudflare Durable Object 继续作为唯一原子额度账本。
- 客户端为每句消息生成 UUID v4 `request_id`；阿里云和 Cloudflare 使用同一个 ID，确保线路切换只扣一次。
- 安装 ID 与来源 IP 各自每天合计最多 20 次，而不是两个后端各 20 次。
- 只有 DNS/TCP/TLS/连接超时且尚未收到 HTTP 响应时允许切换；`ReadTimeout`、HTTP 响应或 SSE 已开始后不切换。

## 云端边界

- 阿里云使用函数计算 3.0 Web 函数，以支持 SSE 流式响应。
- 智谱 Key 只保存在阿里云环境变量；OpenRouter Key 继续只在 Cloudflare Secret。
- Cloudflare 新增受服务器间 Secret 保护的内部额度接口；该接口不接收聊天正文，只接收额度标识与来源 IP。
- 若统一额度服务不可用，阿里云失败关闭，不绕过免费额度。

## 隐私说明

为了维持跨入口统一 IP 额度，阿里云需要把来源 IP 通过 HTTPS 发送至 Cloudflare 做哈希计数。若以后要求 IP 完全不离开中国大陆，唯一额度账本必须迁至阿里云，不能继续使用 Cloudflare Durable Object。

## 2026-08-14 本地实现完成

> [!success] 代码与自动化测试已完成，尚未部署阿里云资源
> Cloudflare 统一额度、阿里云 Web 函数、桌面端阿里云优先/Cloudflare 回退均已实现。当前 `config.json.example` 的阿里云地址故意为空；取得函数公网 URL 后再填入并部署。

- Cloudflare 新增 `/internal/quota/consume`，只接受服务器间 Bearer Secret 与 `request_id`、`install_id`、来源 IP，不接收聊天正文。
- Durable Object 以请求 ID 绑定安装 ID；同一消息从阿里云切到 Cloudflare 时，即使两条线路看到的出口 IP 不同，也只扣一次。
- 公开 Cloudflare 接口继续兼容没有 `request_id` 的旧客户端，由服务端生成临时 ID，避免 v1.4.1 免费聊天失效。
- 阿里云函数源码位于 `aliyun-chat/`：Node Web 函数监听 9000 端口，额度通过后调用 `glm-4.7-flash`，并原样转发 SSE。
- 桌面端为每句消息生成 UUID v4；阿里云使用 `trust_env=False` 直连。仅连接建立前失败才切 Cloudflare；读取超时、HTTP 错误和流错误不切换。
- 诊断日志新增 `route=aliyun|cloudflare`，仍然只记录元数据。
