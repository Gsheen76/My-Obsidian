
## 当前源码入口

源码统一从项目根目录的 `pet.py` 启动。当前重构工作树为：

```text
D:\Agent_project\Petpet\.worktrees\home-scene-system
```

## 运行环境

当前工作树没有 `.venv`，日常直接使用已激活的 Python 环境即可；终端前缀显示
`(base)` 时，`python pet.py` 已可正常运行。

如需建立独立环境，再执行一次以下命令；完成后重新打开终端或激活 `.venv`：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements\runtime.txt
```

## 前台启动

调试、验证功能或查看报错时使用前台启动：

```powershell
Set-Location "D:\Agent_project\Petpet\.worktrees\home-scene-system"
python pet.py
```

## 后台启动

确认前台运行正常后，可使用 `pythonw.exe` 隐藏命令行窗口：

```powershell
Set-Location "D:\Agent_project\Petpet\.worktrees\home-scene-system"
$pythonw = (Get-Command pythonw.exe -ErrorAction Stop).Source
Start-Process -FilePath $pythonw `
    -ArgumentList "pet.py" `
    -WorkingDirectory (Get-Location) `
    -WindowStyle Hidden
```

退出源码版 Petpet 时，从系统托盘右键选择退出；调试启动时也可以在前台窗口按 `Ctrl+C`。
