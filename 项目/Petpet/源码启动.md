
## 当前源码入口

源码统一从项目根目录的 `pet.py` 启动。当前重构工作树为：

```text
D:\Agent_project\Petpet\.worktrees\home-scene-system
```

## 首次准备

```powershell
Set-Location "D:\Agent_project\Petpet\.worktrees\home-scene-system"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements\runtime.txt
```

## 前台启动

调试、验证功能或查看报错时使用前台启动：

```powershell
Set-Location "D:\Agent_project\Petpet\.worktrees\home-scene-system"
.\.venv\Scripts\Activate.ps1
python pet.py
```

## 后台启动

确认前台运行正常后，可使用 `pythonw.exe` 隐藏命令行窗口：

```powershell
Set-Location "D:\Agent_project\Petpet\.worktrees\home-scene-system"
Start-Process ".\.venv\Scripts\pythonw.exe" `
    -ArgumentList "pet.py" `
    -WorkingDirectory (Get-Location) `
    -WindowStyle Hidden
```

退出源码版 Petpet 时，从系统托盘右键选择退出；调试启动时也可以在前台窗口按 `Ctrl+C`。
