# Petpet v1.7.0 发布说明

> [!success] 已发布
> [GitHub Release v1.7.0](https://github.com/Gsheen76/Petpet/releases/tag/v1.7.0)（2026-09-07），提交 `70b5444`，标签 `v1.7.0` 与远端 main 一致；三资产 + SHA256 全部公开。

## 更新亮点（面向用户）

- **宠物详情面板从零重做**：全新左栏宠物头像列表、居中宠物展示与改名牌，简介页「图标+节名/数值」四模块（等级/好感/属性/性格）铺满排布，套装页左右分栏卡+穿装待机动画预览，左下角购买提示框。
- **按键反馈全应用统一**（宠物面板/商店/家园/装修面板）：悬浮放大+白洗+珊瑚描边，按住内缩+压暗，松开键内回弹 40ms 后触发，拖出取消；规范入 AGENTS.md。
- **简介/套装分栏按键素材化**，吸附在内容卡边框上方；小屋菜单「宠物」键新素材（睡窝柴犬）。
- **商店优化**：徽标缩 5%、删页首小字、交互键统一反馈。
- 修复：详情面板背景描边未渲染（空裁剪路径）、商店键悬浮消失（paint 期抓帧）、装修面板按键无反馈、分栏素材文件名互换。
