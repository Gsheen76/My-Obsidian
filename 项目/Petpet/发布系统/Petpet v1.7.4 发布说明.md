# Petpet v1.7.4 发布说明

> [!summary] Summary
> 2026-09-18 09:25（本地）发布，[GitHub Release](https://github.com/Gsheen76/Petpet/releases/tag/v1.7.4)，四资产（Windows exe/zip、macOS arm64、SHA256SUMS），基准 **882 passed**。内容=2026-09-15 发布后全部批次：v1.7.4 首批六项 + 遮挡滞回二次校准 + 小游戏两修 + 全应用审计九修。

## 宠物面板与礼物

- **「查看 / 陪伴」分离**：点头像卡只切换查看对象——简介、待机动画、套装、送礼、改名全部跟随查看的宠物；点「陪我」键才真正切换出勤小狗。改名不再误改出勤宠物、送非出勤宠物不再由出勤宠物替演反应。
- **名牌 / 陪我键 / 改名组件素材化**：胶囊名牌（28 号名字居中）+ 狗头图标改名键（常驻）+ 定稿陪我键；好感升级时面板即时提示。
- **送礼反应**：送出成功时出勤小狗当场播放开心动画（仅送出勤宠物时表演）。
- **礼物排版统一**：面板礼物页三列恒等宽、滚动条常驻；**双键确认弹窗按 Esc / 点卡片外一律视为取消**——不再误触送出消耗礼物。

## 聊天与记忆

- **聊天搜索**：聊天窗标题下新增搜索框，按关键词即时过滤历史记录。
- **陪伴周报**：记录页顶部新增陪伴周报卡（汇总互动数据）。
- **长期记忆抽取移入后台**：长会话（历史存满 60 条）后每条消息可能卡顿最长 20 秒的问题根除。
- **档案不再自我污染**：分栏渲染文本被反复迁回「其他」栏、挤掉真实记忆的问题根除。
- **对话异常兜底**：AI 回复流异常时如实报错收场，输入框不再永久卡在「停止」。
- 离线兜底回复恢复随机多样性。

## 稳定性与数据安全（全应用审计修复）

- **存档原子写入 + 自动备份**：temp+fsync+原子替换，写盘前保留上一份完好存档（`.bak`）；断电/崩溃/磁盘故障不再整档清零，主档损坏时启动自动回退。
- **自动睡醒回归**：精力过低自己走去睡觉、睡饱自动醒来（该状态机自 v1.5.0 重构起失效，本版重新接线）。
- **家具拖拽边界修复**：位置钳制改读家具定义目录（单一事实源），新增 8 件家具不再能被拖出全景外。
- **宠物详情面板**：待机动画帧加载失败后切换不再造成定时器累积（动画倍速异常）。
- **小游戏加固**：小游戏三窗按键接入全应用统一反馈；金币雨截止后的迟滞点击不再计分。

## 家园

- **遮挡滞回带二次校准**：按发布后回收的实测日志 6px → 12px，家具底线附近 ±10px 内晃动不再来回闪层。
