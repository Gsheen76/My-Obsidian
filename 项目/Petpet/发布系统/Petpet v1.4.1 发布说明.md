# Pet陪它 v1.4.1

> [!success] 已发布
> 2026-08-13 已公开：[GitHub Release v1.4.1](https://github.com/Gsheen76/Petpet/releases/tag/v1.4.1)。

这次更新重点优化聊天、设置和新手教程。没有 API Key 也能使用默认免费文字聊天；
需要看图时，可以配置自己的 GLM-4.6V-Flash Key，让小狗理解上传的图片。

## 主要更新

- 聊天模式精简为“免费聊天 / 自己配置”。
- 个人 GLM-4.6V-Flash 支持文字和图片，Key 仅保存在玩家本机。
- 小狗新增随版本维护的游戏知识库，可以回答小屋、家具、互动、成长和设置问题。
- 聊天窗口加入双方头像、玩家自定义头像和统一的暖色圆角组件。
- 设置页和六页教程重新排版、放大字体并默认居中打开。
- 健康提醒改为“少 / 适中 / 多”，性格偏好改为“文静 / 适中 / 活泼”。
- 旧设置自动映射到最近档位，不重置名字、成长、Pet 币、家具、头像或聊天记忆。
