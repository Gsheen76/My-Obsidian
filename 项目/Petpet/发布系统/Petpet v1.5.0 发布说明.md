# Pet陪它 v1.5.0

> [!success]
> 已公开：[GitHub Release v1.5.0](https://github.com/Gsheen76/Petpet/releases/tag/v1.5.0)

## 主要更新

- 家园宠物支持点击移动、四向行走、待机、地毯睡眠和自主活动。
- 家园新增商店与互动入口，状态卡成为可领取和摆放的墙面家具。
- 新增好感成长与零属性红点提醒，优化属性卡、路径、宝藏气泡和对话框定位。
- 宝藏与小游戏的 Pet币基础奖励提高。
- 免费聊天优先使用中国大陆可直连的阿里云函数，并保留 Cloudflare 备用线路。
- 默认模型更新为 GLM-4.7-FlashX；游戏知识只在相关问题中按需注入。
