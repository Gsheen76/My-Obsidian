# 小屋宠物功能分流与好感成长实施计划

> [!abstract]
> 按测试先行顺序实现 [[小屋宠物功能分流与好感成长设计]]，不发布新版本。

## 实施任务

1. 在 `progression.py` 集中实现被动好感、零属性动作映射、互动好感平衡与双倍寻宝规则。
2. 在属性面板加入 EXP/分钟与好感/分钟，并使用小数缓冲持久化被动好感。
3. 停止桌面随机走动，删除低属性可点击气泡，改为独立 10 分钟冷却的语言提醒。
4. 为小屋加入 12–25 秒随机移动调度，确保玩家指令、装修、互动和睡眠优先。
5. 将属性、商店和互动入口加入小屋右上角，互动下拉四项，并根据零属性显示红点。
6. 将寻宝改为圆形气泡，处理右键暂时隐藏、语言互斥与动态对话框三角。
7. 将金币雨和幸运爪爪基础奖励翻倍，完成 focused 与全量验证。

## 验证命令

```powershell
python -m pytest tests/test_progression.py tests/test_progression_integration.py tests/test_home_pet.py tests/test_home_scene.py tests/test_menu_ui.py tests/test_speech_bubble.py tests/test_minigames.py -q
python -m pytest -q
```

每个生产改动前先运行对应失败测试。最终同步 [[Petpet 总档案]] 与本实施计划的完成状态。

## 完成结果

> [!success]
> 2026-08-13 已按测试先行完成全部七项任务。focused tests 为 `251 passed`，完整回归为 `424 passed`，Python 语法检查与 `git diff --check` 同时通过。

- 小屋右上角现为 `属性｜商店｜互动⌄｜装修｜退出`，互动展开抚摸、喂食、玩耍和睡觉；小屋右键不再打开桌面菜单。
- 桌面取消随机移动与低属性点击气泡；小屋在空闲时每 12–25 秒自主选择地面目标。
- 被动好感、逐零属性减半、200 点升级需求上限、七类互动冷却和小数缓冲均已落地并存档。
- 零属性红点同步显示在桌面/小屋宠物、互动入口和对应恢复动作。
- 寻宝气泡已改成宠物正上方的暖黄色圆形提示，支持右键暂时隐藏与菜单关闭恢复；普通对话会主动避让。
- 对话框三角按当前宠物头顶中心动态定位；小游戏与新发现宝藏的奖励已整体翻倍。
- 本次没有提交、推送或发布新版本。
