# 家场景系统 Implementation Plan

> [!summary] Summary
> 记录 家场景系统 Implementation Plan 的背景、过程和结果。


> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` (recommended) or `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent home scene with a fixed viewport, dog-following horizontal camera, purchasable furniture, and free furniture placement.

**Architecture:** Keep `PetWindow` responsible for the dog while a new `HomeSceneWindow` renders the fixed background board behind it. Put coordinate conversion and camera clamping in `scene_system.py`; keep ownership, purchases, and persisted furniture positions in `progression.py`; connect both through narrow methods on `TrayApp` and `ShopWindow`.

**Tech Stack:** Python 3.12, PyQt5, QPainter/QPixmap, JSON state persistence, pytest, PyInstaller, raster assets generated with the `imagegen` skill.

## Global Constraints

- First version has one home scene, one horizontal world, no furniture collision, animation, stat effects, or multi-room navigation.
- The fixed scene board must remain behind the transparent dog window and fit entirely within the selected monitor's available geometry.
- Background visibility, scene board position, ownership, and furniture positions must survive restart without modifying existing outfit state.
- Use Pet coins and `records.coins_spent` for home furniture purchases; never mix furniture IDs with `DECORATION_DEFINITIONS`.
- Use only assets in `assets/scenes/home/`; add this directory to Windows and macOS packaging specs.
- Preserve the unrelated pending update-dialog changes in `pet.py` and `tests/test_menu_ui.py`.

```python
class HomeSceneWindow(QWidget):
    def set_dog_screen_rect(self, dog_rect):
        self.camera_x = scene_system.camera_x_for_dog(
            dog_rect.x() - self.geometry().x(), dog_rect.width()
        )
        self.update()

    def mouseReleaseEvent(self, event):
        if self._dragged_id:
            progression.set_home_decoration_position(
                self.state, self._dragged_id, self._drag_world_x, self._drag_world_y
            )
            self.save_callback(self.state)
```

Use `QPainter.drawPixmap` with a source rectangle offset by `camera_x`; render furniture at `world_x - camera_x`. Use explicit rectangular icon buttons for “隐藏背景” and “布置” in a narrow toolbar. Keep the scene window below the dog with `lower()` after every show/raise operation.
