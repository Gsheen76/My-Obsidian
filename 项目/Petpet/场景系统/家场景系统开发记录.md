# 家场景系统开发记录

关联：[[家场景系统设计]]、[[家场景系统实施计划]]

## 本次实现

- 新增固定在当前屏幕右下角的 `900 x 768` 家场景画板，以及 `1800 x 768` 的横向世界坐标。
- 小狗在家场景中使用独立世界 X 坐标移动；背景视口会水平跟随，并在左右边界停止。
- 在“右键 -> 更多”加入“家”以打开或聚焦家场景；场景右下角的 `X` 按钮用于退出并恢复普通桌面活动。
- 移除了“背景”菜单入口；场景窗口不再接收焦点，点击空白处或拖拽家具后都会将小狗恢复到上层，避免背景遮住小狗。
- 商店新增“家居”栏目，提供地毯、沙发、绿植、壁画四件商品，统一使用 Pet 币购买。
- 家具位置保存为世界坐标，可直接在场景内拖拽；家具不参与碰撞、物理、动画或属性计算。
- 旧存档会自动增加家场景、已拥有家居和家居坐标字段，不会改变原有穿戴装饰数据。
- Windows 与 macOS 的 PyInstaller 配置已包含 `assets/scenes`。

## 资源

- `assets/scenes/home/home-background.png`：横向暖色房间背景。
- `assets/scenes/home/rug.png`、`sofa.png`、`plant.png`、`wall-art.png`：透明家具贴图。
- 已从 Meowa 导入正式素材包：墙面 `background.png` 与透明地板 `midground.png` 在导入阶段合成为单张 `home-background.png`；运行时不做三层视差叠加。
- 导入脚本为 `tools/import_home_background.py`，输出固定为 `1800 x 768`，后续替换素材时可重复执行。

## 2026-08-07 素材与界面调整

- 接入四张正式家具素材：暖绒地毯、舒适沙发、绿植盆栽、墙面装饰画；去除生成图中的棋盘格背景并输出为透明 PNG。
- 家居商店商品名称、简介和操作页面改为中文，商品仍沿用原有存档 ID 与 Pet 币价格。
- 家具贴图按场景尺寸输出：地毯 `440 x 270`、沙发 `360 x 225`、盆栽 `190 x 340`、装饰画 `220 x 285`。
- 家场景画板增加 `24px` 圆角；小狗底线向上内缩 `48px`，脚部不再贴住画板下缘。
- 家具导入脚本为 `tools/import_home_furniture.py`，可从 Downloads 中的四张源图重复生成运行时资源。

## 2026-08-07 视野与装修交互

- 地毯替换为 `ChatGPT Image 2026年8月7日 17_14_04.png`，绿植替换为 `ChatGPT Image 2026年8月7日 17_01_31.png`；导入脚本分别移除暗色渐变和绿色幕布，并输出透明贴图。
- 家场景左右边缘新增“左移”“右移”按钮；点击移动一段视野，按住按钮会持续移动，视野 X 坐标限制在横向世界范围内并保存。
- 右下角新增中文“装修”按钮，与“退出”并列。装修模式打开家具面板，提供“全部、地毯、沙发、绿植、墙饰”分类。
- 已拥有家具可在装修面板中“放置”或“收纳”；选中家具后支持拖动、放大、缩小、左转和右转。
- 退出装修后面板关闭，家具不再响应拖动、缩放和旋转；装修状态、收纳列表、视野位置及家具变换参数均兼容旧存档并持久化。

## 验证

> [!success] 回归结果
> 2026-08-07 在隔离工作区执行 `pytest -q`，结果为 `201 passed in 16.27s`；四张家具 PNG 均验证为带透明通道的目标尺寸，装修家具变换也通过离屏绘制验证。

源码烟测已确认：打开家场景后画板尺寸为 `900 x 768`，小狗位于画板内；退出后场景关闭，小狗回到普通桌面活动。
