# 家园宠物待机与图片导航实施计划

> [!info] 项目内详细计划

## 目标与架构

为家园小狗加入高质量正坐待机图、固定前景尺寸、走向地毯的手动睡眠，以及由高清图片素材组成的脚印路线和目的地反馈。

- `home_pet.py`：不依赖 Qt 的移动、手动/自动睡眠状态和脚印采样。
- `home_scene.py`：素材加载、固定脚底锚点、待机与行走渲染、图片导航和睡眠场景同步。
- `pet.py`：家园激活时把快捷菜单“睡觉”委托给家园场景。
- `assets/scenes/home`：四张新增透明 PNG。

## 全局约束

- 工作区：`D:\Agent_project\Petpet\.worktrees\home-scene-system`
- 分支：`codex/home-scene-system`
- 不执行 `git reset`、`git checkout`，不回退其他未提交改动。
- 不暂存、不提交、不推送、不发布。
- 生产代码修改前先运行新增测试并确认 RED。
- 手工文本编辑使用 `apply_patch`。
- 家园小狗固定使用当前前景最大缩放 `1.08` 对应的尺寸。
- 待机只做单张静态正坐图；本轮不制作正式睡眠素材。
- 脚印、终点和箭头的可见外观全部来自透明 PNG。
- 规格、计划和最终结果同步写入本 Obsidian 功能分类。

## Task 4：快捷菜单走向地毯睡眠

### 接口

- `HomeSceneWindow.toggle_home_sleep(now=None) -> bool`
- `PetWindow.toggle_sleep()` 在活动家园存在时委托并返回。

### 行为

- 醒着：进入 `manual_sleep_walk`，目标优先为已放置地毯中心，否则为默认睡眠点；共享 `sleeping` 在到达前保持 `False`。
- 到达：设置 `sleeping=True`、`sleep_mode="manual"`，记录一次手动睡眠。
- 手动睡眠不因精力恢复自动醒来。
- 已睡着：再次点击则原地醒来。
- 自动睡眠仍使用 `sleep_mode="auto"` 并允许自动唤醒。

### TDD 步骤

- [ ] 添加快捷菜单睡眠委托测试。
- [ ] 添加地毯目标、默认回退、到达后共享状态和原地唤醒测试。
- [ ] 运行相关菜单与场景测试确认 RED。
- [ ] 实现场景睡眠入口、抵达同步和屋内委托。
- [ ] 重跑手动/自动睡眠测试确认 GREEN。

## Task 5：图片脚印、终点和箭头

### 导航反馈结构

`navigation_feedback(now=None)` 增加：

- `footprints`
- `target_rect`
- `arrow_rect`
- `arrow_offset`
- `opacity`

并移除与终点纵坐标相关的 `depth_scale`。目标参考显示尺寸约 `58×28`，脚印约 `18×22`；箭头上下浮动约 `2.5px`，呼吸缩放约 `±4%`。
